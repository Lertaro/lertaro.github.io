外觀與主題 ​

Lertaro 支援主題模式切換與多套配色方案。外觀設定頁面位於設定中心左側側邊欄底部（「關於」上方）。

1. 主題模式（Theme Modes） ​

頁面頂部提供三種主題模式切換卡片，按一下即切換生效：

  • 淺色模式（Light）：固定使用淺色調介面風格，下方的主題選取網格將僅展示淺色風格的主題卡片。
  • 深色模式（Dark）：固定使用深色調介面風格，下方網格將僅展示深色風格的主題卡片。
  • 跟隨系統（Follow System）：介面將根據 Windows 系統的深淺色設定自動即時切換。在此模式下，下方網格會分別呈現淺色主題與深色主題兩個選取區，你可以為白天和黑夜分別指定配色方案，系統切換時無需重啟 Lertaro 即可平滑過渡。

NOTE

Lertaro 會獨立記憶你在淺色與深色模式下分別選取的主題。當你在不同模式之間切換時，已選定的配色方案絕不會遺失。

2. 介面主題選取卡片 ​

主題選取區採用視覺化的縮圖卡片網格呈現，每張卡片都真實反映了搜尋框、邊框陰影、文字層級與選取反白行的實際配色效果，當前生效的主題右上角帶有清晰的勾選徽標。

內建與隨包主題介紹 ​

  • 核心內建主題（CoreExtensions）：
    • 淺色（Light） / 深色（Dark）：經典的黑白基底設計，融入 Windows 原生系統風格。
    • 北歐藍（Nordic Blue）：冷色調極簡極客風，低飽和度的冰藍與深海背景。
    • 櫻花粉（Sakura Pink）：柔和清新的粉白配色，細膩優雅。
    • 賽博龐克（Cyberpunk）：高對比度的霓虹黃與深紫夜色，充滿未來科技感。
  • 動漫主題包（AnimeThemes，隨包提供）：
    • 新世紀（Evangelion）、櫻花盛開（Sakura Blossom）、天氣之子（Weathering with You）。
  • 臻選成對主題（Curated Themes，隨包提供）：
    • 精心調配的 20 組淺色 / 深色成對主題：冰川藍、陶土棕、森林綠、紫水晶、緋紅、石墨灰、靛藍夜、薄荷青、香檳金、琥珀金、暮粉、滄浪青、抹茶綠、摩卡棕、黑曜石、落日珊瑚、薰衣草、鼠尾草青、羊皮紙、克萊因藍。

外掛模組主題擴充能力 ​

所有主題均基於 Lertaro.PluginSdk 的 UI 主題標準規範開發。第三方開發者可以透過編寫主題外掛模組向此網格動態註冊全新的個人化配色方案。
