關於與更新 ​

關於頁面提供了 Lertaro 當前執行環境的完整版本資訊、使用者與系統資料儲存目錄的快速直達入口，以及線上檢查更新與一鍵升級功能。頁面路徑為設定 → 關於。

1. 元件版本與專案資訊 ​

頁面頂部展示了 Lertaro 架構體系中四大核心元件的獨立版本號：

  • App 版本：前景 WPF 使用者互動介面版本。
  • Core 版本：核心搜尋與索引運算邏輯庫版本。
  • Service 版本：後台 Windows 索引服務版本（其文字顏色會動態反映服務當前是否處於健康連線狀態）。
  • CLI 版本：命令列終端互動工具 lff 的版本。

下方提供了專案官方網站、GitHub 開源存放庫以及線上文件中心的直達連結。

2. 資料目錄與自動備份輪轉機制 ​

頁面中央提供了兩個直接可點擊開啟實體路徑的超連結（若目標資料夾尚未產生，點擊時會自動建立）：

使用者資料目錄（User Data Directory） ​

  • 儲存內容：存放當前 Windows 使用者的個人設定檔 user-settings.json、搜尋與關鍵字歷程記錄、使用者專屬快取及憑證。
  • 五級備份輪轉保護機制：每次在設定中心點擊儲存或修改設定時，Lertaro 會自動將現有設定檔順延輪轉備份為 user-settings.json.bak.1，舊的備份依次向後推移至 user-settings.json.bak.5。即使發生斷電、誤改或系統當機，也能隨時在資料目錄中找到最近 5 次的歷史備份進行還原。

機器資料目錄（Machine Data Directory） ​

  • 儲存內容：存放後台提權服務使用的機器級設定檔 machine-settings.json、全盤實體索引持久化快取以及服務端記錄檔。

儲存路徑規則 ​

  • 安裝版：使用者資料存放於 %LocalAppData%\Lertaro，機器資料存放於 %ProgramData%\Lertaro。
  • 可攜版：使用者資料存放於程式目錄下的 Data\Users\<SID hash>，機器資料存放於 Data\Machine，與系統目錄完全隔離（詳見可攜版使用說明）。

3. 檢查更新與一鍵升級 ​

  • 檢查更新按鈕：點擊後手動發起線上版本偵測。按鈕文字會動態反饋檢查狀態（「正在檢查更新...」 → 「已是最新版本」 或彈出新版本更新卡片）。
  • 發現新版本時的升級方式：
    • 無訊息自動更新 —— 在後台自動下載新版本安裝套件並就地覆蓋升級，升級完成後自動重啟拉起 Lertaro。
    • 前往下載頁面 —— 在預設瀏覽器中開啟 GitHub Releases 發布頁面，供手動下載可攜壓縮包或安裝程式。
  • 權限安全提示：若當前運行在受限的標準使用者帳戶下，且無法直接停用後台 Windows 服務完成就地更新，頁面會呈現安全提示，並引導你前往官方頁面下載安裝。
