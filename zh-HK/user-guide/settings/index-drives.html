本頁目錄

索引管理 ​

索引設定頁面用於精細化控制 Lertaro 針對本機硬碟、網路儲存、WSL 子系統以及自訂資料夾的索引範圍、重新整理策略與排除規則。頁面頂部包含五個標籤頁：本機磁碟機、網路磁碟機、WSL（偵測到發行版時自動顯示）、資料夾與排除規則。

1. 本機磁碟機（Local Drives） ​

  • 頂部彙總狀態：展示當前已索引的實體磁碟機數量與總檔案/資料夾項目數，並提供重建索引按鈕觸發所有本機磁碟的全量重建。
  • 磁碟機列表行：每個實體分區獨立顯示一行：
    • 啟用/禁用核取方塊：獨立開關該磁碟的索引。
    • 檔案系統與狀態：顯示底層檔案系統類型（NTFS、ReFS、FAT32、exFAT 等）、當前狀態與已索引項目數。
    • 單盤操作：每行提供獨立的重建與移除操作；在重建掃描進行時會動態提供停止按鈕。
  • 即時監控機制：NTFS 與 ReFS 卷透過 Windows 系統的 USN 變更記錄檔實現毫秒級增量同步；FAT32 與 exFAT 卷透過檔案系統即時變更事件監聽。
  • 重建不中斷：在某個磁碟重建期間，舊索引將繼續回應使用者的搜尋查詢，直到新索引構建完成後一次替換，期間搜尋不會中斷。若重建過程被系統重啟或手動停止中斷，下次會自動從斷點繼續。

2. 網路磁碟機（Network Drives） ​

  • 網路儲存支援：展示所有已對應的 Windows 網路共用磁碟（SMB / NAS）。
  • 重新整理模式（Refresh Mode）：網路儲存缺乏本機 USN 記錄檔，因此支援自訂計劃輪詢策略：
    • 手動 —— 僅在按一下「重建索引」時重新掃描。
    • 每 15 分鐘 —— 高頻協同辦公目錄推薦。
    • 每小時 —— 均衡型定時掃描。
    • 每天 —— 靜態封存共用推薦。
  • 符號連結環路保護：掃描引擎內建了分支祖先路徑棧與符號連結循環偵測演算法，即使 NAS 共用中存在指向父級目錄的軟連結或重新分析點，也能自動攔截死循環，確保索引數量準確不膨脹。

3. WSL（Linux 子系統） ​

當且僅當系統偵測到至少安裝了一個 WSL 發行版時，本標籤頁會自動出現：

  • 自動探測：自動識別 Ubuntu、Debian、Arch 等已安裝的 WSL 發行版。
  • 狀態與重新整理：提供與網路磁碟機完全一致的狀態監控與重新整理模式設定（手動 / 每 15 分鐘 / 每小時 / 每天）。
  • 零 I/O 搜尋：搜尋 WSL 檔案時直接查詢記憶體索引樹，完全不喚醒或阻塞 Linux 子系統。

4. 資料夾（Folders） ​

當你不希望索引整個磁碟機或整台 NAS 伺服器，而只想精準收錄特定工作目錄時，可以使用自訂資料夾索引：

  • 多選新增：按一下新增資料夾按鈕開啟原生選取器，支援按住 Ctrl 或 Shift 一次性批次選取新增多個目錄。
  • UNC 路徑支援：支援直接新增類似 \\server\share\projects 的區域網路 UNC 共用目錄。
  • 獨立計劃重新整理：每個資料夾均擁有獨立的啟用開關、項目計數與重新整理模式下拉框（手動 / 每 15 分鐘 / 每小時 / 每天）。

5. 排除規則（Exclusions） ​

排除規則用於過濾搜尋結果，並限定網路儲存、WSL 與自訂資料夾的走查範圍；它不會停止本機磁碟的索引——本機磁碟區始終整盤走查，所以在這裡寫 E:\ 只會隱藏它的結果。要停掉某塊本機磁碟的索引，請在上方本機磁碟機分頁裡關閉它。規則分為三個子分頁：

路徑排除（Path Exclusions） ​

  • 比對機制：按完整實體路徑前綴進行精確屏蔽。
  • 環境變數支援：支援輸入 %ProgramData%、%APPDATA% 或 D:\Cache。

Glob 萬用字元排除（Glob Rules） ​

  • 常見語法：
    • *：比對單層目錄內的任意字元（如 *.tmp、*.log）。
    • **：跨層級遞迴比對任意子目錄（如 **/node_modules/**、**/bin/**、**/obj/**）。

規則運算式排除（Regex Rules） ​

  • 進階過濾：針對完整路徑或檔案名稱進行正規比對。例如使用 ^\. 排除 Linux 式隱藏點檔案，使用 ~\$ 排除 Office 產生的臨時鎖定檔案。

TIP

排除規則支援單筆新增與批次匯入匯出：按一下從列表產生可將現有規則匯出為多行文字，編輯後按一下套用到列表即可一次性批次生效。修改排除規則後，相關磁碟機與資料夾會自動重新套用過濾。
