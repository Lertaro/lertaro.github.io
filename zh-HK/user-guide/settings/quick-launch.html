快速啟動設定 ​

快速啟動是快速搜尋視窗在搜尋框留空時顯示的啟動面板。它會組合手動管理的項目，以及我的最愛、搜尋記錄等已選取的動態資料來源。

1. 總開關 ​

  • 啟用快速啟動面板：啟用此面板。只有在快速搜尋視窗的搜尋框留空，且至少有一個資料來源存在可用資料時，面板才會顯示。
  • 顯示快速鍵徽章：顯示每個可見項目對應的鍵盤快速鍵。此選項預設開啟；隱藏徽章不會停用快速鍵。
  • 關閉後，面板不會載入任何資料來源。
  • 面板高度會根據項目數量最多的資料來源計算，同時不會超過快速搜尋視窗結果區域的最大高度。

2. 手動快速啟動項目 ​

開啟設定 → 快速啟動 → 快速啟動，即可管理自己的項目：

  • 可以新增檔案、資料夾、網址或 Windows Shell 路徑，檢查目標時支援展開環境變數。
  • 顯示名稱可以留空，留空時 Lertaro 會根據目標自動產生名稱。
  • 檔案和資料夾瀏覽按鈕支援一次選取多個項目，每個有效且不重複的目標都會作為獨立項目加入。
  • 使用拖曳手柄調整順序。按一下編輯後，目前項目列會變成帶有儲存和取消按鈕的就地編輯器；刪除按鈕用於移除項目。
  • 對於手動項目，將滑鼠停留在卡片上並按一下省略號按鈕即可開啟選單，然後選取編輯或刪除；編輯會開啟項目編輯對話方塊。
  • 清單有內容時，可以使用清單標題右側的清空清單按鈕一次移除所有手動項目；清單為空時該按鈕會隱藏。
  • 目前無法使用的目標會從面板中隱藏，目標恢復可用後會自動重新出現。

3. 資料來源 ​

開啟設定 → 快速啟動 → 資料來源，即可選擇動態資料來源：

  • 資料來源來自已安裝的快速面板標籤頁提供者，因此快速啟動可以直接重用我的最愛、搜尋記錄、Windows 記錄、上次目錄、最近檔案以及後續外掛模組資料來源，不需要維護第二份資料。
  • 資料來源提供者存在時預設啟用，使用者設定中只儲存明確關閉的資料來源。
  • 只有已啟用且目前能返回資料的資料來源才會建立面板標籤頁，沒有資料的來源會隱藏。
  • 可以透過資料來源旁的拖曳手柄調整面板標籤頁順序，該順序會隨快速啟動設定儲存。
  • 當所有手動項目和動態資料來源都沒有資料時，快速啟動面板會隱藏。

4. 面板互動 ​

  • 面板欄數會根據搜尋列寬度自動調整。
  • 只有一個資料來源時，底部資料來源指示器會隱藏。
  • 有多個資料來源時，底部會為每個資料來源顯示一個圓點。選取的圓點為藍色，未選取的圓點為灰色；滑鼠停留時圓點會展開顯示資料來源名稱。
  • 在面板上按住 Shift 滾動滑鼠滾輪可以循環切換資料來源，切換後的資料來源會短暫播放同樣的展開動畫。
  • 設定的選取下一項和選取上一項快速鍵（預設為 Ctrl+N 和 Ctrl+P）在面板顯示時也可以循環切換資料來源，到達末尾後會返回第一個資料來源，反向切換時亦然。
  • 每個可見項目都可以使用設定的跳轉選取修飾鍵加 1–9、0 或 A–Z 開啟。第一個項目使用 1，第十個項目使用 0，其後的項目使用 A–Z，因此最多可以為 36 個可見項目提供快速鍵。
  • 面板顯示時，可以使用方向鍵按照項目的視覺網格移動選取：← 和 → 會按閱讀順序移動並跨越行邊界，↑ 和 ↓ 會保持目前欄位、只在相鄰行之間移動，並在目標行該欄沒有項目時停止；選取永遠不會跨越到其他資料來源，也不會循環。
  • 以滑鼠右鍵按一下任何資料來源中的項目，會在快速啟動面板內開啟該項目的懸浮動作選單。面板會暫時擴展到動作清單的最大工作高度，關閉選單後恢復原來的高度；按一下選單以外的區域即可關閉選單。
  • 當面板中的項目超出可見高度時，可以在項目區域使用滑鼠滾輪自由捲動（按像素捲動，而非整行捲動）；滑鼠停留在項目上不會阻止捲動。快速鍵徽章及其對應項目會隨內容一同移動。
  • 開始輸入搜尋內容後，面板會隱藏。
