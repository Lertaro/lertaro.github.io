本頁目錄

運行狀態 ​

運行狀態頁面集中監控 Lertaro 核心後台服務的生命週期健康度，並內建了面向 Service、App 與 Hook 三大核心程序的高效能即時記錄檢視器。頁面路徑為設定 → 運行狀態。

1. 服務狀態與控制 ​

頁面頂部展示後台提權索引服務的運行狀態卡片：

  • 即時狀態顯示：
    • 就緒（Ready）：服務運行健康，即時呈現當前已索引的實體檔案與資料夾總項目數。
    • 索引中（Indexing）：正在執行初始構建或全量增量更新，顯示動態進度指示器。
    • 安裝中（Installing）：正在註冊並部署 Windows 後台服務。
    • 錯誤（Error）：服務未運行或遇到異常中斷，顯示醒目的警告標記與錯誤描述。
  • 服務自我修復與安裝按鈕：當且僅當後台服務尚未安裝或由於系統權限受損進入異常狀態時，頁面會提供安裝並啟動服務按鈕；在服務健康運行期間，系統會維持後台持續常駐，避免誤操作導致索引中斷。

2. 三程序即時記錄檢視器 ​

頁面下方提供了內建記錄終端機，分為三個獨立的標籤頁，分別對應 Lertaro 運行的三大程序：

  • App 標籤頁：記錄前景 WPF 用戶介面、搜尋互動、快速鍵回應與視窗轉譯相關的操作記錄。
  • Hook 標籤頁：記錄低階全域鍵盤掛鉤獨立程序（Lertaro.Service.exe --hook）的按鍵擷取與程序隔離狀態。
  • Service 標籤頁：記錄提權 Windows 後台服務（Lertaro.Service.exe）的 USN 記錄檔剖析、磁碟遍歷、記憶體樹構建與 IPC 通訊記錄。

過濾與記錄清理功能 ​

  • 記錄等級過濾：下拉方塊支援篩選「全部 / 錯誤 / 警告 / 資訊 / 偵錯」，記錄行按嚴重等級自動呈現不同的顏色標記。
  • 即時搜尋過濾：在搜尋框中輸入關鍵字可對當前記錄內容進行全文過濾，並與等級過濾條件疊加生效。
  • 安全清空記錄：按一下清空記錄按鈕可清理當前標籤頁的歷史記錄輸出。清理 Service 記錄時會自動透過提權服務代理安全截斷，無需手動提升管理員權限。
