快速面板設定 ​

快速面板（Quick Panel） 是 Lertaro 專為高頻檔案取用、專案上下文管理與桌面拖曳互動打造的浮動工作區。它會在按下熱鍵時自動停靠在當前前景活動視窗的右下角，讓你無需離開當前工作視窗即可快速瀏覽、拖入或分發常用檔案。

1. 核心機制與總開關 ​

  • 啟用快速面板：總開關，關閉後將不再監聽呼出熱鍵。
  • 喚起熱鍵：預設快捷鍵為 Ctrl+F2（可在設定 → 熱鍵中自訂）。
  • 智慧貼靠與尺寸約束：面板預設尺寸為宿主視窗寬高的各二分之一（最小尺寸限制為 280 × 200px，確保內容與篩選框完整可用）。若當前處於 Lertaro 自身視窗時按熱鍵會被安全忽略，防止視窗重疊；面板開啟狀態下再次按下同款熱鍵可一鍵關閉。
  • 快速跳轉聯動：面板開啟期間，當前選取分組所指向的實體目錄會被自動記錄為活動目錄。在任意系統檔案對話方塊中按下快速跳轉快捷鍵（預設 Ctrl+G），即可直接跳轉到該目錄。

2. 工作區（Workspaces） ​

工作區用於按專案或任務組織一組相關的資料夾來源：

  • 工作區列表管理：左側列表呈現已建立的工作區，支援新建工作區、複製工作區與刪除工作區，可透過拖曳左側手柄調整其在面板標籤列中的前後排列順序。
  • 工作區屬性：
    • 名稱：標籤頁顯示的文字（留空時將自動使用跟隨系統語言的預設名稱）。
    • 啟用開關：勾選狀態決定是否在面板標籤列中顯示。在面板中按一下標籤上的 × 按鈕即是將該工作區臨時隱藏，可在此處重新勾選還原。

選取的工作區可透過右側的兩個子標籤進行精細化設定：來源與應用程式。

3. 來源設定（Sources） ​

每個來源代表工作區內部的一個獨立內容分組：

  • 新增資料夾：按一下新增資料夾按鈕選取實體目錄。
  • 顯示模式（Display Mode）：
    • 最近改動的檔案 —— 由記憶體索引毫秒級直接應答，僅展示近期發生變動的檔案（最新排在最前）。
    • 全部內容，最新在前 —— 呈現全部檔案，按修改時間降序排列。
    • 全部內容，按名稱 —— 適合作為固定檔案的快捷工具列。
  • 包含子資料夾：開啟後將遞迴收錄其所有子目錄下的檔案。
  • 接受拖入的檔案：開啟後，支援直接從外部將檔案、資料夾或瀏覽器圖片拖入該分組，Lertaro 會自動調用 Windows 原生複製介面將檔案複製進該目錄（具備衝突提示與復原支援）。
  • 檔案過濾規則：可使用萬用字元或搜尋語法中的 @ 篩選器限制該分組展示的檔案類型（例如 *.mp4;*.mkv、*.lnk;:@doc;:@img 或 *.lnk;:@doc|img）。
  • 最大條數與時間限制：可限制最大展示數量（設為 0 表示不限制）及僅展示若干分鐘內改動過的檔案。
  • 詳細列表 vs 縮圖平鋪：支援按分組獨立選擇以列表形式還是縮圖網格平鋪展示（平鋪時自動等比拉伸並保持畫面原始比例）。

4. 外掛模組標籤（Plugin Tabs） ​

除自訂工作區外，外掛模組亦可直接向快速面板註冊全域動態清單。CoreExtensions 核心外掛模組內建了五個實用標籤：

外掛模組標籤內容說明
我的最愛集中展示你的星標收藏項目，網址點擊後在瀏覽器中開啟。
搜尋記錄展示你透過 Lertaro 開啟過的最近項目與應用程式。
Windows 記錄自動解析 Windows 系統級的「最近使用的文件」並列出真實實體檔案。
上次目錄自動追蹤並遞回你在檔案總管或檔案對話方塊中剛剛離開的目錄。
最近檔案由後台記憶體索引直接彙總呈現所有設定目錄下的最新變動檔案。

可在列表右側獨立控制此外掛模組標籤的顯示狀態以及採用平鋪還是列表檢視。

5. 應用程式綁定與獨立黑名單 ​

  • 應用程式關聯（Applications）：可為工作區指定一個或多個前景程序名稱（如 chrome.exe 或 devenv.exe）。當你在該軟體上呼出快速面板時，面板將自動直達該關聯工作區，免去手動切標籤的麻煩。
  • 僅快速面板黑名單：可在此設定不希望被快速面板打擾的程序名單。該名單會疊加在全域熱鍵黑名單之上，專用於處理不希望被面板遮擋但無需全域禁用的特殊程式。

6. 面板互動指南 ​

  • 即時模糊過濾：面板右上角內建搜尋過濾框，支援 fzf 模糊比對與拼音別名，輸入即可即時篩選當前工作區。
  • 全鍵盤流暢導覽：使用上下方向鍵可無縫跨越不同分組連續捲動；在選取的項目上按下 Enter 鍵即可直接開啟。
  • 標籤快捷切換：按住 Ctrl + 1–9 即可在各個工作區與外掛模組標籤間快速跳轉。
  • QuickLook 預覽與釘住：選取項目後按 Alt+P 可在面板側邊呼出即時預覽；按 Ctrl+T 可釘住面板使其在失去焦點時不自動消失。
