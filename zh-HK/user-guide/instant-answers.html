即時解答與關鍵字擴充功能 ​

除了本機檔案檢索之外，Lertaro 還內建了一系列強大的即時計算、系統工具與關鍵字擴充外掛模組。無需等待檔案檢索，輸入對應指令即可即刻得到答案或觸發專業功能。

1. 始終生效的即時解答 ​

無需輸入任何前綴關鍵字，只要輸入的文字比對特定模式即可立即觸發：

計算機與進位制轉換 ​

直接在搜尋框中輸入數學運算式，計算結果將在第一行即時呈現。按下 Enter 鍵即可將計算結果複製到剪貼簿：

text
12 * (4 + 3)
100 * (1 - 0.15)

支援常見的進位制轉換表達：

text
255 to hex
0xFF to dec
101010 to bin

環境變數展開與查詢 ​

  • 精準展開變數：輸入 %NAME%（如 %PATH%、%APPDATA%）可直接檢視變數值。對於包含多個路徑的變數（如 PATH），Lertaro 會自動將其拆分為清晰的逐行列表，便於檢查環境設定。
  • 模糊搜尋變數：輸入 % 加上關鍵字（如 %temp）可模糊搜尋所有名稱中包含該關鍵字的系統與用戶環境變數。

快捷執行命令 ​

無需先開啟終端機視窗，直接在搜尋框中輸入：

  • #<命令>：開啟命令提示字元視窗並以系統管理員權限執行該命令（例如 #sfc /scannow 或 #net start Lertaro.Service）。
  • $<命令>：開啟命令提示字元視窗以當前普通用戶權限執行該命令（例如 $ping 1.1.1.1 或 $ipconfig /all）。

網址直達 ​

直接輸入或貼上以 http:// 或 https:// 開頭的完整網址，按下 Enter 即可立即在預設瀏覽器中開啟該頁面。當輸入沒有搜尋結果且以裸域名開頭時，快速搜尋視窗會自動填入 https:// 並將游標移動到文字末尾；已經包含協定的輸入不會被修改。

快速搜尋視窗匯入剪貼簿文字 ​

快速搜尋視窗在沒有預填內容的情況下被呼叫時，如果剪貼簿文字不為空且不同於該視窗上一次匯入的剪貼簿內容，就會自動填入並全選文字。相同內容不會重複匯入，從 URI 或完整搜尋視窗返回時的預填內容也不會被覆蓋。

2. 關鍵字觸發功能（內建外掛模組） ​

透過輸入簡短的觸發關鍵字 + 空格，再輸入實際查詢內容，即可調用專項外掛模組能力。各關鍵字均可在設定 → 外掛模組中自訂修改。

預設關鍵字外掛模組名稱功能說明與使用場景典型使用範例
ps處理程序管理按處理程序名、PID 或視窗標題搜尋運行中的處理程序（支援拼音），按 Enter 一鍵結束處理程序。ps chrome 或 ps 1234
win視窗切換器搜尋並即時切換到當前開啟的應用程式視窗，支援背景即時抓取視窗縮圖。win code 或 win 瀏覽器
bm瀏覽器資料搜尋 Chrome、Edge、Firefox 等瀏覽器的書籤與歷史造訪記錄（書籤與歷史可獨立開關）。bm github
set設定搜尋模糊搜尋 Lertaro 自身的所有設定選項，選取即可直接跳轉到對應設定頁並反白該項。set 熱鍵 或 set 模糊
flowFlow 外掛模組橋接列出所有已載入的 Flow.Launcher 外掛模組及其觸發詞，支援無縫調用 Flow 社群生態。flow

3. 網頁搜尋快捷引擎 ​

網頁搜尋外掛模組內建了主流搜尋引擎快捷方式，輸入對應前綴並跟隨關鍵字即可一鍵拉起瀏覽器搜尋：

快捷詞對應搜尋引擎範例說明
bd百度 (Baidu)bd 深度學習在百度中搜尋關鍵字
g谷歌 (Google)g lertaro github在 Google 中搜尋關鍵字
bing必應 (Bing)bing 微軟文件在 Bing 中搜尋關鍵字
ghGitHubgh Lertaro直接在 GitHub 儲存庫中搜尋
wiki維基百科 (Wikipedia)wiki 量子力學在維基百科中查閱條目
ytYouTubeyt lofi hip hop在 YouTube 中搜尋影片

你可以在設定 → 外掛模組 → 網頁搜尋 → 設定中自由新增、修改或刪除搜尋引擎與自訂 URL 範本。

4. 即時翻譯 ​

輸入預設觸發詞 tr 並在其後輸入待翻譯的內容，即可自動翻譯為 Lertaro 當前所選的介面語言：

text
tr Hello, how are you today?
  • 翻譯結果隨輸入非同步呈現，按 Enter 鍵即可一鍵複製譯文。
  • 可在設定 → 外掛模組 → 翻譯 → 設定中更改觸發詞或檢視連線狀態。

5. 檔案篩選器 ​

在設定 → 外掛模組 → 檔案篩選器 → 設定中，你可以為特定目錄和副檔名建立專屬篩選器規則：

  • 指定監控目錄：遞迴掃描指定工作目錄（如 D:\Engineering\Drawings）。
  • 指定比對規則：例如 *.dwg;*.dxf 或 *.pdf;*.docx（不影響子資料夾收錄）。
  • 設定觸發關鍵字：為該規則綁定專屬前綴（如 cad 或 doc），輸入 cad 零件圖 即可實現特定業務資料的精準隔離搜尋。

6. 自訂命令 ​

在設定 → 外掛模組 → 自訂命令 → 設定中，你可以將任意複雜的命令列工具、指令碼或外部應用程式包裝為一個簡短的啟動命令：

  • 參數占位符：支援位置占位符 %s1、%s2……（對應以空格分隔的參數）以及全文占位符 %s（代表關鍵字後的所有輸入文字）。
  • 快速導覽整合：勾選「在快速導覽中顯示」後，該命令會直接作為選單項出現在快速導覽中，支援使用 / 建立多級子選單分類（如 開發工具/重啟服務）。
