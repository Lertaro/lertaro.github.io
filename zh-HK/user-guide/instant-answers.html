即時解答與關鍵字擴充功能 ​

除了本機檔案檢索之外，Lertaro 還內建了一系列即時計算、系統工具與關鍵字擴充外掛模組。無需等待檔案檢索，輸入對應指令即可即刻得到答案或觸發對應功能。

1. 始終生效的即時解答 ​

無需輸入任何前綴關鍵字，只要輸入的文字比對特定模式即可立即觸發：

計算機與進位制轉換 ​

直接在搜尋框中輸入數學運算式，計算結果將在第一行即時呈現。按下 Enter 鍵即可將計算結果複製到剪貼簿：

text
12 * (4 + 3)
100 * (1 - 0.15)

支援常見的進位制轉換表達：

text
255 to hex
0xFF to dec
101010 to bin

環境變數展開與查詢 ​

  • 精準展開變數：輸入 %NAME%（如 %PATH%、%APPDATA%）可直接檢視變數值。對於包含多個路徑的變數（如 PATH），Lertaro 會自動將其拆分為清晰的逐行列表，便於檢查環境設定。
  • 模糊搜尋變數：輸入 % 加上關鍵字（如 %temp）可模糊搜尋所有名稱中包含該關鍵字的系統與用戶環境變數。

快捷執行命令 ​

無需先開啟終端機視窗，直接在搜尋框中輸入：

  • #<命令>：開啟命令提示字元視窗並以系統管理員權限執行該命令（例如 #sfc /scannow 或 #net start LertaroService）。
  • $<命令>：開啟命令提示字元視窗以當前普通用戶權限執行該命令（例如 $ping 1.1.1.1 或 $ipconfig /all）。

在設定 → 插件 → 核心擴充 → 配置 → 系統命令執行器中，可選擇 CMD（預設）、Windows PowerShell 或 PowerShell（pwsh）。啟用在當前目錄中執行後，內嵌搜尋使用所在目錄，快速搜尋使用最近瀏覽的目錄。未取得目錄時（例如首次使用快速搜尋），使用用戶主目錄；選定目錄無法使用時停止執行。

勾選在快速導航選單中顯示後，可透過在此目錄執行命令輸入命令、選擇解譯器及管理員權限。它使用選單來源目錄，子資料夾的右鍵選單則使用該子資料夾。留空會開啟所選解譯器；#／$ 前綴覆蓋權限選項。前綴後精確輸入 cmd、powershell 或 pwsh 時（忽略大小寫及首尾空格），直接開啟對應程式；只有找不到程式才回退至 CMD 執行原輸入。一般命令選用的解譯器不存在時會報錯。

CMD 在切換目錄前便會展開啟動命令中的 %CD%。若提權或 UNC 路徑使系統變更初始目錄，該變數可能仍指向舊目錄；需要讀取目錄時，可選擇 PowerShell 並使用 $PWD。

網址直達 ​

直接輸入或貼上以 http:// 或 https:// 開頭的完整網址，按下 Enter 即可立即在預設瀏覽器中開啟該頁面。輸入合法的無協定網址（例如 example.com）時，快速搜尋視窗會直接產生兩個瀏覽器即時結果：https://... 和 http://...。無協定識別只針對硬編碼在代碼中的常見頂級網域白名單（超過一百個後綴，如 .com、.cn、.io，並包含 xn-- 國際化網域），無法設定；與常見檔案副檔名重名的後綴被刻意排除；其餘輸入仍依檔名搜尋，例如 abc.txt 不會產生網址結果；要開啟白名單未涵蓋的網址時請一併輸入協定。瀏覽器結果採用兩行式的開啟文案，搜尋框內容不會被修改；已經包含協定的網址只產生一個瀏覽器結果。瀏覽器結果之後還會追加一條 ping <主機> 結果，按 Enter 或按一下會在命令解譯器視窗中執行它，所用解譯器取自系統命令執行器的設定。主機名從網址中自動剝離協定、帳號、端口、路徑與查詢字串後取得，IPv4、IPv6 和國際化網域（轉成 punycode）均可直接 ping。

快速搜尋視窗匯入剪貼簿文字 ​

只有在開啟 設定 → 一般 → 快速搜尋視窗 → 自動將剪貼簿文字填入快速搜尋框（預設關閉）時，快速搜尋視窗在沒有預填內容的情況下被呼叫，且剪貼簿文字不為空並不同於該視窗上一次匯入的剪貼簿內容，才會自動填入並全選文字。相同內容不會重複匯入，從 URI 或完整搜尋視窗返回時的預填內容也不會被覆蓋。

2. 關鍵字觸發功能（內建外掛模組） ​

透過輸入簡短的觸發關鍵字 + 空格，再輸入實際查詢內容，即可調用專項外掛模組能力。各關鍵字均可在設定 → 外掛模組中自訂修改。

分隔符可以是半形空格、全形空格或定位鍵；觸發關鍵詞本身不参与檔案名匹配，也不會被高亮。當兩個功能使用同一個關鍵詞時，外掛程式配置頁會在該欄位下方以黃色提示佔用它的是誰，但不會阻止儲存。

預設關鍵字外掛模組名稱功能說明與使用場景典型使用範例
ps處理程序管理按處理程序名、PID 或視窗標題搜尋運行中的處理程序（支援拼音），按 Enter 一鍵結束處理程序。ps chrome 或 ps 1234
win視窗切換器搜尋並即時切換到當前開啟的應用程式視窗，支援背景即時抓取視窗縮圖。win code 或 win 瀏覽器
bb瀏覽器書籤搜尋 Chrome、Edge、Firefox 等瀏覽器的書籤。bb github
bh瀏覽器歷史搜尋 Chrome、Edge、Firefox 等瀏覽器的歷史造訪記錄。bh github
set設定搜尋模糊搜尋 Lertaro 自身的所有設定選項，選取即可直接跳轉到對應設定頁並反白該項。set 快速鍵 或 set 模糊
flowFlow 外掛模組橋接列出所有已載入的 Flow.Launcher 外掛模組及其觸發詞，支援調用 Flow 社群生態。flow
cs內容搜尋搜尋已建立索引的本機文件內文，並返回帶片段的相符檔案。cs 專案計劃

選取 win 搜尋結果後，開啟動作選單（Ctrl+O）即可使用以下視窗操作。兩項均以視窗所在顯示器的可用區域為準（避開工作列），最小化或最大化的視窗會先還原再定位。

  • 調整至螢幕大小並置中（s）：分別檢查視窗的寬與高，僅將超出可用區域的維度縮小至對應可用尺寸減 12 像素，然後置中。未超出的維度（包括恰好相等）保持不變。
  • 位置置中（e）：將還原後的視窗移到可用區域正中央，不調整大小。

3. 網頁搜尋快捷引擎 ​

網頁搜尋外掛模組內建了主流搜尋引擎快捷方式，輸入對應前綴並跟隨關鍵字即可一鍵拉起瀏覽器搜尋：

快捷詞對應搜尋引擎範例說明
bd百度 (Baidu)bd 深度學習在百度中搜尋關鍵字
g谷歌 (Google)g lertaro github在 Google 中搜尋關鍵字
bing必應 (Bing)bing 微軟文件在 Bing 中搜尋關鍵字
ghGitHubgh Lertaro直接在 GitHub 儲存庫中搜尋
wiki維基百科 (Wikipedia)wiki 量子力學在維基百科中查閱條目
ytYouTubeyt lofi hip hop在 YouTube 中搜尋影片

你可以在設定 → 外掛模組 → 網頁搜尋 → 設定中自由新增、修改或刪除搜尋引擎與自訂 URL 範本。

4. 即時翻譯 ​

輸入預設觸發詞 tr 並在其後輸入待翻譯的內容，即可自動翻譯為 Lertaro 當前所選的介面語言：

text
tr Hello, how are you today?
  • 翻譯結果隨輸入非同步呈現，按 Enter 鍵即可一鍵複製譯文。
  • 可在設定 → 外掛模組 → 翻譯 → 設定中更改觸發詞或檢視連線狀態。

5. 檔案篩選器 ​

在設定 → 外掛模組 → 檔案篩選器 → 設定中，你可以為觸發關鍵字綁定特定目錄，讓一般搜尋可以限定在這些目錄內：

  • 範圍資料夾清單：一行一個路徑（如 D:\Engineering\Drawings），亦支援環境變數（如 %TEMP%）與系統虛擬路徑（如 shell:Downloads），無法解析為真實資料夾的項目會被略過。搜尋結果來自檔案索引，因此資料夾需被索引覆蓋（已啟用索引的本機磁碟，或在設定 → 索引 → 資料夾中新增，支援網絡共用路徑）；未被索引覆蓋的資料夾會被略過並記錄警告日誌。
  • 比對規則：檔案名稱萬用字元模式（如 *.dwg;*.dxf，資料夾一律保留）。
  • 觸發關鍵字：綁定前綴（如 cad）後，在快捷搜尋框輸入 cad 零件圖 即可只在綁定的資料夾內執行一般索引搜尋（按檔案名稱模糊比對，包含拼音別名）；僅輸入關鍵字時會提示繼續輸入。

6. 自訂命令 ​

每個命令均可啟用在當前目錄中執行，覆蓋固定工作目錄：快速導航選單使用來源目錄，內嵌搜尋使用所在目錄，快速搜尋使用最近瀏覽的目錄。目錄無法使用時停止執行；此選項預設關閉。

在設定 → 外掛模組 → 自訂命令 → 設定中，你可以將任意複雜的命令列工具、指令碼或外部應用程式包裝為一個簡短的啟動命令：

  • 參數占位符：支援位置占位符 %s1、%s2……（對應以空格分隔的參數）、全文占位符 %s（代表關鍵字後的所有輸入文字）以及剪貼簿占位符 %c（或 {c}）。
  • 快速導航整合：勾選「在快速導航中顯示」後，該命令會直接作為選單項出現在快速導航中，支援使用 / 建立多級子選單分類（如 開發工具/重啟服務）。
