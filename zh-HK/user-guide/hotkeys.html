熱鍵與互動手勢 ​

Lertaro 採用鍵盤優先的互動設計，同時提供極其豐富的滑鼠快捷手勢與多級導覽系統。除固定按鍵外，所有全域與應用程式內快捷鍵均可在設定 → 熱鍵中自由重新綁定。

1. 全域快捷鍵速查表 ​

功能動作預設快捷鍵功能說明與互動細節
呼出/隱藏快速視窗雙擊 Ctrl可設定為雙擊模式或常規組合鍵（例如 Alt+Space、Win+Space 等）。啟用「預設開啟完整面板」後，此快捷鍵會改為開啟主視窗：首次顯示時只將其置於前景並聚焦一次，視窗已顯示但未啟用時重新啟用，視窗已啟用時再次按下則關閉；不會自動保持置頂。
快速切換（Quick Jump）Ctrl+G在檔案對話方塊中直接跳轉到最近一次從受支援檔案管理器或快速面板中瀏覽的資料夾。
選取下一項Ctrl+N 或 ↓向下移動列表反白項目。在快速面板中支援無縫跨分組連續瀏覽；在快速啟動面板中，方向鍵按照可見網格移動，左右鍵會跨越行邊界，上下鍵會保持目前欄位；快速啟動面板顯示且搜尋內容為空時，Ctrl+N 會循環切換到下一個資料來源。
選取上一項Ctrl+P 或 ↑向上移動列表反白項目。在快速面板中同樣支援跨分組巡覽；在快速啟動面板中，方向鍵按照可見網格移動，左右鍵會跨越行邊界，上下鍵會保持目前欄位；快速啟動面板顯示且搜尋內容為空時，Ctrl+P 會循環切換到上一個資料來源。
跳轉至第 1–9 項結果Ctrl + 1–9修飾鍵可自訂，快速視窗結果旁會顯示對應的數字徽章，直接按鍵秒開目標項目。
開啟動作選單Ctrl+O 或 →展開選取結果的快顯動作面板（複製路徑、屬性、以系統管理員身分執行、檔案操作等）。
從選取項補全搜尋詞Ctrl+Tab將當前選取項目的名稱或完整路徑直接填入搜尋框，便於在此基礎上做二次篩選。
QuickLook 即時預覽Alt+P開啟/關閉選取項目的側邊預覽面板（圖片、文件、音訊/影片即時播放、資料夾結構等）。
上一條搜尋記錄詞Alt+Up向前翻閱最近輸入過的搜尋關鍵字。
下一條搜尋記錄詞Alt+Down向後翻閱最近輸入過的搜尋關鍵字。
刪除當前歷史詞Ctrl+Delete從最近搜尋歷史記錄中移除當前顯示的這一條詞彙。
開啟完整搜尋主視窗Ctrl+F直接開啟大尺寸主搜尋視窗，並自動同步當前快速視窗中的搜尋詞。
開啟傳送視窗（LocalSend）Ctrl+S開啟 LocalSend 無線區域網路傳輸視窗，快速傳送檔案或文字至跨平台裝置。
保持視窗不消失（釘住）Ctrl+T臨時鎖定視窗，在失去焦點時不再自動隱藏（便於從其他視窗複製文字組合查詢）。
呼出/關閉快速面板Ctrl+F2在當前前景活動視窗旁展開包含最近檔案、我的最愛、工作區的快速停靠面板。

2. 搜尋框圖示與滑鼠手勢 ​

搜尋框內的小圖示不僅是品牌識別，更集成了多種實用的滑鼠快捷手勢：

快速搜尋視窗中的圖示手勢 ​

  • 滑鼠左鍵按一下：直接在游標處彈出快捷主選單（顯示主視窗、切換熱鍵配置、開啟設定、關於、乾淨結束、結束程式）。其中「顯示主視窗」會自動攜帶當前輸入的內容。
  • 滑鼠左鍵按住拖曳：自由拖曳調整搜尋列在螢幕上的顯示位置。拖曳時按住 Ctrl 鍵可將移動方向嚴格鎖定為純垂直方向，避免水平位置發生偏移。
  • 滑鼠右鍵按一下：一鍵將快速視窗重設回螢幕初始預設置中位置（不改變已配置的視窗尺寸）。
  • 滑鼠中鍵按一下：快捷切換視窗「釘住（保持不消失）」狀態，釘住期間 Logo 圖示會反白發光。

NOTE

快速視窗記錄的螢幕座標是相對於所在顯示器的相對比例座標。當你將視窗喚出在另一台不同解析度、不同 DPI 縮放的顯示器上時，Lertaro 會自動等比換算位置，絕不會跑出螢幕可視區域。

內嵌視窗與主視窗中的圖示 ​

  • 內嵌視窗：當嵌入在原生檔案對話方塊（開啟/儲存/瀏覽）時，按一下左鍵圖示可直接展開快速導覽級聯選單；停靠在普通檔案總管時僅作展示。
  • 主視窗：按一下左鍵圖示會開啟快顯功能表；由於主視窗已經開啟，功能表中的「顯示主視窗」項目會隱藏。按一下中鍵可切換視窗的釘住狀態。

3. 快速導覽（滑鼠觸發） ​

快速導覽功能讓你無需打字，透過滑鼠按一下即可在任意視窗中直達常用目錄或開啟檔案。

觸發方式與支援環境 ​

  • 桌面空白處：滑鼠中鍵按一下（或開啟按兩下左鍵）直接彈出快速導覽選單，按一下目錄或檔案直接開啟。
  • 檔案總管：在檔案總管空白處按一下滑鼠中鍵觸發，按一下目標後當前視窗立即跳轉到該路徑。
  • 第三方檔案管理器：在 Directory Opus、Total Commander、XYplorer、Files、One Commander 等工具的檔案列表區按一下滑鼠中鍵觸發（詳見支援的檔案管理器）。
  • 系統檔案對話方塊：在任意軟體的「開啟/儲存/瀏覽資料夾」對話方塊中按一下中鍵或按一下內嵌圖示觸發，按一下後對話方塊直接跳轉至目標目錄，絕不會誤觸發「儲存/開啟」確認。

級聯選單內容與管理 ​

快速導覽選單由**級聯資料夾瀏覽器（Folder Cascader）**外掛模組驅動，內容高度結構化：

  1. 當前開啟的資料夾：自動彙總並去重所有受支援檔案管理器當前正在瀏覽的真實目錄，方便在不同應用程式間快速同步路徑。
  2. 我的最愛與歷史記錄：自動按分類列出你的加星收藏與最近造訪歷史。
  3. 自訂快捷分類：支援在設定 → 外掛模組 → 級聯資料夾瀏覽器中自訂目錄與子選單（如使用 工作/專案A 建立多級分類）。
  4. 一鍵新增目錄（+ 按鈕）：選單每個層級的標題右側均設有一個 + 按鈕，按一下即可直接將當前正在瀏覽的資料夾快速儲存到該分類下，無需開啟設定面板。

4. 硬編碼核心按鍵（不可修改） ​

為了保證最核心互動的確定性與一致性，以下按鍵在任何配置下行為始終保持統一：

按鍵觸發場景統一行為
Enter結果列表直接開啟選取的結果（檔案/目錄/程式/動作）。
Ctrl+Enter結果列表在檔案總管中開啟並定位選取項目所在目錄。
Ctrl+Shift+Enter結果列表以系統管理員權限啟動選取的程式或檔案。
Escape任意場景若搜尋框內有文字則清空文字；若搜尋框已為空則關閉當前視窗或退出動作選單。
Backspace動作選單當搜尋過濾詞已為空時，按下直接退出動作選單返回結果列表。
← / → 方向鍵動作選單左箭頭返回上一級選單，右箭頭進入子選單。
Alt+Space所有 Lertaro 視窗強制屏蔽系統標題列選單，防止誤觸彈窗。
Alt+F4主視窗 / 設定視窗關閉當前視窗。在快速視窗、內嵌視窗及預覽浮窗上會被屏蔽（防止誤關閉駐留服務）。

5. 外掛模組動作熱鍵與處理程序黑名單 ​

外掛模組獨立動作熱鍵 ​

外掛模組可以註冊專屬動作快捷鍵（例如 Ctrl+Shift+C 快速複製路徑，以及內建檔案操作：剪下 Ctrl+X、複製 Ctrl+C、貼上 Ctrl+V、刪除 Delete、徹底刪除 Shift+Delete 等）。你可以在設定 → 熱鍵 → 外掛模組動作中統一查看並重新綁定。

處理程序黑名單與全螢幕自動放行 ​

  • 全螢幕應用程式自動放行：當偵測到前景有獨占全螢幕運行的應用程式（如全螢幕 3D 遊戲、全螢幕影片播放器）時，Lertaro 預設會自動放行所有全域快捷鍵，絕不搶佔遊戲控制。
  • 自訂處理程序黑名單：在設定 → 熱鍵頁面中新增特定處理程序名稱（如 game.exe），當該程式處於前景時，全域熱鍵與滑鼠快速導覽將完全靜默放行。
