3 プロセス分離アーキテクチャ

特権境界を厳格に分離し、システム全体の安定性と安全性を最大化

SYSTEM サービスLertaro.Service

LocalSystem 権限でバックグラウンド常駐。NTFS / ReFS の USN ジャーナルと $MFT を直接読み取り、名前付きパイプを通じて超高速な読み取り専用データを提供。

ユーザーアプリLertaro.App

標準ユーザー権限で動作する WPF デスクトップアプリ。クイック検索バー、メイン検索ウィンドウ、設定画面、プラグイン実行を安全に担当。

フック＆統合Lertaro.Service --hook

独立した特権補助プロセス。低レベルキーボードフックを管理し、UIPI 権限の壁を越えて管理者権限ダイアログともクラッシュ耐性を保ちながら連携。

よくある質問 (FAQ)

アーキテクチャ、バックグラウンドサービス、機能に関する技術的解説

Q

なぜバックグラウンド Windows サービスが必要なのですか？

NTFS/ReFS の USN ジャーナルを LocalSystem 権限で直接読み取るためです。UAC 昇格ダイアログなしで安全かつ高速に変更を監視でき、UI アプリに不要な権限を持たせません。

Q

Everything や Listary との主な違いは何ですか？

Lertaro は Listary のようなファイルダイアログへの直接ドッキングとあいまい検索を備えつつ、Everything 級の高速 USN インデックスとモダンな .NET 10 プラグイン機構、容量分析を兼ね備えています。

Q

ポータブル版とインストーラー版の違いは何ですか？

インストーラー版はバックグラウンドサービスを自動登録します。ポータブル版は解凍後すぐに利用でき、必要に応じて設定画面からサービスを登録・解除できます。

Q

検索データがクラウドに送信されることはありますか？

一切ありません。Lertaro は 100% 完全ローカルで動作し、テレメトリ送信や外部通信は一切行いません。
