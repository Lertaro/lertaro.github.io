インスタント機能とキーワード拡張 ​

Lertaro はローカルファイルの検索だけでなく、即座に計算結果を返す機能や各種システムツール、キーワード連動型の拡張プラグインを標準搭載しています。ファイル検索の完了を待つことなく、コマンドを入力するだけで即座に結果を得られます。

1. プレフィックス不要の即時機能 ​

キーワードを入力しなくても、入力した文字列が特定のパターンに一致すると自動的に起動します。

計算機と基数変換 ​

検索ボックスに計算式を直接入力すると、計算結果が 1 行目にリアルタイムで表示されます。Enter キーを押すと計算結果がクリップボードにコピーされます。

text
12 * (4 + 3)
100 * (1 - 0.15)

進数変換にも標準で対応しています。

text
255 to hex
0xFF to dec
101010 to bin

環境変数の展開と検索 ​

  • 変数の展開：%NAME%（例: %PATH%、%APPDATA%）を入力すると、変数の実際の値が表示されます。PATH などの複数のパスを含む変数は、見やすいリスト形式に自動展開されます。
  • 変数のあいまい検索：% に続けてキーワードを入力する（例: %temp）と、名前にその文字を含むシステム/ユーザー環境変数を検索できます。

コマンドの直接実行 ​

ターミナルを開かずに検索ボックスから直接コマンドを実行できます。

  • #<コマンド>：コマンドプロンプトを開き、管理者権限で実行します（例: #sfc /scannow や #net start LertaroService）。
  • $<コマンド>：コマンドプロンプトを開き、通常のユーザー権限で実行します（例: $ping 1.1.1.1 や $ipconfig /all）。

設定 → プラグイン → コア拡張 → 構成 → コマンド実行で CMD（既定）、Windows PowerShell、PowerShell（pwsh）を選べます。現在のディレクトリで実行を有効にすると、インライン検索ではその場所、クイック検索では最後に閲覧したディレクトリを使用します。フォルダーを取得できていない場合（クイック検索の初回利用時など）はユーザーフォルダーを使用します。選択したフォルダーが利用できない場合は実行を停止します。

クイックナビゲーションに表示を有効にすると、メニューの呼び出し元ディレクトリでコマンドを実行できます。子フォルダーの右クリックメニューではその子フォルダーを使用します。ダイアログで実行環境と管理者権限を選択でき、空欄では選択したシェルを開きます。#／$ は権限チェックボックスより優先されます。接頭辞の後が正確に cmd、powershell、pwsh の場合は対応するプログラムを直接開きます（大小文字と前後の空白は無視）。見つからない場合のみ元の入力を CMD で実行します。通常のコマンドで選択したシェルが見つからない場合はエラーになります。

CMD はディレクトリ変更前に起動コマンドの %CD% を展開します。昇格や UNC パスによって初期ディレクトリが変わると、以前の場所を示すことがあります。起動コマンドで場所を取得する場合は PowerShell の $PWD を使用できます。

Web サイトの URL 直開き ​

http:// または https:// で始まる URL を入力または貼り付けて Enter を押すと、既定のブラウザでそのページが即座に開きます。example.com のような有効なプロトコルなしの Web アドレスを入力すると、クイック検索ウィンドウに https://... と http://... の 2 つのブラウザー用即時結果が生成されます。プロトコルなしの認識は、コードに固定された一般的なトップレベル ドメインのホワイトリスト（.com、.cn、.io など百を超える接尾語と xn-- の国際化ドメイン）に限定されており、設定できません。一般的な拡張子を兼ねる接尾語は意図的に除外され、それ以外の入力はそのままファイル名検索として扱われるため、abc.txt ではブラウザー用の結果が生成されません。一覧にない URL を開きたい場合はプロトコルを含めて入力してください。ブラウザー用の結果は開く案内を 2 行形式で表示し、検索ボックスの内容は変更されません。すでにプロトコルを含む URL はブラウザー用の結果として 1 件表示されます。その後に ping <ホスト> の結果が追加され、Enter またはクリックでコマンドインタープリターのウィンドウが開いて実行されます。使用するインタープリターはシステムコマンド実行の設定に従います。ホスト名は URL からプロトコル、ユーザー情報、ポート、パス、クエリを除いて取得し、IPv4、IPv6、国際化ドメイン（punycode 変換）のいずれにも直接 ping できます。

クイック検索ウィンドウへのクリップボード文字列の取り込み ​

設定 → 一般 → クイック検索ウィンドウ → クリップボードのテキストを自動入力（既定は無効）を有効にすると、入力が事前設定されていない状態でクイック検索ウィンドウを呼び出したとき、クリップボードが空でなく、同じウィンドウで直前に取り込んだ値と異なる場合に自動入力して全選択します。同じ値は繰り返し取り込まず、URI やフル検索ウィンドウから戻った際の事前入力も上書きしません。

2. キーワード起動機能（内蔵プラグイン） ​

短い トリガーキーワード + スペース の後にクエリを入力することで、専用プラグインの機能を呼び出せます。各キーワードは 設定 → プラグイン で自由に変更可能です。

区切りには半角スペース・全角スペース・タブのいずれでも使え、トリガーワード自体はファイル名マッチやハイライトには使われません。同じ語を二つの機能が使っている場合、プラグイン設定画面の該当欄の下に琥珀色の注意表示が出ますが、保存は阻止されません。

既定のキーワードプラグイン名機能概要と活用シーン入力例
psプロセス管理実行中のプロセスを名前、PID、ウィンドウタイトル（ピンイン対応）で検索し、Enter キーで即座に終了。ps chrome や ps 1234
winウィンドウ切り替え開いているウィンドウを検索して切り替え。バックグラウンドでのリアルタイムサムネイル取得に対応。win code や win ブラウザ
bbブラウザーのブックマークChrome、Edge、Firefox などのブックマークを検索します。bb github
bhブラウザーの閲覧履歴Chrome、Edge、Firefox などの閲覧履歴を検索します。bh github
set設定検索Lertaro 内部のすべての設定項目をあいまい検索。選択すると該当する設定画面へ直接ジャンプしてハイライト。set ホットキー や set あいまい
flowFlow プラグインブリッジ読み込まれている Flow.Launcher プラグインとそのトリガーワードを一覧表示。flow
csコンテンツ検索インデックス済みローカル文書の本文を検索し、スニペット付きでファイルを表示。cs プロジェクト計画

win の検索結果を選択し、アクションメニュー（Ctrl+O）を開くと、次のウィンドウ操作を利用できます。どちらも対象ウィンドウがあるモニターの作業領域（タスクバーを除く）を使用し、最小化・最大化されている場合は通常の状態に戻してから配置します。

  • 画面に収めて中央に配置（s）：幅と高さを個別に確認し、作業領域を超えている寸法だけを、その領域の対応する寸法から 12 ピクセル引いた値に縮小して中央に配置します。収まっている寸法（同じ値の場合も含む）は変更しません。
  • 中央に配置（e）：通常の状態に戻したウィンドウを、サイズを変更せずに作業領域の中央へ移動します。

3. Web 検索エンジン連携 ​

Web 検索プラグインには主要な検索エンジンのショートカットが組み込まれており、プレフィックスに続けて検索語を入力するとブラウザで検索を実行できます。

設定 → プラグイン → Web 検索 → 設定 で検索エンジンの追加、編集、削除、URL テンプレートの変更が可能です。

4. インスタント翻訳 ​

既定のトリガーワード tr の後にテキストを入力すると、Lertaro で現在選択されている UI 言語に自動翻訳されます。

text
tr Hello, how are you today?
  • 入力中に非同期で翻訳結果が表示され、Enter キーで訳文をコピーできます。
  • 設定 → プラグイン → 翻訳 → 設定 でトリガーワードの変更が可能です。

5. ファイルフィルター ​

設定 → プラグイン → ファイルフィルター → 設定 で、トリガーキーワードに特定のフォルダーを紐付け、通常の検索をそれらのフォルダー内に限定できます。

  • 対象フォルダー: 1 行に 1 つのパスを入力（例: D:\Engineering\Drawings）。環境変数（例: %TEMP%）とシェルの仮想パス（例: shell:Downloads）にも対応し、実フォルダーに解決できない項目はスキップされます。検索結果はファイルインデックスから得られるため、フォルダーはインデックスの対象である必要があります（インデックス対象のローカルドライブ、または設定 → インデックス → フォルダーへの追加。ネットワーク共有パスも対応）。インデックスが対象外とするフォルダーはスキップされ、ログに警告が出力されます。
  • 拡張子ルールの指定: *.dwg;*.dxf などのファイル名パターン（フォルダーは常に含まれる）。
  • トリガーキーワードの割り当て: プレフィックス（例: cad）を割り当てると、クイック検索で cad パーツ図 と入力した際、通常のインデックス検索（ファイル名のファジーマッチ、ピンイン別名を含む）がバインドされたフォルダー内に限定されます。キーワードのみ入力した場合は入力を促す表示になります。

6. カスタムコマンド ​

各コマンドの現在のディレクトリで実行は、固定作業ディレクトリをメニューの呼び出し元、インライン検索の場所、またはクイック検索で最後に閲覧した場所で置き換えます。利用できない場合は実行を停止します。既定では無効です。

設定 → プラグイン → カスタムコマンド → 設定 で、よく使うスクリプトやツール、外部アプリを簡単なコマンドとして登録できます。

  • パラメータプレースホルダー：位置プレースホルダー %s1、%s2...、キーワード以降の全文を受け取る %s、クリップボードのテキストを受け取る %c（{c} でも可）に対応。
  • クイックナビゲーションへの登録：「クイックナビゲーションに表示」を有効にすると、クイックナビゲーション メニューにピン留めされ、/ を使った多階層分類（例: 開発ツール/サービス再起動）も可能です。
