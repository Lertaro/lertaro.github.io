ユーザーガイド ​

Lertaro 公式ユーザーガイドへようこそ！Lertaro は、Windows 向けのファイル検索＆生産性向上ランチャーです。バックグラウンドでインメモリインデックスツリー（NTFS / ReFS は USN 変更ジャーナル、その他のファイルシステムはリアルタイムイベント監視）を常時保持し、数千万件規模のファイルに対してもミリ秒未満の検索応答を実現します。

  • クイックスタート —— インストール手順、ポータブル版、アーキテクチャ概要、3 つのウィンドウ形態（クイック / メイン / インライン）、基本操作。
  • 検索構文 —— あいまい一致、修飾演算子（! 除外、' 完全一致、^ 前方一致、$ 後方一致、| OR 条件）、ドライブ指定、パスモード、多言語ピンイン対応。
  • ホットキーとマウス操作 —— グローバルホットキー一覧、検索ボックスロゴのマウス操作、クイックナビゲーション階層メニュー、固定キー。
  • アクションとプレビュー —— コンテキストアクションメニュー（Ctrl+O）、メインウィンドウ一覧操作、QuickLook メディア/文書プレビュー、対話型プラグインカード。
  • ストレージ分析 —— ディスク I/O ゼロのツリーマップ＆サイズ降順一覧で大容量ファイルを特定。
  • インスタント機能とキーワード拡張 —— 常時利用可能な計算機・環境変数・コマンド実行、およびプロセス管理（ps）、ウィンドウ切り替え（win）、ブラウザーのブックマーク（bb）、閲覧履歴（bh）、設定検索（set）などのプラグイン。
  • コマンドライン検索（lff） —— ターミナル用対話型あいまい検索ツール。インメモリインデックスを共有し、パイプラインやシェルスクリプトと連携。
  • URI プロトコル（lertaro://） —— ブラウザーリンクやショートカット、スクリプトから検索画面、設定画面、LocalSend 送信へダイレクトジャンプ。
  • 対応ファイルマネージャー —— Windows 標準ダイアログや Directory Opus、Total Commander、XYplorer、Files などのファイラーとの統合。
  • 設定項目リファレンス —— サービス状態、インデックス管理、一般設定、外観、ホットキー、プラグイン設定の全項目解説。
  • トラブルシューティング —— ホットキーが反応しない場合やインデックス未更新時の診断とログ確認手順。
  • 寄付とサポート —— Lertaro の継続的な開発とオープンソース活動への支援。
