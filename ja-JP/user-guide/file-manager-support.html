対応ファイルマネージャーとダイアログ統合 ​

Lertaro は単体のデスクトップランチャーとしても、Windows エクスプローラー、サードパーティ製ファイラー、各種アプリのダイアログに組み込まれた状態としても使え、ファイルを開く・保存する・フォルダーを移動する作業を効率化します。

1. 3 つの主要な統合機能 ​

対象となるウィンドウの特性に応じて、最大 3 つの統合機能が提供されます。

  • インライン検索（Inline Search）：対象ウィンドウの上部やダイアログ内に検索バーを直接埋め込み、作業中の画面を離れることなく現在のフォルダーや全体を即座に検索。対応するファイル一覧で英数字を入力した瞬間に現れ、最初に入力した 1 文字を自身のボックスへ引き継ぎます。
  • クイックナビゲーション（Quick Navigation）：余白の中クリック（有効にした場合のみ左ダブルクリック。既定でオフ）やロゴのクリックで、現在開いているフォルダー、お気に入り、履歴、カスタム分類を含むクイックナビゲーションメニューを表示。サードパーティ製ファイラーは中クリックのみに対応しています。
  • アクティブパス検知（Active Path Detection）：対象ウィンドウが現在開いているフォルダーをリアルタイムに検知し、検索範囲を自動的にそのフォルダーに限定したり、相対パス操作を正確に解決。

TIP

ファイルダイアログにドッキングしたインラインウィンドウは、意図的にキーボードをダイアログ側に残します。これまでどおりそのまま入力を続けられるためです。Ctrl の 2 回連打（または設定済みの呼び出しホットキー）でキャレットをウィンドウへ移し、検索語が空のウィンドウでもう一度押すとフォーカスをダイアログへ返せます。詳しくは ホットキー の「インラインウィンドウの呼び出しとフォーカスの引き継ぎ」を参照してください。

2. Windows 標準コンポーネント（組み込み・設定不要） ​

以下の標準コンポーネントは、追加のプラグインなしで標準でサポートされています。

対象ウィンドウインライン検索クイックナビゲーション操作アクティブパス検知
Windows エクスプローラー対応余白部分で中クリック、または有効化すれば左ダブルクリック対応
モダン「開く/保存」ダイアログ対応（ダイアログ内に直接埋め込み）中クリック、またはロゴアイコンを左クリック—
クラシック「開く/保存」ダイアログ対応中クリック、またはロゴアイコンを左クリック—
フォルダーの参照ダイアログ対応中クリック、またはロゴアイコンを左クリック—

NOTE

各種ファイル選択ダイアログでは、Lertaro がダイアログ内部に直接埋め込まれているため、外部からのパス検知は不要です。クイックナビゲーションで項目を選択すると、ダイアログがそのフォルダーへ直接移動します。

3. サードパーティ製ファイラー対応（プラグイン） ​

高度なファイラーをご利用の方向けに、専用の統合プラグインが用意されています。設定 → プラグイン で有効化し、インライン検索やクイックナビゲーションを個別に設定できます。

ファイラー名インライン検索クイックナビゲーション操作アクティブパス検知通信方式・プロトコル
Directory Opus対応ファイル一覧領域で中クリック対応WM_COPYDATA 公式リモート API
Total Commander対応ファイル一覧領域で中クリック対応WM_COPYDATA 公式メッセージプロトコル
XYplorer対応ファイル一覧領域で中クリック対応専用プロセス間通信
Files対応ファイル一覧領域で中クリック対応Windows UI Automation
One Commander対応ファイル一覧領域で中クリック対応Windows UI Automation

Directory Opus 向けの統合 ​

  • フォルダーサイズ列（Lertaro サイズ）：Directory Opus プラグインで「Lertaro サイズ列を有効化」にすると、カスタムスクリプト列が追加されます。Lertaro のインメモリインデックスから再帰的な合計サイズを直接取得するため、ディスク I/O ゼロ でドライブ全体のフォルダーサイズを表示できます。
  • 設定の保存：列セレクターで「Lertaro サイズ」を追加後、フォルダー → フォルダー形式 → 保存 → すべてのフォルダーに形式を保存 をクリックして永続化します。

Everything 互換サービス (IPC) ​

設定 → 一般 → システム で Everything 互換サービス (IPC) を有効化 すると、標準の Everything Win32 IPC インターフェースをエミュレートします。Directory Opus、Total Commander、Flow Launcher などのツールから、Everything を起動することなく Lertaro のインメモリインデックスを直接利用できます。

4. 各種アプリの独自ダイアログ対応（専用プラグイン） ​

標準の Windows ダイアログを使用せず、独自のカスタムダイアログを持つ主要アプリに対しても専用プラグインを提供しています。

アプリとダイアログ種別インライン検索クイックナビゲーション操作備考
WPS Office 開く/保存ダイアログ対応中クリック、またはロゴアイコンをクリックWPS Writer、Spreadsheets、Presentation、PDF を網羅
WinRAR 解凍ダイアログ対応中クリック、またはロゴアイコンをクリック解凍先フォルダーを素早く指定
Bandizip 解凍ダイアログ対応中クリック、またはロゴアイコンをクリック解凍先の出力フォルダーを即座に指定
Bandizip ファイル追加ダイアログ対応中クリック、またはロゴアイコンをクリックアーカイブに追加するファイルを素早く選択
AutoCAD 開く/保存ダイアログ対応中クリック、またはロゴアイコンをクリック設計図面ファイルの素早い保管と呼び出しに最適化

各プラグインはウィンドウの内部コントロール構造とハンドル階層を直接認識して動作するため、言語パックや細かな UI の違いに左右されません。
