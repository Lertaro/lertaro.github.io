ホットキーとマウス操作 ​

Lertaro はキーボード優先の操作設計を採用しつつ、多彩なマウスジェスチャーとクイックナビゲーションを提供します。固定キーを除き、すべてのグローバルおよびアプリ内ホットキーは 設定 → ホットキー で自由にカスタマイズできます。

1. グローバルホットキー一覧 ​

機能・アクション既定のキー機能説明と操作の詳細
クイックウィンドウの表示/非表示Ctrl の 2 回連打連打方式または通常の修飾キー組み合わせ（例: Alt+Space など）に変更可能です。連打は同じ修飾キーを 2 回押して 100〜300 ms をおいて離す操作を指します。左右の Ctrl は別のキーであり、その間に他のキーを押すとカウントはやり直しになります。連打方式では修飾キー自体が吸収されないため、通常の Ctrl+C 系のショートカットはそのまま動作します。既定でメインウィンドウを開くを有効にすると、このキーでメインウィンドウを開き、初回表示時は一度だけ前面とフォーカスを処理します。表示中で非アクティブなら再アクティブ化し、すでにアクティブならもう一度押すと既定ではクイックウィンドウへ戻り、ショートカットの再入力でフルウィンドウを閉じるを有効にした場合はそのまま閉じます。自動的に最前面へ固定されることはありません。
クイックジャンプ（Quick Jump）Ctrl+Gファイルダイアログ内で、直前にエクスプローラー、対応するファイラー、またはファイルダイアログで開いていたフォルダーへ移動。
クイックナビゲーションメニュー既定値なし任意のグローバルショートカットでクイックナビゲーションメニューを開けます。デスクトップや通常のアプリではデスクトップのコンテキストを使い、エクスプローラーやネイティブのファイルダイアログではアクティブなウィンドウのコンテキストを使います。通常の前景保護でグローバルホットキーが抑止される場合でも、ファイラーとファイルダイアログは許可されます。

アクションメニューを開くCtrl+O または →選択中の項目のコンテキストアクション（パスのコピー、プロパティ、管理者実行、ファイル操作等）を展開。クイックウィンドウと、ファイルダイアログ外のインラインウィンドウで使えます。メインウィンドウでは同じメニューを右クリックまたは Apps キー（Shift+F10）で開きます。

前の検索履歴語Alt+Up最近入力した検索キーワードを前に遡って表示。

メインウィンドウを開くCtrl+F現在入力中の検索キーワードを引き継いだまま、大画面のメイン検索ウィンドウを開く。
LocalSend 画面を開くCtrl+SLocalSend 経由で他デバイスにファイルやテキストを送信する画面を開く。
ウィンドウを固定（ピン留め）Ctrl+Tフォーカスを失ってもウィンドウを閉じずに維持（他アプリから文字をコピーして貼り付ける際に便利）。
クイックパネルの表示/非表示Ctrl+F2現在のアクティブウィンドウの横に、最近のファイル・お気に入り・ワークスペースを含むパネルを表示。

ファイルダイアログで検索欄が空の場合 ​

ネイティブのファイルダイアログにインライン検索ボックスが埋め込まれていて検索欄が空の場合、一覧にはまず「前回のディレクトリ」グループが表示されます。「インライン検索に現在開いているフォルダーを表示」が有効なら、対応ファイラーで現在開いているフォルダーをまとめた「現在開いているフォルダー」グループも表示され、ここにはダイアログ自身が現在開いているフォルダーも意図的に含まれます。重複するパスは統合され、空のグループは表示されません。グループ見出しにはショートカットバッジも表示されません。この設定は既定で有効で、設定 → 一般 → システム から変更できます。この動作はファイルダイアログ内のインライン検索だけに適用され、クイックウィンドウとフルウィンドウには影響しません。

インラインウィンドウの呼び出しとフォーカスの引き継ぎ ​

ネイティブのファイルダイアログにドッキングしたウィンドウは、意図的にキーボードを奪いません。フォーカスはダイアログに残るので、ダイアログ自身のファイル名欄へそのまま入力を続けられ、ウィンドウ側は検索語を反映します。キャレットを動かせる操作は次のとおりです。

操作効果条件
英数字を入力ウィンドウが呼び出され、最初に入力した 1 文字が検索ボックスに引き継がれ、その後のキー入力もそのまま流れ込みます実際のキー入力のみが対象です。自動化ツールによる合成入力はそのまま素通しされ、コンテキストメニューやシステムメニューが開いている間は何も捕捉しません
Ctrl の 2 回連打（または設定済みの呼び出しホットキー）キャレットをウィンドウ自身の検索ボックスへ入れます。検索ボックスがすでにキャレットを持っていて検索語が空の場合は、代わりに検索語をクリアし、ウィンドウを開いたままフォーカスをダイアログの欄へ返します他の場所と同じホットキーです。設定 → ホットキー で割り当てを変えれば、この引き継ぎも一緒に変わります。ブラックリストや全画面で通常ならグローバルホットキーが抑止される場合でも、ファイルダイアログは許可されたままです
Escapeダイアログがキーボードを持っている間はウィンドウを閉じます。ウィンドウが持っている間は検索語をクリアし、フォーカスをダイアログへ戻します（ファイルダイアログの場合）か、ウィンドウを閉じます（通常のエクスプローラー上にドッキングしている場合）
空の欄で BackspaceEscape とまったく同じように検索を終了しますウィンドウがキャレットを持っている場合のみ。ダイアログがキーボードを持っている間は、このキーはウィンドウの検索語を編集するだけにとどまります
空の欄で EnterEscape と同じように検索を終了しますウィンドウがキャレットを持っている場合のみ。ダイアログがキーボードを持っている間は、Enter は選択中のブラウズ行を開きます
Tabダイアログ自身のコントロール移動に残り続けるため、ウィンドウへは呼び出しホットキーで移動してください

NOTE

ファイルダイアログ内では、ウィンドウのアクションメニューを利用できません（Ctrl+O、→、右クリックはいずれも効かず、Alt+P のプレビューも提供されません）。マウスは行に対してそのまま使えます。左クリックで選択中の結果を開き、Ctrl+クリックで管理者として開き、行をドラッグアウトしてダイアログ側に落とせ、ホバーするだけで選択が動きます（ホストのファイラー側にも同じ選択が反映されます）。

2. 検索ボックスのロゴとマウス操作 ​

検索ボックス内の小さなロゴアイコンには、実用的なマウス操作が割り当てられています。

クイックウィンドウでのロゴ操作 ​

  • 左クリック：カーソル位置にコンテキストメニューを表示（メインウィンドウの表示、他のデバイスへ送信、ホットキーの有効化/無効化、設定、バージョン情報、クリーン終了、終了。トレイアイコンと同じメニューです）。「メインウィンドウの表示」は現在の検索語を引き継ぎます。
  • 左ドラッグ：画面上の検索バーの位置を自由に移動。Ctrl キーを押しながらドラッグすると、移動方向が垂直方向のみに固定され、横位置のズレを防げます。
  • 右クリック：設定されたサイズを維持したまま、クイックウィンドウを画面中央の既定位置にリセット。
  • 中クリック：ウィンドウの「固定（ピン留め）」を切り替え。固定中はロゴが点灯します。

NOTE

クイックウィンドウが記憶する座標は、表示中のモニターに対する相対比率座標です。解像度や DPI スケーリングが異なる別のモニターに移動した際も、自動的に画面内に収まるよう比率計算されます。

インラインウィンドウおよびメインウィンドウでのロゴ ​

  • インラインウィンドウ：ファイルダイアログ（開く/保存/参照）に埋め込まれている場合、左クリックで クイックナビゲーション を表示。通常のエクスプローラーでは装飾表示のみです。ロゴをドラッグするとウィンドウ自体が移動し、そのオフセットは次回以降ドッキングするたびに再適用されます。ロゴを右クリックするとそのオフセットを捨てて、カードをこのホスト本来のドッキング位置に戻します。
  • メインウィンドウ：ロゴを左クリックするとコンテキストメニューを開きます。すでにメインウィンドウを開いているため、メニューではメインウィンドウを表示は非表示になります。中クリックでウィンドウの固定状態を切り替えます。右クリックすると、そのモニターの作業領域（タスクバーを除く）にウィンドウ全体を中央へ配置し直します。最大化中はまず元に戻してから配置します。

検索ボックスのマウス操作（クイックウィンドウ） ​

  • ボックス上でホイールを回す：過去の検索語を後ろ・前へ遡ります。Alt+Up / Alt+Down と同じ移動を、マウスから手を離さずにできます。
  • ボックスを中クリック：現在表示されている履歴項目を削除します。このジェスチャーは固定で、変更可能な Ctrl+Delete の割り当てとは別のものです。
  • いつでも文字を入力すると履歴セッションが終わるため、次のホイール操作は現在の検索語からやり直しになります。履歴はループしません。最も古い語で停止し、最も新しい語まで戻ると最初に始めていた検索語が返ります。

トレイアイコン ​

  • 左クリック：クイックウィンドウを表示/非表示します。呼び出しホットキーとまったく同じ動作です。
  • 右クリック（ダブルクリック用のハンドラがないため、2 回目のクリックでも開きます）：カーソル位置でメニューを開きます。内容はメインウィンドウの表示、他のデバイスへ送信（LocalSend が有効な間のみ）、ホットキーの有効化/無効化、設定、バージョン情報、クリーン終了（Lertaro だけが実行中のプロセスである場合のみ）、終了です。
  • トレイアイコンを隠す（設定 → 一般 → システム）を使うとアイコンは消えますが、ウィンドウ内ロゴのメニューまでは消えません。このメニューからホットキーを無効にしている間は、自分で閉じ出せないようアイコンが強制復帰します。

3. クイックナビゲーション（マウス操作） ​

キーボード入力を行わずに、マウス操作だけで頻繁に使うフォルダーや最近のファイルにアクセスできます。

設定 → ホットキー で、任意のグローバルキーボードショートカットを割り当てることもできます。デスクトップや通常のアプリではデスクトップのコンテキストでメニューを開き、エクスプローラーやネイティブのファイルダイアログではアクティブなウィンドウのコンテキストを使います。

呼び出し環境 ​

  • デスクトップの余白：中クリック（または左ダブルクリック）でメニューを開き、フォルダーやファイルをクリックして直接開く。
  • エクスプローラー：余白部分を中クリックして開き、クリックしたフォルダーへ現在のウィンドウが即座に移動。
  • 対応ファイラー：Directory Opus、Total Commander、XYplorer、Files、One Commander などのファイル一覧部分を中クリック（詳細は 対応ファイルマネージャー を参照）。
  • ファイルダイアログ：各種アプリの「開く/保存/フォルダーの参照」ダイアログ内で中クリックまたはロゴをクリック。対象フォルダーへ安全に移動します。

メニュー構成と管理 ​

次の 4 種類のグループは カスケードフォルダーブラウザー（Folder Cascader） プラグインが提供します：

  1. 現在開いているフォルダー：サポートされているすべてのファイラーで現在開かれているフォルダーを自動集約・重複排除して一覧表示。
  2. お気に入り・履歴：スター付きのお気に入りと最近のアクセス履歴を分類表示。
  3. カスタム階層フォルダー：設定 → プラグイン → カスケードフォルダーブラウザー で独自の階層メニューを作成可能（例: 仕事/プロジェクトA）。
  4. クイックフォルダー登録（+ ボタン）：メニューの各階層ヘッダーにある + ボタンをクリックするだけで、現在開いているフォルダーをそのカテゴリに直接追加可能。

4. 固定キー（変更不可） ​

直感的な操作の一貫性を保つため、以下のキー操作はすべての設定で固定されています。

← / → 方向キーアクションメニュー左キーで親メニューに戻り、右キーでサブメニューに入る。Tab でもサブメニューに入るが、次の項目/前の項目のホットキーに割り当てている場合はそちらが優先される。

Alt+F4メイン / 設定ウィンドウウィンドウを通常どおり閉じる。クイックウィンドウ・インラインウィンドウ・クイックパネル・プレビュー・LocalSend・アプリ内ダイアログでは無効化。

5. プラグインアクションとプロセスブラックリスト ​

プラグインアクションのホットキー ​

内蔵のファイル操作には次の既定キーが用意されています：切り取り Ctrl+X、ファイルのコピー Ctrl+C、貼り付け Ctrl+V、削除 Delete、完全削除 Shift+Delete、パスコピー Ctrl+Shift+C、名前をコピー Shift+C、エクスプローラーで表示 Ctrl+Enter、管理者として実行 Ctrl+Shift+Enter。

破壊的なキーを検索ボックスの下で安全に扱うため、2 つの歯止めを設けています。組み合わせキーがアクションに届くのは、検索ボックスにテキストが選択されていないときだけなので、Ctrl+X / Ctrl+C / Ctrl+V はこれまでどおり検索語の切り取り・コピー・貼り付けに使えます。Delete のような修飾キーなしのキーがアクションに届くのは、キャレットがすでに検索語の末尾にあるときだけです。そこでは削除すべき文字が残っていませんから、テキストのそれ以外の位置ではこのキーは入力用のキーのままです。さらに、どちらの削除アクションも Shell 自身の IFileOperation を通るため、キーとファイルの間にはネイティブの「ごみ箱へ移動しますか」/「完全に削除しますか」の確認が立ちはだかります。いずれも 設定 → ホットキー → プラグインアクション で再登録したりクリアしたりできます。

プロセスブラックリストと全画面自動バイパス ​

  • 全画面アプリの自動バイパス：フルスクリーンで動作する 3D ゲームや動画プレイヤーを検知すると、Lertaro は自動的にすべてのグローバルホットキーを通過させ、ゲームの操作を妨げません。
  • カスタムプロセスブラックリスト：設定 → ホットキー に特定のプロセス名（例: game.exe）を登録すると、そのアプリがフォアグラウンドにある間はホットキーを完全に無効化します。
