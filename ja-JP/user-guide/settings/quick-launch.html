クイック起動設定 ​

クイック起動は、検索ボックスが空のときにクイック検索ウィンドウの下に表示される起動パネルです。手動で管理する項目と、お気に入りや履歴など選択した動的データソースを組み合わせて表示します。

1. マスタースイッチ ​

  • クイック起動パネルを有効にする：パネルを有効にします。クイック検索ウィンドウの検索欄が空で、少なくとも1つのデータソースに利用可能なデータがある場合だけ表示されます。
  • ショートカットバッジを表示：表示中の各項目に割り当てられたキーボードショートカットを表示します。既定で有効で、バッジを非表示にしてもショートカットは無効になりません。
  • 無効にすると、パネルはデータソースを読み込みません。
  • パネルの高さは項目数が最も多いデータソースを基準に計算され、クイック検索ウィンドウの結果領域の最大高さを超えません。

2. 手動クイック起動項目 ​

設定 → クイック起動 → クイック起動を開くと、自分で登録した項目を管理できます。

  • ファイル、フォルダー、URL、Windows Shell パスを追加できます。対象の確認時には環境変数も展開されます。
  • 表示名は空欄にできます。空欄の場合、Lertaro が対象から名前を自動生成します。
  • ファイルとフォルダーの参照ボタンでは複数選択ができ、有効で重複しない対象がそれぞれ独立した項目として追加されます。
  • ドラッグハンドルで順序を変更できます。編集をクリックすると対象の行が保存・キャンセルボタン付きのインライン編集欄に変わり、削除ボタンで項目を削除できます。
  • 手動項目では、タイルにマウスを置いて省略記号ボタンをクリックするとメニューが開き、編集 または 削除 を選べます。編集 は項目エディターのダイアログを開きます。
  • 項目がある場合は、一覧見出しの右側にある一覧をクリアで手動項目を一括削除できます。項目がない場合、このボタンは非表示です。
  • 現在利用できない対象はパネルから一時的に除外され、再び利用可能になると表示されます。

3. データソース ​

設定 → クイック起動 → データソースを開くと、動的データソースを選択できます。

  • データソースはインストール済みのクイックパネルのタブプロバイダーから提供されます。そのため、お気に入り、履歴、Windows 履歴、前回のディレクトリ、最近使ったファイル、今後のプラグインソースを二重管理せずに再利用できます。
  • プロバイダーが存在するソースは既定で有効です。ユーザー設定には明示的に無効化したソースだけが保存されます。
  • 有効で、現在データを返すソースだけがパネルのタブになります。データのないソースは非表示です。
  • データソースの横にあるドラッグハンドルでパネルタブの順序を変更できます。順序はクイック起動設定に保存されます。
  • 手動項目と動的データソースのすべてにデータがない場合、クイック起動パネルは非表示になります。

4. パネルの操作 ​

  • 列数は検索バーの幅に合わせて変化します。
  • ソースが1つだけの場合、下部のソースインジケーターは非表示です。
  • 複数のソースがある場合、下部にソースごとのドットが1つ表示されます。選択中は青、未選択はグレーで、ドットにマウスを置くとソース名が展開表示されます。
  • パネル上で Shift を押しながらマウスホイールを回すとソースを順番に切り替えられ、切り替えたソースには同じ展開アニメーションが短時間表示されます。
  • 設定した 次の項目を選択 と 前の項目を選択 のホットキー（既定は Ctrl+N と Ctrl+P）でも、パネル表示中はソースを切り替えられます。末尾から先頭、先頭から末尾へ循環します。
  • 表示中の各項目は、設定した 選択ジャンプ 修飾キーと 1–9、0、A–Z の組み合わせで開けます。最初の項目は 1、10番目は 0、それ以降は A–Z となり、最大36項目にショートカットを割り当てられます。
  • パネル表示中は、方向キーで項目を見た目どおりのグリッドに沿って移動できます。← と → は読む順序で行の境界を越えて移動し、↑ と ↓ は現在の列を保ったまま隣接行間のみを移動し、対象行のその列に項目がなければ現在の位置に留まります。選択がほかのソースへ移ることも、循環することはありません。
  • どのソースの項目でも右クリックすると、クイック起動パネル内にその項目のフローティングアクションメニューが開きます。パネルは一時的にアクション一覧の最大作業高さまで広がり、メニューを閉じると元の高さに戻ります。メニューの外側をクリックすると閉じます。
  • パネル内の項目が表示領域に収まらない場合は、項目部分でマウスホイールを回して自由にスクロールできます。項目にマウスを置いてもスクロールは妨げられません。ショートカットバッジとその対象は、内容とともに移動します。
  • 検索語の入力を始めると、パネルは非表示になります。
