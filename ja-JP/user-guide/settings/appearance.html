外観とテーマ ​

Lertaro は、テーマモードの切り替えと複数のカラーパレットを提供します。外観設定は、設定センターの左サイドバー下部（「バージョン情報」の上）に配置されています。

1. テーマモード（Theme Modes） ​

画面上部に表示される 3 つのモードカードから選択できます。

  • ライトモード（Light）：明るいデザインに固定します。下のテーマ一覧にはライトスタイルのテーマのみが表示されます。
  • ダークモード（Dark）：落ち着いたダークデザインに固定します。下のテーマ一覧にはダークスタイルのテーマのみが表示されます。
  • システムに追従（Follow System）：Windows のライト/ダーク設定に応じて自動で切り替わります。このモードでは下のグリッドが ライトテーマ と ダークテーマ の 2 つに分かれ、昼と夜でそれぞれ配色を指定できます。Windows の設定変更に合わせて再起動なしでスムーズに切り替わります。

NOTE

Lertaro はライトモードとダークモードで選択したテーマを個別に記憶するため、モードを切り替えても選択内容が失われることはありません。

2. テーマ選択カード ​

テーマは実際の縮小プレビューカードで表示されます。検索ボックス、影、文字の視覚階層、選択ハイライトの配色が正確に再現されており、現在適用中のテーマにはチェックマークが付きます。

標準・同梱テーマ一覧 ​

  • コア内蔵テーマ（CoreExtensions）：
    • ライト（Light） / ダーク（Dark）：Windows のシステムスタイルに溶け込むシンプルなデザイン。
    • ノルディックブルー（Nordic Blue）：深いネイビーとアイスブルーが調和したクールなギークスタイル。
    • サクラピンク（Sakura Pink）：柔らかなパステルトーンの清潔感あるエレガントな配色。
    • サイバーパンク（Cyberpunk）：ネオンイエローとミッドナイトパープルの高コントラストな近未来デザイン。
  • アニメテーマ（AnimeThemes、同梱）：
    • エヴァンゲリオン（Evangelion）、桜の開花（Sakura Blossom）、天気の子（Weathering with You）。
  • キュレーションテーマペア（Curated Themes、同梱）：
    • ライト・ダークが対になった 20 組の配色：グレイシャー、テラコッタ、フォレスト、アメジスト、クリムゾン、グラファイト、インディゴ、ミント、シャンパン、アンバー、ロゼ、ティール、抹茶、モカ、オブシディアン、コーラルサンセット、ラベンダー、セージグリーン、パーチメント、コバルトブルー。

プラグインによるテーマの拡張 ​

すべてのテーマは Lertaro.PluginSdk の UI テーマ仕様に準拠しています。サードパーティ開発者は独自のテーマプラグインを作成して新しい配色を追加できます。
