お気に入り ​

お気に入り機能は、頻繁に使用するフォルダー、ファイル、スクリプト、Web サイトの URL を固定登録し、独自のカスタム名と最優先の検索順位を付与する機能です。設定は 設定 → お気に入り で行います。

1. お気に入りの追加 ​

画面上部の登録フォーム：

  • 表示名：任意のカスタムエイリアス（空欄の場合、対象がローカルパスであれば自動的にファイル名やフォルダー名が設定されます）。
  • 対象パス：ローカルの絶対パス、%USERPROFILE% などの環境変数、shell:Downloads などの Windows Shell 仮想パス、または http:// / https:// で始まる Web サイトの URL を入力できます。
  • 参照ボタン：フォルダーを参照 または ファイルを参照 をクリックして標準ダイアログから選択可能。
  • 追加ボタン：有効なパスを入力後、追加 をクリックして登録。

2. 一覧管理とドラッグによる並び替え ​

登録されたお気に入りは下部の一覧に表示され、柔軟に管理できます。

  • 6 点ドラッグハンドルによる並び替え：各行の左側にある 6 点ハンドルをドラッグ＆ドロップして順序を変更できます。また、右側の 上へ移動 / 下へ移動 ボタンでも調整可能です。ここでの順序は検索結果やクイックナビゲーションでの表示順に直接反映されます。
  • その場で編集：編集をクリックすると対象の行がそのまま編集欄に変わり、行内で保存またはキャンセルできます。上部の追加フォームは再利用しません。
  • 削除：お気に入りから安全に削除します。
  • 一覧をクリア：一覧に項目がある場合、一覧見出しの右側にあるボタンですべてのお気に入りを一括削除できます。一覧が空の場合、このボタンは非表示です。

検索結果のアクションメニューから、存在するファイルまたはフォルダーを 1 件だけお気に入りに追加することもできます。Lertaro は表示名を入力するダイアログを開き、同じパスが登録済みの場合はこのアクションを表示しません。

3. 検索での呼び出しと表示 ​

  • スターマーク（★）：検索結果にお気に入り項目が含まれる場合、パスの横に目立つ ★ マークが表示されます。
  • カスタムエイリアス検索：深い階層にあるファイルに覚えやすい名前を付けることができます（例: D:\Workspace\2026\Q1\Financial\Summary.xlsx に 第1四半期財務 と命名）。検索ボックスでその名前を入力するだけで呼び出せます。
  • 複数機能との連携：登録したお気に入りは、クイックナビゲーション メニューや クイックパネル の「お気に入り」タブに自動的に反映されます。
