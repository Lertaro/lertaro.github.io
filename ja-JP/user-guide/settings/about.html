バージョン情報と更新 ​

バージョン情報画面では、Lertaro の稼働環境に関する完全なバージョン情報、各種データディレクトリへのアクセスリンク、およびオンラインでの更新確認・自動アップデート機能を提供します。設定画面は 設定 → バージョン情報 です。

1. コンポーネントバージョンと概要 ​

画面上部には、Lertaro を構成する 4 大コンポーネントのバージョン番号が表示されます。

  • App バージョン：フロントエンド WPF UI のバージョン。
  • Core バージョン：検索・インデックス処理コアライブラリのバージョン。
  • Service バージョン：バックグラウンド Windows サービスのバージョン（文字色が現在の接続健全性を動的に反映）。
  • CLI バージョン：コマンドラインツール lff のバージョン。

下部には、公式サイト、GitHub リポジトリ、およびオンラインドキュメントへのリンクが配置されています。

2. データディレクトリと 5 世代バックアップローテーション ​

エクスプローラーで直接開くことができる 2 つのリンクが用意されています（フォルダーが存在しない場合は自動作成されます）：

ユーザーデータディレクトリ ​

  • 保存内容：ユーザー設定（user-settings.json, plugin-settings.json）、検索・キーワード履歴、ユーザーキャッシュ、セキュリティ証明書。
  • 5 世代バックアップローテーション：設定保存時、既存の設定ファイルが user-settings.json.bak.1 へとローテーションされ、最大 .bak.5 まで自動保持されます。誤設定やクラッシュ時も直近 5 回分のバックアップから即座に復元可能です。

マシンデータディレクトリ ​

  • 保存内容：マシン全体の設定（machine-settings.json）、永続化された物理インデックスキャッシュ、バックグラウンドサービスのログ。

ディレクトリの配置構成 ​

  • インストーラー版：ユーザーデータは %LocalAppData%\Lertaro、マシンデータは %ProgramData%\Lertaro に保存されます。
  • ポータブル版：実行ファイルと同階層の Data\Users\<SID hash> および Data\Machine に保存され、システムディレクトリからは完全に分離されています（詳細は ポータブル版のデータ分離 を参照）。

データディレクトリの移設（シンボリックリンクとジャンクション） ​

  • 対応しています：ユーザーデータディレクトリ（インストーラー版は %LocalAppData%\Lertaro、ポータブル版は <インストール先>\Data\Users）は、シンボリックリンクまたはジャンクションで別のローカルパーティションや別のローカルディスクへ移設できます。起動時に Lertaro がそのリンクの連鎖を実体のディレクトリへ解決し、以降はその実体を読み書きします。
  • ローカルの固定ディスクのみ：リンク先はローカルの固定ボリュームである必要があります。ネットワーク上の場所やリムーバブルボリュームを指すリンクは、起動時に理由を示して明確に拒否します（別の場所へ黙って書き込むことはありません）。
  • データディレクトリより下のリンクは引き続き一律に拒否：データディレクトリ内部のサブディレクトリはリンクにできません。動作中に差し替えられたリンクは書き込み先を転送してしまうためです。これはセキュリティ境界であり、設定項目ではありません。

3. 更新の確認と自動アップデート ​

  • 更新を確認：オンラインで新しいリリースを問い合わせ、結果をボタン上に表示します（「更新を確認中...」 → 「最新バージョンです」または新バージョンの案内）。
  • 新バージョン検出時の適用方法：
    • サイレント自動更新 —— バックグラウンドで新バージョンをダウンロードして自動置換し、完了後に再起動します。
    • ダウンロードページへ移動 —— ブラウザーで GitHub Releases を開き、手動でパッケージを取得します。
  • 権限に関するガイダンス：標準ユーザー権限でサービスの停止・更新が制限されている場合、手動ダウンロードを案内する通知が表示されます。

4. プラグイン設定と設定バックアップ ​

ネイティブパラメーターは user-settings.json と同じ場所の plugin-settings.json に保存され、各ファイルに最大五世代のバックアップを保持します。旧埋め込みパラメーターは一度だけ移行します。完全な設定 ZIP は両ファイル、カレンダーデータ、Flow 設定を含みます。実行可能な Flow プラグインファイルは明示的な選択が必要です。現在のプラグイン設定を移す際は主設定ファイルだけをコピーしないでください。

同期ソフトがバックアップ先を一時的に使用している場合、復旧可能な転送エラーでは現在の設定を維持してアプリを開きます。実行ロックはポータブル版でも同期データの外にある %LocalAppData%\Lertaro\RuntimeLocks に置きます。ロールバックが完了しない場合、部分的に復元された設定でプラグインを起動しません。
