クイックパネル設定 ​

クイックパネル（Quick Panel） は、頻繁に使用するファイルの呼び出し、プロジェクトのコンテキスト管理、デスクトップ上でのドラッグ＆ドロップ操作のために設計されたフローティングワークスペースです。ホットキーを押すとアクティブウィンドウの右下に吸着表示され、作業中の画面を離れずにファイルを参照・整理できます。

1. コア機能とメインスイッチ ​

  • クイックパネルを有効化：全体の有効化スイッチ。無効にするとホットキーは反応しなくなります。
  • 呼び出しホットキー：既定は Ctrl+F2（設定 → ホットキー で変更可能）。
  • スマートドッキングとサイズ制御：親ウィンドウの幅・高さのそれぞれ 1/2 のサイズで表示されます（視認性と操作性を保つため最小サイズは 280 × 200px に制限）。Lertaro のウィンドウがアクティブな場合は誤動作防止のためホットキーは無視され、パネルが開いている状態で同じホットキーを押すと閉じます。

2. ワークスペース（Workspaces） ​

プロジェクトやタスクごとにフォルダーの組み合わせを整理できます。

  • ワークスペース管理：左側の一覧で 新規作成、複製、削除 を行え、ドラッグでタブバー上の表示順序を並び替えられます。
  • プロパティ：
    • 名前：タブに表示されるテキスト（空欄の場合は言語設定に応じた既定名になります）。
    • 有効スイッチ：タブバーに表示するかどうかを制御します。パネル上でタブの × ボタンを押して非表示にした場合も、ここで再度有効化できます。

選択したワークスペースは、右側の ソース と アプリケーション の 2 つのタブで設定します。

3. ソース設定（Sources） ​

ワークスペース内の独立したフォルダーグループを定義します。

  • フォルダーを追加：対象となる物理ディレクトリを選択します。
  • 表示モード（Display Mode）：
    • 最近変更されたファイル —— インメモリインデックスからミリ秒未満で最近更新されたファイルを抽出（新しい順）。
    • すべてのコンテンツ —— すべてのファイルを表示し、更新日時の降順または名前で並べ替えられます（名前順は定番ファイルのショートカットバーとして利用できます）。
    • フォルダーのみ —— ディレクトリだけを一覧表示。
    • ファイルのみ —— ファイルだけを一覧表示。
  • サブフォルダーを含める：配下のファイルを再帰的に含めます。
  • ドロップされたファイルを受け入れる：有効にすると、外部からファイルやフォルダー、Web 画像をこのグループにドラッグ＆ドロップしてコピーできます（Windows 標準のコピー機能を使用し、衝突確認や取り消しに対応）。
  • フィルタールール：ワイルドカードまたは検索構文の @ フィルターで表示する拡張子を限定（例: *.mp4;*.mkv、*.lnk;:@doc;:@img、*.lnk;:@doc|img）。
  • 最大表示件数と時間制限：表示件数の上限（0 で無制限）や、N 分以内に更新されたファイルのみに絞り込む設定。
  • 詳細リスト vs サムネイルタイル：グループごとにリスト表示かグリッドタイル表示かを選択可能（タイルは縦横比を維持したまま均等に拡大縮小）。

4. プラグイン動的タブ（Plugin Tabs） ​

プラグインが提供する動的リストをクイックパネルに表示できます。CoreExtensions には 5 つの標準タブが含まれています。

プラグインタブ内容
お気に入りスターを付けた登録アイテム（URL はブラウザーで開きます）。
履歴Lertaro 経由で開いた最近のアイテムやアプリ。
Windows 履歴Windows の「最近使った項目」を実ファイルとして展開。
前回のフォルダーエクスプローラーやダイアログで直前に開いていたフォルダーを追跡。
最近のファイルインデックスを利用して設定済みフォルダー内の最新ファイルを一覧表示。

各タブの有効/無効や、リスト/タイルの初期表示形式を個別に設定できます。

5. アプリ連携と専用ブラックリスト ​

  • アプリケーション連携（Applications）：特定のプロセス名（例: chrome.exe や devenv.exe）を登録すると、そのアプリ上でクイックパネルを呼び出した際に該当するワークスペースが自動で開きます。
  • クイックパネル専用ブラックリスト：パネルの表示を抑制したいアプリを登録します。グローバルブラックリストに上乗せして適用されます。

6. パネルの操作ガイド ​

  • リアルタイムあいまい絞り込み：右上の検索ボックスであいまい一致とピンイン検索による絞り込みが可能。絞り込むのは名前だけで、一覧の並び順が変わることはありません。項目がすべて外れたグループは表示されなくなりますが、タブは残ります。Escape はまず絞り込みをクリアし、2 回目の Escape ではじめてパネルが閉じます。
  • キーボードナビゲーション：上下キーでグループをまたいで選択移動し、Enter で実行するとパネルは開いたままです。この移動はループしません。最初と最後に見えている項目が明確な終点となり、空のグループは飛ばされ、まだ何も選択していない状態では ↑ / ↓ のどちらも先頭項目に移動します。タイル表示では 4 つの矢印キーが見た目のグリッド上を動きます。← / → は読む順序で行の境界をまたぎ、↑ / ↓ は列を維持します。
  • タブ切り替え：Ctrl + 1–9 で各タブ間をすばやく切り替え。
  • QuickLook プレビューとピン留め：項目を選択して Alt+P でプレビューを表示、Ctrl+T またはヘッダーのピンボタンでフォーカス喪失時も閉じないように固定。
  • フォーカスの行先：呼び出すとキャレットは絞り込みボックスに入り、先頭の項目がすでに選択された状態になります。そのまま入力して絞り込めます。ボックスがフォーカスを持っている間、プラグインのアクションホットキーは意図的に身を引きます。ここでは Ctrl+A と Ctrl+C はファイル操作ではなくテキスト編集を意味します。
  • アクションフライアウト：右クリックを離したとき（押したときではない）に、メインウィンドウと同じアクションフライアウトがカーソル位置に開きます。未選択の行を右クリックすれば、その行に対して作用します。フライアウトはそのあと ↑ ↓ ← →、Enter、Space、Escape を受け持ちます。キーハンドラをパネルにぶら下げる形になっているため、フライアウトが開いている間は、通常ならパネルを閉じるところの外側クリックが無視されます。
  • 行に対するマウス操作：左ダブルクリックで開きます。右ダブルクリックはフライアウトを開き直すだけで、起動することはありません。中クリックでプレビューを開閉し、行にホバーすると選択が動きます。
  • パネルの移動：ポインターがヘッダーに近づくとドラッグ用の帯が表示され、そこをドラッグするとパネルが移動します。ドラッグ中でもパネルは閉じられません（エクスプローラーからのドラッグアウトがパネル内に落ちるのはそのためです）。
  • 外側をクリックしたとき：フォーカスが離れて約 200 ms 後にパネルは隠れます。ただし、パネルをドラッグしていたとき、ピン留めされているとき、アクションフライアウトが開いているとき、そしてパネルが開いたプレビューがフォアグラウンドを保っているときは立ち退きません。自分のプレビュー側をクリックするのは、外側をクリックしたことには当たりません。
  • 選択の編集：グループ内の余白をクリックすると、Ctrl や Shift を押していない限りすべてのグループの選択が同時に解除されます。ラバーバンドのドラッグは自分のグループ内でのみ選択し、Ctrl を併用すれば追加選択になります。あるグループで始めたドラッグは別のグループへ届くことはありません。
  • ファイルのドロップを受け入れる：Lertaro の内で始まったドラッグは受け付けられません。途中でやめたドラッグアウトが余計なコピーになることはないということです。クリックアウトでパネルが閉じるため、エクスプローラーからファイルをドラッグインできるのはパネルがピン留めされている間だけです。ドロップは常にコピーとなり、移動になることはありません。
  • グループヘッダー：ヘッダーの名前、パス、ルールの行をクリックするとグループの折りたたみと展開が切り替わります。ソートと表示はその横にある別々のボタンです。並び替え・表示モード・折りたたみ状態はセッション単位で、タブの順序とタブを閉じた操作は永続します。
