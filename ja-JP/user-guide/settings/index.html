設定項目リファレンス ​

Lertaro は、柔軟で詳細なカスタマイズオプションを提供します。検索バーのピクセル単位のサイズ調整から、グローバルホットキーの設定、ドライブごとのインデックス周期の調整、サードパーティ製プラグインやワークスペースの管理まで、すべてを設定センターから行えます。

1. ウィンドウ機能と操作性 ​

  • 自由なリサイズと最大化：設定ウィンドウは境界線をドラッグしてのサイズ変更や、タイトルバーのダブルクリックによる最大化に対応しています。
  • 設定全体のあいまい検索：設定ウィンドウのタイトルバー中央にある検索ボックスから、すべての設定項目を検索できます。検索にはメイン検索と同じ fzf あいまい一致エンジンが使用され、プラグイン設定やアクション項目もカバーします。結果を選択すると該当する設定ページへジャンプし、対象の項目が点滅ハイライト表示されます。
  • スクロール可能なタブバー：複数のサブタブを持つセクション（一般、ホットキー、インデックスなど）では、言語によって文字幅が長くなっても左右のスクロール矢印によりすべてのタブにアクセスできます。

2. 設定セクション一覧 ​

左側のサイドバーには以下の主要な設定セクションが配置されています。

セクション主な設定内容
サービス状態Windows バックグラウンドサービスの状態監視、および Service / App / Hook プロセスのリアルタイムログビューアー。
インデックス管理ローカルドライブ（NTFS / ReFS / FAT32）、ネットワーク共有（SMB / NAS）、WSL ディストリビューション、個別フォルダー、除外・優先度ルール。
一般設定自動起動、ハードウェアアクセラレーション、IPC 互換サービス、検索バーのサイズ調整、テーブル列の並び替え、プレビュー設定。
ホットキーグローバルホットキー、ナビゲーションキー、プラグインアクションのショートカット、プロセスブラックリスト、全画面アプリの除外。
プラグインインストール済みプラグイン一覧、コンポーネントごとの有効/無効化、設定フォーム、Flow Launcher コミュニティプラグインの管理、実行状態の確認。
LocalSendLocalSend 公式クライアント互換の LAN 内ファイル/テキスト転送設定（デバイス名、ポート、PIN 認証、自動保存）。
お気に入りよく使うフォルダー、ファイル、Web サイトの登録、並び替え、ピンイン検索。
検索履歴検索結果の実行履歴と入力キーワード履歴の管理、優先表示、履歴のクリア。
クイック起動手動のクイック起動項目を管理し、空のクイック検索ウィンドウに表示する動的データソースを選択します。
クイックパネルアクティブウィンドウに吸着するフローティングワークスペース、フォルダーの集約表示、ドラッグ＆ドロップ登録、プラグイン動的タブ。
外観とテーマライト / ダーク / システム連動モードの切り替え、標準および付属テーマのリアルタイム縮小プレビューカード。
バージョン情報各コンポーネントのバージョン、ユーザー/マシンのデータディレクトリへの直接アクセス、バックアップローテーション、自動更新。

以降の各ページでは、セクションごとの詳細な設定項目、設定範囲、既定の動作について順を追って解説します。
