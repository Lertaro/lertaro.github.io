クイックスタート ​

Lertaro へようこそ！Lertaro は、Windows 向けのファイル検索＆生産性向上ランチャーです。このガイドでは、インストール方法、コアアーキテクチャ、3 つのウィンドウ形態、および基本的な検索操作について説明します。

1. ダウンロードとインストール ​

公式サイトのトップページから最新バージョンを入手できます。各リリースでは、ネイティブ x64 および ARM64 アプリケーション用のインストーラー版とポータブル版が提供されます。

インストーラー版（Lertaro-Setup.exe、推奨） ​

  • 自動セットアップ：インストールウィザードは必要な .NET Desktop Runtime の検出とインストールを自動的に行います。バックグラウンドインデックスサービスの登録とスタートアップ登録は、Lertaro を初めて起動したときにアプリ自身が行います。
  • 上書きアップデート：バックグラウンドでの自動更新チェックとワンクリックでの上書きアップデートに対応しています。

ポータブル版（Lertaro-Portable.zip） ​

  • 解凍してすぐ実行：任意のフォルダーに解凍するだけで直接実行でき、インストールは不要です。
  • ランタイムの追加：システムに必要な .NET Desktop Runtime が未導入の場合は、解凍先にある install-dotnet-runtime.bat を実行してインストールしてください。
  • データの分離と自己完結：ポータブル版は、マシン全体の設定をアプリと同じディレクトリの Data\Machine に、ユーザーごとの個別設定を Data\Users\<SID hash> に保存します。Data ディレクトリが未作成の場合は互換性のためにシステムの %ProgramData%\Lertaro や %LocalAppData%\Lertaro を参照しますが、一度フォルダーが作成されると完全に自己完結したポータブル環境として動作します。
  • サービスのインストール時にフォルダーを保護：バックグラウンドサービスをインストールすると（UAC の確認を 1 回承認します）、ポータブル版のフォルダーが保護されます。アプリケーションファイルを変更できるのは管理者のみとなり、Data\Machine はサービスだけが書き込み、各ユーザーの Data\Users\<SID ハッシュ> フォルダーはそのユーザー専用になります。そのため、ポータブル版の更新や削除には管理者権限が必要です。portable-cleanup.bat は自動で管理者権限を要求します。
  • 完全なクリーンアップ：ポータブル版が不要になった場合は、フォルダーを削除する前に同梱の portable-cleanup.bat を実行してください。バックグラウンドサービスを停止・削除し、ユーザーの lertaro:// URI プロトコルやスタートアップ登録をクリーンに削除します。

TIP

Surface Pro X や Snapdragon 搭載ノート PC などの Windows on ARM デバイスをご利用の場合は、ネイティブの Lertaro-Setup-arm64.exe または Lertaro-Portable-arm64.zip をダウンロードすることで、最高のパフォーマンスと省電力性を得られます。

2. コアアーキテクチャの概要 ​

Lertaro を初めて起動すると、専用の Windows バックグラウンドサービス（サービス名 LertaroService、実行ファイル Lertaro.Service.exe）が自動的にインストールされ起動します。この設計を理解しておくと、より快適に使いこなせます。

  • フォアグラウンド App（UI・対話層）：検索ウィンドウ、フローティングパネル、アクションメニュー、キーフック、プレビューの描画を担当します。メモリ消費を低く抑え、常にミリ秒未満の即時応答性を維持します。
  • バックグラウンド Service（インデックス・データ層）：システムサービス権限で常駐し、NTFS / ReFS の USN 変更ジャーナルの監視、その他のファイルシステムのリアルタイム変更の検知、ネットワーク共有インデックスの管理、インメモリ検索ツリーの構築を行います。
  • アーキテクチャの利点：UI の再起動や更新を行ってもバックグラウンドのインデックスが失われたり全スキャンが再実行されたりすることはありません。また、大容量ディスクのインデックス処理が UI の快適なタイピングを妨げることもありません。設定 → サービス状態 でいつでも稼働状況を確認できます。

3. 3 つのウィンドウ形態 ​

Lertaro には、ワークフローに応じた 3 つのウィンドウ形態が用意されています。

ウィンドウ形態既定の呼び出し方法主な特徴と設計コンセプト最適な利用シーン
クイックウィンドウ（Quick Window）Ctrl キーの 2 回連打（変更可能）画面中央に素早く現れるコンパクトなポップアップ。数字キーによるダイレクト選択や完全なキーボード操作に対応アプリの高速起動、特定ファイルの即時検索、計算機や翻訳の利用
メインウィンドウ（Full Window）タスクバー/スタートメニュー、または Ctrl+F大画面のフル機能ウィンドウ。膨大な結果のテーブル表示、サイドバーフィルター、列ソート、内蔵ストレージ分析機能に対応ファイル探索、大容量ディスクの整理、高度な条件絞り込み
インラインウィンドウ（Inline Window）ファイルダイアログやファイラーの中で英数字を入力（エクスプローラーではドッキング）Windows 標準のダイアログや対応ファイラーに直接組み込まれ、作業中の画面を離れずに検索可能。キーボードを奪うことはなく、ダイアログ自身の欄へそのまま入力を続けられます。Ctrl の 2 回連打（設定済みの呼び出しホットキー）でキャレットをインラインウィンドウへ動かしますアプリの「開く」「名前を付けて保存」画面で目的のフォルダーやファイルを即座に指定

3 つのウィンドウ形態は、まったく同一の検索エンジン、ショートカット体系、フィルター規則、アクションメニューを共有しています。

4. 初めての検索と基本操作 ​

入力して即座に検索 ​

検索ウィンドウを開いたら、キーボードからそのまま文字を入力するだけです。ミリ秒単位の即時性で結果がリアルタイムに表示されます。検索アルゴリズムは既定であいまい一致を採用しており、連続していない文字飛びでも正確にヒットします。詳しくは 検索構文 をご覧ください。

結果の選択と起動 ​

  • 項目の移動：方向キー ↑ / ↓（または設定されたナビゲーションキー Ctrl+P / Ctrl+N）で一覧の選択項目を上下に移動します。
  • 直接開く：Enter キーを押して、選択したファイルを開くかアプリケーションを起動します。
  • エクスプローラーで表示：Ctrl+Enter を押すと、エクスプローラーが開き対象ファイルが選択された状態で表示されます。
  • 管理者として実行：Ctrl+Shift+Enter を押すと、管理者権限で実行します。
  • 数字キーによる直接起動：クイックウィンドウでは、Ctrl + 1〜9 を押すことで上位 9 件の結果を直接開くことができます。

アクションメニューと拡張操作 ​

選択中の項目で Ctrl+O または方向キー → を押すと、アクションメニュー が開き、パスのコピー、プロパティ確認、ファイル操作、プラグイン拡張コマンドなどを実行できます。この 2 つのキーはクイックウィンドウ（およびファイルダイアログ外のインラインウィンドウ）のもので、メインウィンドウでは代わりに右クリックまたは Apps キーを使ってください。詳しくは アクションとプレビュー および ホットキー を参照してください。
