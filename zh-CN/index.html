三进程隔离架构与运行模型

严格划分特权边界，确保系统级检索性能与前台 UI 的极致稳定性

SYSTEM 服务Lertaro.Service

以 LocalSystem 权限常驻后台，直接读取 NTFS / ReFS 底层 USN Journal 与 $MFT，监听 FAT32 / exFAT 变动，并通过命名管道提供高性能只读数据检索。

用户态前台Lertaro.App

标准用户 Session 桌面程序，承载快速搜索居中浮窗、完整主窗口、设置中心、动作菜单以及插件管理，不持有任何多余系统特权。

窗口与钩子Lertaro.Service --hook

独立特权辅助进程，托管低级全局键盘与鼠标监听，突破 Windows UIPI 权限隔离以无缝嵌入管理员权限对话框，同时隔离异常崩溃风险。

常见问题与解答

针对架构设计、系统服务与使用模式的核心技术解答

Q

为什么需要安装后台 Windows 服务？

后台服务以 LocalSystem 权限直接读取 NTFS/ReFS 磁盘底层的 USN Journal，无需用户在前台频繁弹窗赋予管理员权限，既保证了全盘变更监听的高性能，又避免了让前台 UI 进程持有不必要的系统高特权。

Q

Lertaro 与 Everything、Listary 的主要区别与定位是什么？

Lertaro 专注于像 Listary 一样深度挂载文件对话框与即时模糊查找，同时具备 Everything 级别的底层 USN 秒级索引性能，并提供现代 .NET 10 开放插件生态与即时磁盘空间分析。

Q

便携版（Portable）与安装版（Installer）有什么区别？

安装版会自动注册并管理后台索引服务，适合长期作为系统主力检索工具；便携版完全免安装解压即用，若需要后台全盘索引服务也可在设置中心一键按需注册与卸载。

Q

检索数据会上传到云端或产生网络遥测吗？

完全不会。Lertaro 为 100% 本地纯离线运行工具，不包含任何后台遥测、数据统计上报或强制云端连接，严格保障本地隐私安全。
