动作菜单与即时预览 ​

Lertaro 既能定位文件，也集成了上下文操作体系与即时预览面板，让你无需频繁打开文件资源管理器即可完成文件的查看、管理与分发。

1. 动作菜单详解 ​

在快速窗口中，于高亮结果上按下 Ctrl+O 或方向键 →，即可展开该项目的上下文动作菜单；其中 → 只在光标已位于搜索内容末尾时才生效，因此你在文本前部编辑时它绝不会抢占光标移动。同样的按键在文件对话框之外的内嵌卡片上照常有效；停靠在打开/保存/浏览对话框中的卡片则完全没有动作菜单。完整搜索窗口里这两个键都没有绑定：在该窗口中右键点击结果，或按 Apps（Shift+F10），即可为该项目打开同一个动作菜单。

并非每一行都配有动作菜单。展示更多行、插件提供的结果、网址类收藏、没有任何提供器认领的即时结果、快速窗口之外的应用程序，以及所有文件对话框，都不提供动作菜单；在这些行上按菜单按键只会毫无反应，而不会弹出空面板。

内置核心动作速查 ​

动作名称默认快捷键功能说明
打开Enter使用系统默认关联程序打开选中的文件或启动应用程序。在完整搜索窗口中，Enter 会作用于全部选中行；双击只作用于被双击的那一行。
在资源管理器中定位Ctrl+Enter打开文件所在目录，并在资源管理器中直接选中该文件。
以管理员身份运行Ctrl+Shift+Enter以管理员权限启动选中的程序（支持可执行文件、快捷方式、批处理脚本等）。
复制完整路径Ctrl+Shift+C将文件的绝对路径（如 D:\Projects\app.exe）复制到剪贴板。
复制名称Shift+C将选中文件或文件夹的名称复制到剪贴板，不含路径。
复制文件Ctrl+C将文件本身放入剪贴板，可直接在资源管理器或其他目录中粘贴。
剪切 / 复制文件Ctrl+X / Ctrl+C将文件本身放入剪贴板，可直接在资源管理器或其他目录中粘贴。在搜索框中选中了文本时，它们仍然是文本编辑命令。
粘贴到文件夹Ctrl+V高亮的是文件夹时，把剪贴板里的文件直接粘贴进该目录；高亮的是文件时，粘贴到其所在目录。它要求剪贴板中是真正的文件列表，因此把文本粘贴回搜索框不受影响。
删除（移入回收站）Delete将选中的文件或文件夹安全移至 Windows 回收站。单独按键只有在光标已位于搜索内容末尾时才会触发动作，之后还会跟着原生的回收站确认框。
彻底删除Shift+Delete永久删除选中的文件或文件夹（先弹出原生的“彻底删除？”确认框，此后便无法恢复）。
重命名—通过 Windows Shell 重命名单个已存在的文件或文件夹，对话框会预先选中文件名主体。
打开 Windows 右键菜单—展开原生的 Windows 资源管理器完整上下文菜单（包含第三方软件扩展和发送到子菜单）。

动作菜单交互与即时过滤 ​

  • 即输即过滤：展开动作菜单后，直接打字即可按动作名称快速过滤（例如输入 copy 即刻定位到所有复制相关操作）。过滤框会接管键盘，因此切换离开时绝不会动到你原来的搜索词。
  • 助记字母：每个动作都可能显示一个高亮字母。按下它会立即执行该动作而不只是高亮它，但仅在过滤框仍为空时生效，所以你为了过滤而输入的第一个字母绝不会被抢走。
  • 独立搜索框：动作菜单拥有独立且打开后自动获得焦点的搜索框，过滤动作不会改变主搜索词。切换菜单层级时会清空动作过滤词，并让新层级的搜索框获得焦点。
  • 浮动动作面板：快速窗口、快速启动面板和完整搜索窗口中的动作都会以悬浮面板显示，并锚定在当前项目附近。快速启动面板会临时扩展到动作列表的完整工作高度，关闭动作菜单后恢复紧凑高度。
  • 层级导航：在带有子菜单的条目（如“发送到”或级联动作）上按下 →、Tab 或 Enter 进入下一级；按 ← 或在过滤词为空时按 Backspace 返回上一级。在嵌套菜单中按 Escape 或点击鼠标右键会返回上一级；在根层级则关闭动作菜单。
  • 导航按键依旧有效：你配置的上/下一项快捷键（默认 Ctrl+N / Ctrl+P）在动作列表内同样能移动高亮，会越过首项和末项循环，并跳过分隔线、标题与不可用的动作。只有在你没有把 Tab 绑定成这些导航键之一时，Tab 才用于进入子菜单。
  • 点击空白处关闭：点击浮动动作面板之外的区域会关闭面板。宿主支持时，在动作面板打开期间右键点击其他结果会就地替换当前动作目标。
  • 动作快捷键：动作面板获得焦点后即可使用提供器定义的动作快捷键。执行后会关闭浮动面板，但完整搜索窗口或快速启动面板仍保持打开。

2. 完整搜索窗口的结果列表交互 ​

主搜索窗口（Ctrl+F）专为海量文件管理与多维度浏览设计：

  • 双击路径列定位：双击结果列表中的文件名称为直接打开文件；双击路径列则会自动打开该文件所在的父级文件夹。双击只指左键；双击列标题不会有任何反应，最大化/还原要双击窗口顶部的非输入区域。
  • 多选：表格视图就是一个普通的 Windows 列表：Ctrl+单击可加入或移出若干行，Shift+单击选取一个连续区间，随后 Enter 会一次性作用于全部选中行，双击则只作用于被双击的那一行。在已属于选区的行上点击右键会保留整个选区，而不是收缩为那一个行。
  • 无限流式结果加载：在搜索大容量磁盘或数百万条目时，结果会随后台索引引擎的检索实时流式呈现在列表中，无需等待全盘扫描完毕即可随时点击或选中操作；追加新行会保留你的选中项与滚动位置，只有真正全新的结果集才回到顶部重新开始。
  • 键盘循环导航：在结果第一行按 ↑ 可直接跳转到末尾行，在最后一行按 ↓ 可回到首行。快速窗口和内嵌卡片同样循环，尚未选中任何行时按 ↑ 落在最后一行、按 ↓ 落在第一行。唯有快速面板会把各分组串成一条连续列表遍历，且不循环。
  • 横向滚动：在表格上按住 Shift 滚动鼠标滚轮，每格横向滚动三列，窗口较窄时就是这样够到最远的列的。
  • 拖出文件：任何一行都可以作为真正的文件拖放直接拖进资源管理器、对话框或聊天窗口；处于多选状态时拖动其中一行会把全部选中项一起带出。在 Lertaro 之外放下会隐藏窗口，而拖放进行中会暂缓关闭，因此拖拽光标不会粘住。
  • 选择数量摘要：选中多个结果时，状态栏会在结果总数旁显示当前选中的项目数量。
  • 悬停预览：指针划过某一行时，已经打开的预览面板会改而预览这一行，选中项保持不变，于是你可以逐个翻看候选，再回到中意的那一行按 Enter。
  • 窗口无边框拖拽与尺寸记忆：主窗口顶部非输入区域可作为拖拽抓取条，鼠标指针悬停时会有提示条淡入；手动调整的窗口宽高会自动记忆并在下次启动时沿用。

3. QuickLook 即时预览机制 ​

在可预览的结果上按下 Alt+P，即可在搜索窗口旁呼出停靠的即时预览面板，或对该行点击鼠标中键，两者切换的是同一个面板。这两种手势在内嵌窗口中都不可用；快速面板两者都支持。

预览面板不接收键盘输入 ​

面板刻意做成不激活窗口：它绝不会从搜索窗口夺走焦点，因此没有任何可供输入的地方，Escape 也不会关闭它。开关它请用 Alt+P，或者关闭它所停靠的那个窗口。它的所有控件——媒体播放条、滚动条、插件卡片——都只认鼠标，键盘焦点会原地不动。

多格式预览支持 ​

  • 图片：支持 JPG、PNG、GIF、BMP、ICO 图像格式的缩放呈现。
  • 文本与代码：以等宽字体直接呈现 TXT、Markdown、JSON、XML、YAML、C#、Python、JS、HTML 等文本内容（不做语法高亮）。
  • 音视频即时播放：MP4、M4V、WMV、AVI、MOV、MPG/MPEG 视频与 MP3、WAV、WMA、M4A、AAC 音频在预览面板打开时会自动开始播放，并配备自适应主题的迷你控制条（播放/暂停、拖动进度、实时时长、静音控制），切换选中项时立即停止。
  • 文件夹结构透视：选中文件夹时，预览面板会自动列出其前 30 个直接子项目并显示文件图标与大小，自动过滤系统和隐藏文件。

细节设计与避让机制 ​

  • 尺寸与边界自适应：预览窗口的尺寸可在设置 → 通用 → 预览窗口中自定义，系统会自动确保预览窗口不会超出当前显示器的可视工作区。
  • 停靠方位：面板停靠在所属搜索窗口的右侧，只有右侧放不下时才翻到左边，它不会追着更宽敞的一侧跑，因此你在宽窗口里滚动时它会安在原地。之后移动或缩放宿主窗口，它都会跟随。
  • 尺寸记忆仅限本次会话：只要预览还在使用，拖动调整手柄改变尺寸或移动面板都会被记住；但搜索窗口下次被隐藏或关闭之后，面板就会回到设定的尺寸与停靠方位。
  • 原生弹窗自动避让：当预览 Office 加密文档弹出输入密码对话框时，Lertaro 会自动临时隐藏快速窗口与预览面板，待密码输入完成或弹窗关闭后自动恢复。
  • 预览窗口拖拽源：预览面板顶部可作为拖拽源，直接将正在预览的文件拖入编辑器、浏览器或外部聊天软件中。底部栏拖动的则是面板本身。

4. 插件交互式与富文本预览 ​

QuickLook 除了本地文件预览，还开放了插件交互扩展能力：

  • 自适应深浅色富文本：基于 WebView2 与原生组件渲染，自动适配系统的深色/浅色主题，并注入高对比度字体与半透明细滚动条。
  • 丰富的插件卡片：支持词典释义卡片、即时天气、网页即时快照、API 调试信息等复杂交互式面板。

5. 第三方独立 QuickLook 桥接（可选） ​

如果你已在系统中安装了独立的第三方开源工具 QuickLook（GitHub 上的 QL-Win/QuickLook），可以在设置 → 插件中启用内置的 QuickLook 桥接 插件。

  • 接管预览：该插件会通过本地命名管道连接独立的 QuickLook 进程，并将外部预览窗口自动吸附在 Lertaro 旁。
  • 自动回退：若第三方 QuickLook 进程未运行或已关闭，Lertaro 会回退至内置的原生预览面板。

6. 解除文件占用 ​

官方的文件占用解除插件为已存在的文件提供单选动作。它会列出当前正在使用该文件的进程、PID 和可执行文件路径，并请求这些进程释放文件。选择文件夹、文件不存在或同时选择多个项目时，该动作不可用；未检测到占用进程时，请求释放按钮也会禁用。窗口使用宿主主题，并在对话框模式下保持在搜索窗口上方且不出现在 Alt+Tab 切换列表中，同时提供刷新功能。

7. 添加到收藏夹 ​

CoreExtensions 提供添加到收藏夹动作，适用于单个已存在的文件或文件夹。该动作会打开主题化对话框让你填写显示名称；如果相同路径已经是收藏项，动作会隐藏。

8. 重命名 ​

CoreExtensions 提供重命名动作，适用于单个已存在的文件或文件夹。主题化对话框会显示完整的当前名称并预先选中文件名主体：例如 report.pdf 只选中 report，文件夹和没有扩展名的名称会全选。按 Enter 确认，按 Esc 取消。确认后由 Windows Shell 执行实际重命名。
