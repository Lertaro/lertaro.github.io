用户手册 ​

欢迎查阅 Lertaro 官方用户手册！Lertaro 是一款为 Windows 定制的文件检索与生产力启动器。通过在后台维护高效的内存索引树（NTFS / ReFS 基于底层 USN 变更日志，其他文件系统基于实时事件监听），实现千万级文件的毫秒级检索响应。

  • 快速上手 —— 安装与便携版使用、App 与 Service 架构职责、三种窗口形态（快速窗口 / 主窗口 / 内嵌窗口）及基础操作。
  • 搜索语法 —— 模糊匹配、修饰符（! 排除、' 精确、^ 前缀、$ 后缀、| 或条件）、盘符定向、路径模式与拼音别名匹配。
  • 快捷键与交互手势 —— 全局快捷键速查表、搜索框 Logo 鼠标拖动与重置手势、鼠标快速导航级联菜单与核心固定按键。
  • 动作菜单与即时预览 —— 结果上下文动作面板（Ctrl+O）、主窗口结果交互、内置 QuickLook 音视频/文档预览与插件富文本卡片。
  • 空间分析 —— 零磁盘 I/O 的 Treemap 矩形树状图与体积降序列表，便于定位大文件。
  • 即时解答与关键词功能 —— 始终生效的计算器、环境变量与运行命令，以及进程管理（ps）、窗口切换（win）、浏览器书签（bb）、浏览器历史（bh）、设置直达（set）等关键词插件。
  • 命令行搜索（lff） —— 终端环境下的交互式模糊查找伴侣工具，共享内存索引，支持管道传参与 Shell 脚本联动。
  • URI 协议（lertaro://） —— 外部超链接、快捷方式与脚本直达搜索、设置分区及 LocalSend 传输。
  • 支持的文件管理器 —— Windows 原生文件对话框、Directory Opus、Total Commander、XYplorer、Files 等工具的内嵌与快速导航集成。
  • 设置项参考 —— 运行状态、索引管理、通用选项、外观主题、快捷键绑定、插件配置等各项设置详细说明。
  • 故障排查 —— 全局快捷键失灵、索引未更新、输入法候选框及日志查看排查指南。
  • 捐赠与支持 —— 支持 Lertaro 的持续迭代与开源维护。
