插件管理 ​

Lertaro 采用模块化的插件架构。从核心扩展组件、本地工具到社区第三方生态，都可以在插件管理中心中统一查看、管理与配置。页面路径为设置 → 插件。

1. 页面布局与 SDK 版本 ​

  • Plugin SDK 徽标：页面右上角标注了当前运行时加载的 Lertaro.PluginSdk 版本号。点击该徽标可直接跳转至开发者手册查阅接口文档。
  • 左右双栏独立滚动：左侧展示已安装的所有插件列表，右侧展示当前选中插件的详细信息与配置面板，两侧独立滚动互不干扰。

2. 插件详情与组件开关 ​

点击左侧列表中的任意插件后，右侧会展示该插件的图标、名称、版本号与功能简介：

详情标签页（Details） ​

  • 组件清单与分组：列出该插件注册的所有底层功能组件（例如：搜索源、右键动作、快速导航提供者、即时预览解析器等）。
  • 组件级独立开关：每个非必要组件均配有独立的启用/禁用复选框；带有锁形图标的组件为系统级必要核心，不可关闭。
  • 一键全选/全不选：当某个组件分组包含多个可切换项目时，标题右侧会提供“全选/全不选”链接。
  • 组件悬停说明：鼠标悬停在组件旁边的 (!) 图标上，可查看该组件的底层实现说明与触发方式。

配置标签页（Configure） ​

  • 原生嵌入式表单：插件自定义的配置项会直接渲染在右侧面板中，无需弹出额外的对话框。支持文本框、数字调节、开关、下拉选择及多分组子标签页。
  • 图标输入字段：使用 Schema 键 Icon 的文本框会显示图标预览，并支持 WPF Path Data。粘贴完整 SVG/XML 文档时会自动提取并合并其中的路径数据；无效的图标内容会被清空，并通过主题化对话框提示。
  • 多行配置编辑器：StringList 字段在展开后的编辑器中支持自动折行；真实换行会显示浅色 ↵ 标记，标记仅用于视觉区分，不会保存到配置值或复制内容中。
  • 安全提交与回滚机制：在保存之前，任何修改均仅暂存于内存中；切换至其他插件或离开页面时，已修改的内容会继续保留，不会丢失，方便你对比多个插件的配置。点击设置窗口底部的应用或确定会统一保存所有改动过的插件配置；点击取消（或直接关闭窗口）则还原为上次保存的参数。

系统设置搜索 ​

启用系统设置搜索插件后，可以按 Windows 提供的本地化关键字搜索控制面板任务。例如，env 可找到环境变量入口，无需手工维护别名。每个查询词都必须匹配标题或关键字中某个词的开头；关键字随 Windows 版本和系统语言变化。

CoreExtensions 搜索类型过滤器 ​

在设置 → 插件 → CoreExtensions → 配置 → 搜索过滤器中，可以管理完整搜索窗口左侧显示的类型过滤器。文件和文件夹始终可用，文档、图片和视频过滤器可以分别关闭。

自定义侧栏过滤器列表可以添加带有显示名称、可选 WPF Path Data 图标和通配符规则的过滤器。名称为空或规则展开后为空的项目会隐藏，图标留空时使用默认图标。名称仅用于显示，不能作为 @ 引用。@ 引用只在“过滤规则”字段中生效：@关键字 会展开已有自定义过滤器列表中匹配的关键字，即使该过滤器未启用也可以引用。引用会递归展开并去除重复模式；不存在或循环引用不会生成匹配规则。

CoreExtensions 内联搜索窗口 ​

在设置 → 插件 → CoreExtensions → 配置 → 资源管理器内联窗口中，可以关闭内联窗口显示快捷命令。内联窗口是唯一会把插件快捷命令（如「快捷命令」分组）排在文件结果之前、并被默认选中的地方，因此回车执行的是命令而不是打开匹配到的文件；关闭后内联搜索只针对文件。快速窗口与主窗口不受影响。

浏览器书签与历史记录 ​

浏览器书签与历史记录插件可以搜索已配置的 Chromium 系浏览器和 Firefox 浏览器配置目录。默认触发关键字分别为书签的 bb 和历史记录的 bh；你可以在插件配置中修改这两个关键字，也可以分别关闭书签或历史记录索引。

黑名单字段每行填写一个字面字符串。当书签或历史记录的标题或网址包含任一规则时，该条目会被隐藏；匹配不区分大小写，且不会进行模糊匹配。规则同时作用于书签和历史记录，并会在插件重新加载缓存数据后生效。

如果浏览器本地数据库中存在匹配的网站图标，插件会以只读方式读取并将其显示在结果中，不会复制数据库文件。读取不到网站图标时，则依次使用配置的浏览器图标，以及默认的书签或历史记录图标。

3. Flow Launcher 社区生态支持 ​

除了基于 Lertaro.PluginSdk 构建的原生 C# 插件之外，Lertaro 还通过内置的 Flow Launcher Bridge 提供了对 Flow Launcher 社区插件生态的兼容支持。

多语言运行时与隔离环境 ​

  • 全类型插件兼容：可运行由 C# (.NET)、Python 3.12、Node.js v20 LTS 以及独立可执行程序（.exe）编写的 Flow Launcher 插件。
  • 零依赖污染与自包含运行时：Python（FlowData\PythonEmbeded-{arch}）与 Node.js（FlowData\NodeEmbeded-{arch}）运行时完全隔离在 Lertaro 的用户数据目录中按需自动下载部署，不依赖且绝不污染 Windows 系统的全局环境变量与 PATH。
  • 依赖自动安装：插件首次加载时，系统会在后台静默根据 requirements.txt 安装 Python pip 依赖，或根据 package.json 执行 npm 依赖安装。

在线社区市场与包管理指令 ​

你可以直接在 Lertaro 搜索框中键入以下指令管理 Flow 插件：

  • flow install <关键词>：实时在线检索 Flow.Launcher 官方社区插件库，选中后一键自动下载、解压、部署并拉起依赖安装。
  • flow update：自动检测所有已安装 Flow 插件的更新版本并支持一键升级。
  • flow uninstall <插件名>：一键安全卸载指定的 Flow 插件并清理相关本地目录。
  • 手动安装：亦可将下载好的第三方 Flow 插件文件夹直接放入 <用户数据目录>\FlowData\Plugins\ 完成本地离线安装。

插件配置、触发词与交互式预览 ​

  • 集中管理与触发词修改：在设置 → 插件 → Flow Launcher Bridge → 配置中，可为每个 Flow 插件单独开关，并自由修改其专属触发词（ActionKeyword）。配置集中持久化在 FlowData\Settings\Plugins.json 中，插件更新后配置不丢失。
  • 动态配置表单：完整支持 Flow 插件基于 YAML/JSON 模板表单（SettingsTemplate.yaml/.json）或 C# WPF 设置面板（ISettingProvider）的配置界面，自动融合当前深浅色主题并支持 i18n 本地化。
  • WebView2 交互式富文本预览：支持 Flow 插件返回的复杂预览面板（如 MDict 词典释义、天气卡片、API 调试信息、网页快照等），在 QuickLook 中免额外按键平滑展开；Lertaro 会自动注入深浅色自适应样式、清晰字体与细滚动条。
  • 宿主能力集成：Flow 插件通过 API 打开文件夹时自动遵循宿主配置的第三方文件管理器，弹窗消息框自动渲染为宿主主题自绘样式，且内部日志汇入设置中心日志查看器。
  • 快捷总览：在搜索框中直接输入 flow 即可列出当前已加载的所有 Flow 插件及其触发词；选中插件后会直接跳转到设置中的对应配置分组。

4. 音频设备选择器 ​

音频设备选择器是一个仅支持 Windows 的原生插件。输入 ad 可列出当前活动的播放和输入设备，选择设备后会将其设为对应的默认多媒体设备；也可以在触发词后附加设备名称来筛选结果。

插件设置支持修改触发词，并选择结果显示友好名称、设备名称或设备描述。它可以切换默认播放或输入端点，但不负责音量、静音或单应用音频路由。

5. 内容搜索 ​

内容搜索插件可以搜索配置的本地文档正文。打开它的配置标签页，可以设置触发关键字、监测文件夹、索引后缀、单个文件大小上限、索引体积上限以及排除完整路径的正则表达式。默认触发关键字为 cs，因此输入 cs 项目计划 即可搜索文档正文，并显示带片段的匹配文件。

配置中还提供清空索引与重建索引。清空索引只删除内容索引，重建索引则会删除内容索引并重新扫描所有监测文件夹。这两个操作都不会删除 Lertaro 的普通文件名索引。

6. 插件运行状态 ​

在设置 → 插件 → 运行状态中，可以查看 Lertaro 运行期间已安装插件的宿主侧调用情况。数据按插件汇总，并在该标签页打开时持续刷新。

  • 插件筛选：使用筛选框按插件名称进行模糊搜索。
  • 列排序：点击列头可依次切换升序、降序和默认插件顺序。
  • 可用指标：调用次数、平均耗时、最近耗时、最大耗时、托管分配量和观测到的异常次数。
  • 统计范围：统计在当前 Lertaro 进程运行期间累计，重启后重置。数值为零表示尚未记录到对应的调用；托管分配量是被测调用产生的托管内存分配，不代表插件的全部私有内存占用。
