收藏夹 ​

收藏夹用于将你最高频使用的文件夹、文件、脚本或网页 URL 固定下来，赋予专属的自定义名称与最高检索优先级。设置页面路径为设置 → 收藏夹。

1. 添加收藏项目 ​

在页面上方的添加表单中：

  • 显示名称：自定义名称（可选）。若留空且目标为本地路径，系统会自动使用目标文件或文件夹的文件名作为默认名称。
  • 目标路径：支持输入本地文件/目录的绝对路径、%USERPROFILE% 等环境变量、shell:Downloads 等 Windows Shell 虚拟路径，或以 http:// / https:// 开头的完整网页网址。
  • 浏览选择：点击浏览文件夹或浏览文件按钮可直接调用原生文件选择器，免去手动输入路径的繁琐。
  • 添加：填入有效路径后点击添加按钮即可将该项存入收藏列表。

2. 列表管理与拖拽排序 ​

下方列表集中展示所有已添加的收藏项，支持细致的排序与维护：

  • 六点拖拽手柄排序：每一行左侧均配有六点拖拽手柄，你可以按住手柄直接上下拖动调整条目顺序，亦可点击右侧的向上移动 / 向下移动按钮微调。这里的排列顺序直接决定了该收藏项在搜索结果与快速导航菜单中的先后次序。
  • 就地编辑：点击编辑后，当前行会直接变成编辑器，可在该行保存或取消，不会复用上方的添加表单。
  • 删除此项：从收藏夹中安全移除该条目。
  • 清空列表：列表有内容时，可以使用列表标题右侧的按钮一次移除所有收藏项；列表为空时该按钮会隐藏。

你也可以在搜索结果的动作菜单中，将单个已存在的文件或文件夹直接添加到收藏夹。Lertaro 会弹出对话框让你填写显示名称；如果相同路径已经收藏，该动作不会显示。

3. 搜索召回与视觉呈现 ​

  • 专属星标徽标（★）：在快速窗口或主搜索窗口中检索到收藏项时，结果旁会显示醒目的 ★ 星标徽标。
  • 自定义别名搜索：你可以为复杂的路径起一个简短好记的显示名称（例如将 D:\Workspace\2026\Q1\Financial\Summary.xlsx 命名为 财务总表）。在搜索框中输入 cwzb 即可通过拼音别名召回该文件。
  • 多端聚合呈现：所有收藏项会自动同步呈现在鼠标快速导航菜单与快速面板的“收藏夹”标签中，点击即可打开。
