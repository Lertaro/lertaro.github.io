运行状态 ​

运行状态页面集中监控 Lertaro 核心后台服务的生命周期健康度，并内置了面向 Service、App 与 Hook 三大核心进程的高性能实时日志查看器。页面路径为设置 → 运行状态。

1. 服务状态与控制 ​

页面顶部展示后台提权索引服务的运行状态卡片：

  • 实时状态显示：
    • 就绪（Ready）：服务运行健康，实时呈现当前已索引的物理文件与文件夹总条目数。
    • 索引中（Indexing）：正在执行初始构建或全量增量更新，显示动态进度指示器。
    • 安装中（Installing）：正在注册并部署 Windows 后台服务。
    • 错误（Error）：服务未运行或遇到异常中断，显示醒目的警告标记与错误描述。
  • 服务自愈与安装按钮：当且仅当后台服务尚未安装或由于系统权限受损进入异常状态时，页面会提供安装并启动服务按钮；在服务健康运行期间，系统会维持后台持续常驻，避免误操作导致索引中断。

2. 三进程实时日志查看器 ​

页面下方提供了内置日志终端，分为三个独立的标签页，分别对应 Lertaro 运行的三大进程：

  • App 标签页：记录前台 WPF 用户界面、搜索交互、快捷键响应与窗口渲染相关的操作日志。
  • Hook 标签页：记录低级全局键盘钩子独立进程（Lertaro.Service.exe --hook）的按键捕获与进程隔离状态。
  • Service 标签页：记录提权 Windows 后台服务（Lertaro.Service.exe）的 USN 日志解析、磁盘遍历、内存树构建与 IPC 通信日志。

过滤与日志清理功能 ​

  • 日志等级过滤：下拉框支持筛选“全部 / 错误 / 警告 / 信息 / 调试”，日志行按严重等级自动呈现不同的颜色标记。
  • 实时搜索过滤：在搜索框中输入关键词可对当前日志内容进行全文过滤，并与等级过滤条件叠加生效。
  • 安全清空日志：点击清空日志按钮可清理当前标签页的历史日志输出。清理 Service 日志时会自动通过提权服务代理安全截断，无需手动提升管理员权限。
