关于与更新 ​

关于页面提供了 Lertaro 当前运行环境的完整版本信息、用户与系统数据存储目录的快速直达入口，以及在线检查更新与一键升级功能。页面路径为设置 → 关于。

1. 组件版本与项目信息 ​

页面顶部展示了 Lertaro 架构体系中四大核心组件的独立版本号：

  • App 版本：前台 WPF 用户交互界面版本。
  • Core 版本：核心搜索与索引计算逻辑库版本。
  • Service 版本：后台 Windows 索引服务版本（其文字颜色会动态反映服务当前是否处于健康连接状态）。
  • CLI 版本：命令行终端交互工具 lff 的版本。

下方提供了项目官方网站、GitHub 开源仓库以及在线文档中心的直达链接。

2. 数据目录与自动备份轮转机制 ​

页面中央提供了两个直接可点击打开物理路径的超链接（若目标文件夹尚未生成，点击时会自动创建）：

用户数据目录（User Data Directory） ​

  • 存储内容：存放当前 Windows 用户的个人配置文件 user-settings.json、搜索与关键字历史记录、用户专属缓存及证书。
  • 五级备份轮转保护机制：每次在设置中心点击保存或修改配置时，Lertaro 会自动将现有配置文件顺延轮转备份为 user-settings.json.bak.1，旧的备份依次向后推移至 user-settings.json.bak.5。即使发生断电、误改或系统崩溃，也能随时在数据目录中找到最近 5 次的历史备份进行恢复。

机器数据目录（Machine Data Directory） ​

  • 存储内容：存放后台提权服务使用的机器级配置文件 machine-settings.json、全盘物理索引持久化缓存以及服务端日志。

存储路径规则 ​

  • 安装版：用户数据存放于 %LocalAppData%\Lertaro，机器数据存放于 %ProgramData%\Lertaro。
  • 便携版：用户数据存放于程序目录下的 Data\Users\<SID hash>，机器数据存放于 Data\Machine，与系统目录完全隔离（详见便携版使用说明）。

3. 检查更新与一键升级 ​

  • 检查更新按钮：点击后手动发起在线版本检测。按钮文字会动态反馈检查状态（“正在检查更新...” → “已是最新版本” 或弹出新版本更新卡片）。
  • 发现新版本时的升级方式：
    • 静默自动更新 —— 在后台自动下载新版本安装包并就地覆盖升级，升级完成后自动重启拉起 Lertaro。
    • 前往下载页面 —— 在默认浏览器中打开 GitHub Releases 发布页面，供手动下载便携压缩包或安装程序。
  • 权限安全提示：若当前运行在受限的标准用户账户下，且无法直接停用后台 Windows 服务完成就地更新，页面会呈现安全提示，并引导你前往官方页面下载安装。
