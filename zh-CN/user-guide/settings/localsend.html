LocalSend 局域网传输设置 ​

Lertaro 内置了与官方开源 LocalSend 协议原生兼容的局域网无线传输引擎。无需依赖外部互联网或数据线，即可在同一局域网下的 Windows 电脑、Mac、Linux、iPhone、iPad 以及 Android 手机之间互传文件、文件夹与纯文本。设置页面路径为设置 → LocalSend。

1. 基础服务设置 ​

  • 启用 LocalSend 局域网传输：总开关。开启后，Lertaro 会在后台启动轻量级传输监听服务，并在系统托盘菜单中激活“发送到其他设备...”功能项。
  • 设备名称：本机在局域网多播广播中向其他设备展示的别名。默认根据计算机名称自动生成，你可以随时修改为一个更具辨识度的名称（例如 工作笔记本）。
  • 服务端口：HTTP / HTTPS 传输监听端口（遵循 LocalSend 官方标准，默认为 53317）。若本地该端口被其他服务占用，可在此自定义更改。

2. 安全加密与存储规则 ​

  • 加密传输 (HTTPS)：默认开启。启用后设备间的数据往来均采用 TLS 加密传输，防止局域网抓包窥探。
  • 接收 PIN 码：可设置 PIN 码（留空则不启用验证）。设置后，其他设备向你发起传输请求时必须在发送端输入匹配的 PIN 码方可建立连接。
  • 自动保存文件：开启后，接收来自局域网设备的传输请求将自动确认并下载落盘，无需每次手动点击弹窗确认。
  • 保存目录：设置接收到的文件与文件夹默认保存的物理目标路径（默认为系统的“下载”文件夹），点击右侧浏览按钮可随时更改。

3. 发送窗口与快捷调用 ​

  • 快捷键唤起：可在全局任何界面按下默认快捷键 Ctrl+S（可在设置 → 快捷键中重新绑定）唤起 LocalSend 独立发送窗口。
  • 发送模式切换：发送窗口顶部支持在 [发送文件 / 文件夹] 与 [发送文本] 两种模式之间一键切换。
  • 即时拖拽分发：支持直接从 Lertaro 搜索结果列表、快速面板或文件资源管理器中将多个文件或整个项目目录拖入发送窗口，雷达扫描会自动列出局域网内当前在线的所有设备，点击目标设备头像即可全速发送。
