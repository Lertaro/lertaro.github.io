即时解答与关键词扩展功能 ​

除了本地文件检索之外，Lertaro 还内置了一系列即时计算、系统工具与关键词扩展插件。无需等待文件检索，输入对应指令即可即刻得到答案或触发对应功能。

1. 始终生效的即时解答 ​

无需输入任何前缀关键词，只要输入的文本匹配特定模式即可立即触发：

计算器与进制转换 ​

直接在搜索框中输入数学表达式，计算结果将在第一行实时呈现。按下 Enter 键即可将计算结果复制到剪贴板：

text
12 * (4 + 3)
100 * (1 - 0.15)

支持常见的进制转换表达：

text
255 to hex
0xFF to dec
101010 to bin

环境变量展开与查询 ​

  • 精准展开变量：输入 %NAME%（如 %PATH%、%APPDATA%）可直接查看变量值。对于包含多个路径的变量（如 PATH），Lertaro 会自动将其拆分为清晰的逐行列表，便于检查环境配置。
  • 模糊搜索变量：输入 % 加上关键词（如 %temp）可模糊搜索所有名称中包含该关键词的系统与用户环境变量。

快捷运行命令 ​

无需先打开终端窗口，直接在搜索框中输入：

  • #<命令>：打开命令行窗口并以管理员权限执行该命令（例如 #sfc /scannow 或 #net start LertaroService）。
  • $<命令>：打开命令行窗口以当前普通用户权限执行该命令（例如 $ping 1.1.1.1 或 $ipconfig /all）。

网址直达 ​

直接输入或粘贴以 http:// 或 https:// 开头的完整网址，按下 Enter 即可立即在默认浏览器中打开该页面。输入合法的无协议网址（例如 example.com）时，快速搜索窗口会直接生成两条即时结果：https://... 和 http://...。无协议识别只针对一份硬编码的常见顶级域名白名单（一百多个后缀，如 .com、.cn、.io，并支持 xn-- 国际化域名），不可设置；常见文件扩展名被刻意排除在外，其余输入仍按文件名检索，例如 abc.txt 不会生成网址结果，确需打开其他后缀的网址时请连同协议一起输入。每条结果都采用两行式的浏览器打开文案，搜索框内容不会被修改；已经包含协议的网址则只生成一条结果。

快速搜索窗口导入剪贴板文本 ​

在设置 → 通用 → 快速搜索窗口 → 自动将剪贴板文本填入快速搜索框（默认关闭）开启后，快速搜索窗口在没有预填内容的情况下被呼出时，如果剪贴板文本不为空且不同于该窗口上一次导入的剪贴板内容，就会自动填入并全选文本。相同内容不会重复导入，从 URI 或完整搜索窗口返回时的预填内容也不会被覆盖。

2. 关键词触发功能（内置插件） ​

通过输入简短的触发关键词 + 空格，再输入实际查询内容，即可调用专项插件能力。各关键词均可在设置 → 插件中自定义修改。

分隔符可以是半角空格、全角空格或制表符；触发关键词本身不参与文件名匹配，也不会被高亮。当两个功能使用同一个关键词时，插件配置页会在该字段下方以黄色提示占用它的是谁，但不会阻止保存。

默认关键词插件名称功能说明与使用场景典型使用示例
ps进程管理按进程名、PID 或窗口标题搜索运行中的进程（支持拼音），回车一键结束进程。ps chrome 或 ps 1234
win窗口切换器搜索并即时切换到当前打开的应用窗口，支持后台实时抓取窗口缩略图。win code 或 win 微信
bb浏览器书签搜索 Chrome、Edge、Firefox 等浏览器的书签。bb github
bh浏览器历史搜索 Chrome、Edge、Firefox 等浏览器的历史访问记录。bh github
set设置搜索模糊搜索 Lertaro 自身的所有设置选项，选中即可直接跳转到对应设置页并高亮该项。set 快捷键 或 set 模糊
flowFlow 插件桥接列出所有已加载的 Flow.Launcher 插件及其触发词，支持调用 Flow 社区生态。flow
cs内容搜索搜索已建立索引的本地文档正文，并返回带片段的匹配文件。cs 项目计划

3. 网页搜索快捷引擎 ​

网页搜索插件内置了主流搜索引擎快捷方式，输入对应前缀并跟随关键词即可一键拉起浏览器搜索：

快捷词对应搜索引擎示例说明
bd百度 (Baidu)bd 深度学习在百度中搜索关键词
g谷歌 (Google)g lertaro github在 Google 中搜索关键词
bing必应 (Bing)bing 微软文档在 Bing 中搜索关键词
ghGitHubgh Lertaro直接在 GitHub 仓库中搜索
wiki维基百科 (Wikipedia)wiki 量子力学在维基百科中查阅词条
ytYouTubeyt lofi hip hop在 YouTube 中搜索视频

你可以在设置 → 插件 → 网页搜索 → 配置中自由新增、修改或删除搜索引擎与自定义 URL 模板。

4. 即时翻译 ​

输入默认触发词 tr 并在其后输入待翻译的内容，即可自动翻译为 Lertaro 当前所选的界面语言：

text
tr Hello, how are you today?
  • 翻译结果随输入异步呈现，按 Enter 键即可一键复制译文。
  • 可在设置 → 插件 → 翻译 → 配置中更改触发词或查看联网状态。

5. 文件过滤器 ​

在设置 → 插件 → 文件过滤器 → 配置中，你可以为触发关键字绑定特定目录，让普通搜索可以限定在这些目录内：

  • 范围文件夹列表：一行一个路径（如 D:\Engineering\Drawings），也支持环境变量（如 %TEMP%）与系统虚拟路径（如 shell:Downloads），无法解析为真实文件夹的条目会被跳过。搜索结果来自文件索引，因此文件夹需被索引覆盖（已启用索引的本地盘，或在设置 → 索引 → 文件夹中添加，支持网络共享路径）；未被索引覆盖的文件夹会被跳过并记录警告日志。
  • 匹配规则：文件名通配模式（如 *.dwg;*.dxf，文件夹始终保留）。
  • 触发关键字：绑定前缀（如 cad）后，在快捷搜索框输入 cad 零件图 即可只在绑定的文件夹内执行常规索引检索（按文件名模糊匹配，含拼音别名）；仅输入关键字时会提示继续输入。

6. 自定义命令 ​

在设置 → 插件 → 自定义命令 → 配置中，你可以将任意复杂的命令行工具、脚本或外部应用包装为一个简短的启动命令：

  • 参数占位符：支持位置占位符 %s1、%s2……（对应以空格分隔的参数）以及全文占位符 %s（代表关键词后的所有输入文本）。
  • 快速导航集成：勾选“在快速导航中显示”后，该命令会直接作为菜单项出现在快速导航中，支持使用 / 创建多级子菜单分类（如 开发工具/重启服务）。
