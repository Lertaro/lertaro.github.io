本頁目錄

索引管理 ​

索引設定頁面用於精細化控制 Lertaro 針對本機硬碟、網路儲存、WSL 子系統以及自訂資料夾的索引範圍、重新整理策略與排除規則。頁面頂部包含五個索引標籤頁：本機磁碟機、網路磁碟機、WSL（偵測到發行版時自動顯示）、資料夾與排除規則。

1. 本機磁碟機（Local Drives） ​

  • 頂部彙總狀態：展示目前已索引的實體磁碟機數量與總檔案/資料夾項目數，並提供重建索引按鈕觸發所有本機磁碟的全量重建。
  • 磁碟機清單行：每個實體磁碟分割獨立顯示一行：
    • 啟用/停用核取方塊：獨立開關該磁碟的索引。
    • 檔案系統與狀態：顯示底層檔案系統類型（NTFS、ReFS、FAT32、exFAT 等）、目前狀態與已索引項目數。
    • 單盤操作：每行提供獨立的重建與移除操作；在重建掃描進行時會動態提供停止按鈕。
  • 即時監控機制：NTFS 與 ReFS 卷透過 Windows 系統的 USN 變更記錄檔實現毫秒級增量同步；FAT32 與 exFAT 卷透過檔案系統即時變更事件監聽。
  • 重建不中斷：在某個磁碟重建期間，舊索引將繼續回應使用者的搜尋查詢，直到新索引建置完成後一次替換，期間搜尋不會中斷。若重建過程被系統重啟或手動停止中斷，下次會自動從斷點繼續。

2. 網路磁碟機（Network Drives） ​

  • 網路儲存支援：展示所有已連線的 Windows 網路共用磁碟（SMB / NAS）。
  • 重新整理模式（Refresh Mode）：網路儲存缺乏本機 USN 記錄檔，因此支援自訂排程輪詢策略：
    • 手動 —— 僅在按一下「重建索引」時重新掃描。
    • 每 15 分鐘 —— 高頻協同辦公目錄推薦。
    • 每小時 —— 均衡型定時掃描。
    • 每天 —— 靜態封存共用推薦。
  • 符號連結環路保護：掃描引擎內建了分支祖先路徑堆疊與符號連結循環偵測演算法，即使 NAS 共用中存在指向父級目錄的軟連結或重新分析點，也能自動攔截死循環，確保索引數量準確不膨脹。

3. WSL（Linux 子系統） ​

當且僅當系統偵測到至少安裝了一個 WSL 發行版時，本索引標籤頁會自動出現：

  • 自動探測：自動識別 Ubuntu、Debian、Arch 等已安裝的 WSL 發行版。
  • 狀態與重新整理：提供與網路磁碟機完全一致的狀態監控與重新整理模式設定（手動 / 每 15 分鐘 / 每小時 / 每天）。
  • 零 I/O 搜尋：搜尋 WSL 檔案時直接查詢記憶體索引樹，完全不喚醒或封鎖 Linux 子系統。

4. 資料夾（Folders） ​

當你不希望索引整個磁碟機或整台 NAS 伺服器，而只想精準收錄特定工作目錄時，可以使用自訂資料夾索引：

  • 多選新增：按一下新增資料夾按鈕開啟原生選取器，支援按住 Ctrl 或 Shift 一次性批次選取新增多個目錄。
  • UNC 路徑支援：支援直接新增類似 \\server\share\projects 的區域網路 UNC 共用目錄。
  • 獨立排程重新整理：每個資料夾均擁有獨立的啟用開關、項目計數與重新整理模式下拉式方塊（手動 / 每 15 分鐘 / 每小時 / 每天）。

5. 排除規則（Exclusions） ​

排除規則用於過濾搜尋結果，並限定網路儲存、WSL 與自訂資料夾的走查範圍；它不會停止本機磁碟的索引——本機磁碟區始終整盤走查，所以在這裡寫 E:\ 只會隱藏它的結果。要停掉某塊本機磁碟的索引，請在上方本機磁碟機索引標籤裡關閉它。規則是一張統一清單，沒有子索引標籤：每條規則由比對方式與等級組成，比對方式依寫法自動判定，輸入框會即時顯示「辨識為」。

  • 完整路徑：以磁碟機代號（D:\Cache）、UNC（\\server\share）、環境變數（%ProgramData%、%APPDATA%）或 shell: 虛擬路徑開頭，遮蔽該目錄及其全部子項。
  • 萬用字元：其餘寫法一律按萬用字元處理。* 比對單層目錄內的任意字元（*.log），? 比對單一字元，** 跨層級遞迴（**\node_modules\**）。不含分隔符的規則依名稱命中任意層級（node_modules、*.tmp）；含分隔符的規則從磁碟機代號根錨定——Listary\abc 命中 C:\Listary\abc 及其子項，但不會命中 D:\work\Listary\abc。
  • 正規表示式：兩端用 / 包住，對完整路徑或檔案名稱做隱式部分比對，例如 /^\./ 排除 Linux 式隱藏點檔案，/~\$/ 排除 Office 產生的臨時鎖定檔案。能用萬用字元就別寫正規表示式：每次比對都要解釋執行，更費資源。

等級決定怎麼處理：排除完全不顯示，低／正常／高只影響先後，高優先規則還能勾選置頂，把命中行釘在結果最前。等級有兩種寫法：行右側的下拉式選單，或文字前綴 ! 排除、- 低、+ 高，不寫是正常；行首加一個反斜槓可把前綴當普通字元。

NOTE

前綴只在新增輸入框與批次編輯裡剝掉。行內編輯既有規則時文字按字面處理，改等級請用下拉式選單：把 ! 寫進萬用字元規則，它就成了路徑裡的字面字元，而 Windows 路徑不含 !，於是這條規則永遠命中不了任何東西，頁面上也不會報錯。

本機磁碟在搜尋時才套用規則；網路磁碟、WSL 與自訂資料夾在建立索引時就跳過排除項目，套用設定後會自動更新。優先順序規則被排除規則涵蓋時，清單上方出現衝突橫幅，被涵蓋的規則不會生效。

TIP

排除規則支援單筆新增與批次匯入匯出：按一下從列表生成可把現有規則匯出為多行文字，編輯後按一下套用到列表即可一次性批次生效。批次文字裡只要有一行無法辨識，整批都不會套用，文字會留在框裡等你修改。
