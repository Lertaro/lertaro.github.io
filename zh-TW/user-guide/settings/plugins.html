外掛模組管理 ​

Lertaro 採用模組化的外掛模組架構。從核心擴充元件、本機工具到社群第三方生態，都可以在外掛模組管理中心中統一檢視、管理與設定。頁面路徑為設定 → 外掛模組。

1. 頁面配置與 SDK 版本 ​

  • Plugin SDK 徽標：頁面右上角標註了目前執行階段載入的 Lertaro.PluginSdk 版本號。按一下該徽標可直接跳轉至開發者手冊查閱介面文件。
  • 左右雙欄獨立捲動：左側展示已安裝的所有外掛模組清單，右側展示目前選取外掛模組的詳細資訊與設定面板，兩側獨立捲動互不干擾。

外掛啟用狀態與重新啟動 ​

關閉全部可切換元件等同停用整個外掛。可以連續修改多個外掛，按套用儲存後繼續編輯。按套用後，以任何方式關閉設定時，若外掛啟用狀態已改變，程式會自動靜默重新啟動；按確認則儲存並立即關閉。無需獨立的重新啟動按鈕。未儲存直接關閉會放棄未儲存的修改。此次重新啟動會記錄一條 Info 日誌。重新啟動後，App 與目前使用者的 Hook 不再載入停用外掛；名稱、版本號與介紹仍正常顯示，元件和設定需重新啟用並重新啟動後查看。主題與翻譯元件的開關唯讀，但仍可停用整個外掛。共用 Windows 索引服務繼續使用別名外掛。

2. 外掛模組詳情與元件開關 ​

按一下左側清單中的任意外掛模組後，右側會展示該外掛模組的圖示、名稱、版本號與功能簡介：

詳情索引標籤頁（Details） ​

  • 元件清單與分組：列出該外掛模組註冊的所有底層功能元件（例如：搜尋來源、快顯動作、快速導航提供者、即時預覽剖析器等）。
  • 元件級獨立開關：每個非必要元件均配有獨立的啟用/停用核取方塊；帶有鎖形圖示的元件為系統級必要核心，不可關閉。
  • 一鍵全選/全不選：當某個元件分組包含多個可切換項目時，標題右側會提供「全選/全不選」連結。
  • 元件停留說明：滑鼠停留在元件旁邊的 (!) 圖示上，可檢視該元件的底層實作說明與觸發方式。

設定索引標籤頁（Configure） ​

  • 原生嵌入式表單：外掛模組自訂的設定項會直接轉譯在右側面板中，無需快顯額外對話方塊。支援文字方塊、數字調節、開關、下拉式選單及多分組子索引標籤頁。
  • 圖示輸入欄位：使用 Schema 鍵 Icon 的文字方塊會顯示圖示預覽，並支援 WPF Path Data。貼上完整 SVG/XML 文件時會自動擷取並合併其中的路徑資料；無效的圖示內容會被清空，並透過主題化對話方塊提示。
  • 多行設定編輯器：StringList 欄位在展開後的編輯器中支援自動換行；實際換行會顯示淺色 ↵ 標記以便辨識，標記僅供視覺顯示，不會儲存到設定值或包含在複製內容中。
  • 安全認可與回復機制：在儲存之前，任何修改均僅暫存於記憶體中；切換至其他外掛模組或離開頁面時，已修改的內容會繼續保留，不會遺失，方便你比較多個外掛模組的設定。按下設定視窗底部的套用或確定會統一儲存所有改動過的外掛設定；按下取消（或直接關閉視窗）則回復為上次儲存的參數。

系統設定搜尋 ​

啟用系統設定搜尋外掛後，可用 Windows 提供的本地化關鍵字搜尋控制台工作。例如，env 可找到環境變數入口，不必手動維護別名。每個查詢詞都必須符合標題或關鍵字中某個詞的開頭；關鍵字隨 Windows 版本及系統語言而異。

CoreExtensions 搜尋類型篩選器 ​

在設定 → 外掛模組 → CoreExtensions → 設定 → 搜尋篩選器中，可以管理按類型篩選結果的各列。這些列會同時提供給兩個介面：完整搜尋視窗左側的類型篩選器，以及快速視窗搜尋框下方的類型篩選欄——關掉一列，兩處同時少一項；修改一個 @ 關鍵字的名稱，兩處同時改名。

可關閉的類型列共有七列：文件、圖片、影片、音訊、壓縮檔、應用程式、設定；檔案與資料夾兩列始終可用。

自訂過濾器現在是一張唯一的項目分類表，每一項都帶兩種觸發：在搜尋方塊輸入 :@<關鍵字> 對當前結果做收窄；或勾選顯示為篩選列，讓同一項目成為可點擊的列，同時出現在完整搜尋視窗的側欄和快速視窗的類型篩選欄。名稱為空、或規則展開後為空的項目會隱藏；圖示留空時使用介面預設標記。規則中可用 @<關鍵字> 引用其他項目：引用會遞迴展開、重複模式會被移除，不存在或循環引用不會產生比對，被停用的項目仍可被引用。:@ 與 @ 查找的都是關鍵字本身，獨立的顯示名稱只是讓列可以顯示在地詞，而關鍵字仍是 doc。

原本只設定側欄的那張清單已經取消。首次執行時會把它的項目併入這張表並打開「顯示為篩選列」；若某個項目的關鍵字已經存在，就只把已有那項打開為列，不會重複新增一份；其餘項目保留自己的規則，並沿用它原本顯示的名稱。

CoreExtensions 內嵌搜尋視窗 ​

在設定 → 外掛模組 → CoreExtensions → 設定 → 資源管理器內嵌視窗中，可以關閉內嵌視窗顯示快捷命令。內嵌視窗是唯一會把外掛快捷命令（如「快捷命令」分組）排在檔案結果之前、並被預設選取的地方，因此 Enter 執行的是命令而不是開啟符合的檔案；關閉後內嵌搜尋只針對檔案。快速視窗與主視窗不受影響。

瀏覽器書籤與瀏覽紀錄 ​

瀏覽器書籤與瀏覽紀錄外掛模組可以搜尋已設定的 Chromium 系瀏覽器及 Firefox 瀏覽器設定檔目錄。預設觸發關鍵字分別為書籤的 bb 和瀏覽紀錄的 bh；你可以在外掛模組設定中修改這兩個關鍵字，也可以分別關閉書籤或瀏覽紀錄索引。

黑名單欄位每行輸入一個字面字串。當書籤或瀏覽紀錄的標題或網址包含任何規則時，該項目會被隱藏；比對不分大小寫，且不會進行模糊比對。規則同時套用於書籤和瀏覽紀錄，並會在外掛模組重新載入快取資料後生效。

如果瀏覽器本機資料庫中存在相符的網站圖示，外掛模組會以唯讀方式讀取並將其顯示在結果中，不會複製資料庫檔案。讀取不到網站圖示時，則依次使用已設定的瀏覽器圖示，以及預設的書籤或瀏覽紀錄圖示。

3. Flow Launcher 社群生態支援 ​

除了基於 Lertaro.PluginSdk 建置的原生 C# 外掛模組之外，Lertaro 還透過內建的 Flow Launcher Bridge 提供了對 Flow Launcher 社群外掛模組生態的相容支援。

多語言執行階段與隔離環境 ​

  • 全類型外掛模組相容：可執行由 C# (.NET)、Python 3.12、Node.js v20 LTS 以及獨立可執行程式（.exe）編寫的 Flow Launcher 外掛模組。
  • 零相依性污染與自包含執行階段：Python（FlowData\PythonEmbeded-{arch}）與 Node.js（FlowData\NodeEmbeded-{arch}）執行階段完全隔離在 Lertaro 的使用者資料目錄中按需自動下載部署，不依賴且絕不污染 Windows 系統的全域環境變數與 PATH。
  • 相依性自動安裝：外掛模組首次載入時，系統會在背景無訊息根據 requirements.txt 安裝 Python pip 相依套件，或根據 package.json 執行 npm 相依套件安裝。

線上社群市場與套件管理指令 ​

你可以直接在 Lertaro 搜尋框中鍵入以下指令管理 Flow 外掛模組：

  • flow install <關鍵字>：即時線上檢索 Flow.Launcher 官方社群外掛模組庫，選取後一鍵自動下載、解壓、部署並拉起相依性安裝。
  • flow update：自動偵測所有已安裝 Flow 外掛模組的更新版本並支援一鍵升級。
  • flow uninstall <外掛模組名>：一鍵安全解除安裝指定的 Flow 外掛模組並清理相關本機目錄。
  • 手動安裝：亦可將下載好的第三方 Flow 外掛模組資料夾直接放入 <使用者資料目錄>\FlowData\Plugins\ 完成本機離線安裝。

外掛模組設定、觸發詞與互動式預覽 ​

  • 集中管理與觸發詞修改：在設定 → 外掛模組 → Flow Launcher Bridge → 設定中，可為每個 Flow 外掛模組單獨開關，並自由修改其專屬觸發詞（ActionKeyword）。設定集中保存於 FlowData\Settings\Plugins.json 中，外掛模組更新後設定不遺失。
  • 動態設定表單：完整支援 Flow 外掛模組基於 YAML/JSON 範本表單（SettingsTemplate.yaml/.json）或 C# WPF 設定面板（ISettingProvider）的設定介面，自動融合目前深淺色主題並支援 i18n 當地語系化。
  • WebView2 互動式豐富文字預覽：支援 Flow 外掛模組傳回的複雜預覽面板（如 MDict 字典釋義、天氣卡片、API 偵錯資訊、網頁快照等），在 QuickLook 中免額外按鍵平滑展開；Lertaro 會自動插入深淺色自適應樣式、清晰字型與細捲軸。
  • 宿主能力整合：Flow 外掛模組透過 API 開啟資料夾時自動遵循宿主配置的第三方檔案管理員，快顯訊息方塊自動轉譯為宿主主題自繪樣式，且內部記錄匯入設定中心記錄檢視器。
  • 快速概覽：在搜尋方塊中直接輸入 flow 即可列出目前已載入的所有 Flow 外掛模組及其觸發詞；選取外掛模組後會直接跳轉至設定中的對應設定群組。

4. 音訊裝置選擇器 ​

音訊裝置選擇器是僅支援 Windows 的原生外掛模組。輸入 ad 可列出目前啟用的播放和輸入裝置，選取裝置後會將其設為對應的預設多媒體裝置；也可以在觸發詞後附加裝置名稱來篩選結果。

外掛模組設定支援修改觸發詞，並選擇結果顯示友善名稱、裝置名稱或裝置描述。它可以切換預設播放或輸入端點，但不負責音量、靜音或單一應用程式的音訊路由。

5. 內容搜尋 ​

內容搜尋外掛模組可以搜尋已設定的本機文件內文。開啟它的設定標籤頁，可以設定觸發關鍵字、監控資料夾、索引副檔名、單一檔案大小上限、索引容量上限以及排除完整路徑的正規表示式。預設觸發關鍵字為 cs，因此輸入 cs 專案計畫 即可搜尋文件內文，並顯示附有片段的符合檔案。

設定中還提供清除索引與重建索引。清除索引只刪除內容索引，重建索引則會刪除內容索引並重新掃描所有監控資料夾。這兩個操作都不會刪除 Lertaro 的普通檔名索引。

6. 外掛模組執行狀態 ​

在設定 → 外掛模組 → 執行狀態中，可以查看 Lertaro 執行期間已安裝外掛模組的宿主側呼叫情況。資料按外掛模組彙總，並在該標籤頁開啟時持續重新整理。

  • 外掛模組篩選：使用篩選框按外掛模組名稱進行模糊搜尋。
  • 欄位排序：點擊欄位標題可依次切換升序、降序和預設外掛模組順序。
  • 可用指標：呼叫次數、平均耗時、最近耗時、最大耗時、受管理配置量和觀察到的例外次數。
  • 統計範圍：統計在目前 Lertaro 程序執行期間累計，重新啟動後重設。數值為零表示尚未記錄到對應呼叫；受管理配置量是受測呼叫產生的受管理記憶體配置，不代表外掛模組的全部私有記憶體佔用。
