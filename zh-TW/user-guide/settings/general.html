一般設定 ​

一般設定涵蓋系統的核心執行行為、搜尋視窗外觀與配置參數、各結果類型的優先順序權重以及預覽元件的排程順序。頁面頂部共分為六個索引標籤頁：系統、快速搜尋視窗、完整搜尋視窗、預覽視窗、快速導覽與預覽與縮圖。

1. 系統（System） ​

  • 開機自動啟動 Lertaro：勾選後在 Windows 使用者登入時自動啟動 Lertaro。
  • 啟動時自動檢查更新：勾選後在軟體每次啟動時自動連線查詢最新版本。
  • 自動無訊息更新：僅在以系統管理員身分執行 Lertaro 且開啟「檢查更新」時可用。偵測到新版本後將在背景無訊息下載並自動覆蓋升級，免去手動操作。
  • 啟用硬體加速：預設開啟。若遇到筆記型電腦獨立顯示卡（如 NVIDIA Advanced Optimus）因 Lertaro 常駐而無法自動休眠切換內建顯示卡的問題，可關閉該項改用軟體轉譯。修改後需重啟 Lertaro 生效。
  • 隱藏系統匣圖示：勾選後隱藏 Windows 工作列右下角的系統匣圖示。快速搜尋視窗內的 Logo 圖示依然能呼出完整的系統功能表，不會遺失任何入口。
  • 啟用 Everything 相容服務 (IPC)：預設關閉。開啟後，Lertaro 會在背景模擬標準 Everything Win32 IPC 通訊協定介面，讓 Directory Opus、Total Commander 等第三方軟體無需額外安裝執行 Everything 即可直接呼叫 Lertaro 的記憶體索引。
  • 啟用模糊比對：預設開啟。開啟時支援跳躍字元模糊比對；關閉後要求普通查詢詞必須為連續子字串（詳見搜尋語法）。即時生效無需重啟。
  • 關閉後保留搜尋框內容：預設關閉。開啟後，隱藏快速視窗與在主視窗中按 Escape 都不再清空搜尋框；在主視窗中按 Escape 會在第一次按鍵就直接關閉視窗，不必無謂地按兩次。下次呼出時交給視窗的搜尋詞會整段選取，因此第一個字元是取代它而不是接在後面。這僅維持在本次執行期間，文字絕不會寫入磁碟。
  • 在內嵌搜尋中顯示目前開啟的資料夾：內嵌視窗停靠在檔案對話方塊時，在搜尋內容為空的狀態下顯示該對話方塊目前開啟的資料夾，預設開啟。
  • 查詢標記總引導字元：單字元文字方塊（預設為 :）。用於設定搜尋框尾部後綴切分標記（如 :.pdf、:@doc、:[S]）的總引導符號。
  • 記錄等級：下拉選擇「錯誤 / 警告 / 資訊 (預設) / 偵錯」，控制系統各處理程序記錄輸出的詳細程度。
  • 介面語言：下拉選擇 Lertaro 的全域顯示語言。

2. 快速搜尋視窗（Quick Search Window） ​

本索引標籤頁用於精細化設定快速置中浮動視窗的幾何尺寸與結果排序：

搜尋列配置 ​

  • 搜尋列寬度 (像素)：取值範圍 300–1200px，預設 570px。
  • 搜尋列高度 (像素)：取值範圍 45–120px，預設 60px。該數值會按比例同步驅動結果清單的圖示大小、行高與字型大小，確保視覺協調。
  • 搜尋框內顯示時鐘：開啟後，在搜尋框為空時將提示文字替換為目前即時日期、星期與時間。輸入文字後時鐘自動隱藏。
  • 再次按下快速鍵時開啟完整視窗：開啟後，在快速視窗已顯示狀態下再次按下全域呼出快速鍵，將攜帶目前輸入內容直接切換至完整主搜尋視窗。
  • 鎖定位置：開啟後禁止滑鼠拖曳移動快速視窗，防止誤觸改變位置。
  • 自動將剪貼簿文字填入快速搜尋框：預設關閉。快速視窗在沒有預填內容時，如果剪貼簿中有新的非空文字，就將其用作搜尋內容。手動貼上和其他視窗不受影響。
  • 重設配置設定：一鍵將快速視窗尺寸與配置恢復為系統初始預設值。

結果類型優先順序與觸發符 ​

  • 優先順序排序清單：支援拖曳左側手柄或上下移動各結果類型（應用程式、系統設定、檔案、外掛模組擴充項目等）。排在前面的類型在綜合搜尋結果中享有更高的排列權重。
  • 專屬單字元觸發符：可為特定結果類型設定專屬單字元前綴（如將檔案篩選器設為 ;）。在搜尋框開頭輸入該字元即可直接過濾出該類型的專屬結果。

3. 完整搜尋視窗（Full Search Window） ​

用於設定大尺寸主搜尋視窗（Ctrl+F）的預設行為與表格檢視：

  • 視窗寬度 / 高度 (像素)：寬度範圍 640–2000px（預設 854px），高度範圍 400–1400px（預設 480px）。
  • 僅允許一個完整搜尋視窗：開啟後，再次開啟完整視窗將直接啟用已有執行個體，避免重複建立多開。
  • 再次按下快速鍵時關閉完整視窗：預設關閉，此時在完整視窗已取得焦點的情況下再次按下全域呼出快速鍵，會攜帶目前輸入內容切回快速搜尋視窗，並在兩個視窗之間反覆切換，直到按 Esc 退出。啟用後，再次按下快速鍵將直接關閉完整視窗。無論開關如何設定，完整視窗可見但未取得焦點時按下快速鍵都只會將其帶回前景。
  • 重設搜尋視窗設定：一鍵恢復主視窗預設寬高設定。
  • 結果表格欄順序：拖曳自訂表格檢視中各欄（名稱、路徑、修改時間等）的先後排列順序。
  • 側邊欄篩選順序：拖曳調整主視窗左側分類篩選欄的展示順序；篩選欄會即時動態呈現目前關鍵字在各分類下的比對項目數量。
  • 動作功能表分組順序：拖曳調整快顯動作功能表（Ctrl+O）中各功能分組的顯示先後。

4. 預覽視窗（Preview Window） ​

  • 預覽視窗寬度 / 高度 (像素)：寬度範圍 250–900px，高度範圍 250–1200px。
  • 重設預覽視窗設定：將 QuickLook 預覽浮動視窗的尺寸重設為標準預設比例。系統會自動計算避免預覽視窗超出目前顯示器的工作可視區域。

5. 快速導覽（Quick Navigation） ​

  • 提供者順序：透過上下箭頭或拖曳手柄，調整滑鼠快速導覽階層式功能表根層級各個資料來源提供者（我的最愛、搜尋歷程記錄、已開啟資料夾、第三方管理器書籤等）的分組排列順序。

6. 預覽與縮圖（Previews & Thumbnails） ​

  • 檔案預覽提供者順序：調整多個預覽外掛模組（如內建富文字/媒體解碼器與第三方 QuickLook 橋接）的呼叫優先順序。
  • 縮圖提供者順序：調整結果清單中檔案圖示與縮圖擷取元件的呼叫優先順序。
