本頁目錄

關於與更新 ​

關於頁面提供了 Lertaro 目前執行環境的完整版本資訊、使用者與系統資料儲存目錄的快速直達入口，以及線上檢查更新與一鍵升級功能。頁面路徑為設定 → 關於。

1. 元件版本與專案資訊 ​

頁面頂部展示了 Lertaro 架構體系中四大核心元件的獨立版本號：

  • App 版本：前景 WPF 使用者互動介面版本。
  • Core 版本：核心搜尋與索引運算邏輯庫版本。
  • Service 版本：背景 Windows 索引服務版本（其文字顏色會動態反映服務目前是否處於健康連線狀態）。
  • CLI 版本：命令列終端機互動工具 lff 的版本。

下方提供了專案官方網站、GitHub 開源存放庫以及線上文件中心的直達連結。

2. 資料目錄與自動備份輪轉機制 ​

頁面中央提供了兩個直接可點擊開啟實體路徑的超連結（若目標資料夾尚未產生，點擊時會自動建立）：

使用者資料目錄（User Data Directory） ​

  • 儲存內容：存放目前 Windows 使用者的個人設定檔 user-settings.json, plugin-settings.json、搜尋與關鍵字歷程記錄、使用者專屬快取及憑證。
  • 五級備份輪轉保護機制：每次在設定中心點擊儲存或修改設定時，Lertaro 會自動將現有設定檔順延輪轉備份為 user-settings.json.bak.1，舊的備份依次向後推移至 user-settings.json.bak.5。即使發生斷電、誤改或系統當機，也能隨時在資料目錄中找到最近 5 次的歷史備份進行還原。

機器資料目錄（Machine Data Directory） ​

  • 儲存內容：存放背景提權服務使用的機器級設定檔 machine-settings.json、全盤實體索引持久化快取以及服務端記錄檔。

儲存路徑規則 ​

  • 安裝版：使用者資料存放於 %LocalAppData%\Lertaro，機器資料存放於 %ProgramData%\Lertaro。
  • 免安裝版：使用者資料存放於程式目錄下的 Data\Users\<SID hash>，機器資料存放於 Data\Machine，與系統目錄完全隔離（詳見免安裝版使用說明）。

資料目錄搬遷（符號連結與 Junction） ​

  • 支援搬遷：使用者資料目錄（安裝版為 %LocalAppData%\Lertaro，免安裝版為 <安裝目錄>\Data\Users）可以用符號連結或 Junction 搬到其他本機磁碟分割區或另一顆本機磁碟。啟動時 Lertaro 會把這條連結鏈解析成真實目錄，之後都讀寫該真實目錄。
  • 僅支援本機固定磁碟：連結目標必須是本機固定磁碟區。若連結指向網路位置或可卸除式磁碟區，程式會在啟動時明確拒絕並說明原因，而不是不聲不響地寫到別處。
  • 資料目錄以下的連結仍然一律拒絕：資料目錄內部的任何子目錄都不允許是連結——執行期間被換上的連結會把寫入重導向出去。這是安全邊界，不是可設定的項目。

3. 檢查更新與一鍵升級 ​

  • 檢查更新按鈕：點擊後手動發起線上版本偵測。按鈕文字會動態反饋檢查狀態（「正在檢查更新...」 → 「已是最新版本」 或快顯新版本更新卡片）。
  • 發現新版本時的升級方式：
    • 無訊息自動更新 —— 在背景自動下載新版本安裝套件並就地覆蓋升級，升級完成後自動重啟拉起 Lertaro。
    • 前往下載頁面 —— 在預設瀏覽器中開啟 GitHub Releases 發布頁面，供手動下載免安裝壓縮包或安裝程式。
  • 權限安全提示：若目前執行在受限的標準使用者帳戶下，且無法直接停用背景 Windows 服務完成就地更新，頁面會呈現安全提示，並引導你前往官方頁面下載安裝。

4. 外掛設定與設定備份 ​

原生外掛參數位於與 user-settings.json 同目錄的 plugin-settings.json，兩個檔案分別保留最多五級輪轉備份。舊版內嵌參數只移轉一次。完整設定 ZIP 包含這兩個檔案、行事曆資料和 Flow 設定；可執行的 Flow 外掛檔案需要明確選擇包含。移轉目前外掛設定時，不應只複製主設定檔。

同步軟體暫時占用備份目標時，可復原的傳輸失敗會保留目前設定並正常開啟程式。本機執行鎖統一放在 %LocalAppData%\Lertaro\RuntimeLocks，可攜版也不將它放在被同步的使用者資料目錄中。如果無法完成回復，則不會在部分還原的設定上啟動外掛。
