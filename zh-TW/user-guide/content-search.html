內容搜尋 ​

內容搜尋外掛模組可以搜尋本機文件中的內文，並在背景建立索引，與 Lertaro 原有的檔名搜尋並行運作。

開始使用 ​

開啟設定 → 外掛模組 → 內容搜尋 → 設定，至少設定一個監控資料夾並儲存。預設觸發關鍵字為 cs：

text
cs 專案計畫

關鍵字後必須跟一個空格。如果 cs 與你的使用習慣衝突，可以在外掛模組設定中改成其他關鍵字。

索引內容 ​

  • 監控資料夾：外掛模組會向主機索引服務註冊設定的本機資料夾，透過 SDK 的索引目錄列舉和經過防抖處理的目錄變更通知完成首次及增量偵測；每個資料夾都必須由主機的本機磁碟機索引或資料夾索引涵蓋，否則列舉不到檔案。支援 %USERPROFILE% 等環境變數，以及能解析為真實資料夾的 shell:Downloads 等系統虛擬路徑。
  • 檔案副檔名：預設包含 txt、md、pdf、docx、docm、pptx、pptm、xlsx、xlsm 和 csv，你可以按需要修改以逗號分隔的清單。
  • PDF 檔案：會同時搜尋可擷取的頁面內文和已儲存的可填寫 PDF 表單欄位值。
  • 檔案大小：超過單一檔案大小上限的檔案會被略過；內容索引還有獨立的容量上限，設為 0 表示不限制。
  • 排除路徑：輸入以分號分隔的正規表示式來排除符合的完整路徑。資料夾路徑符合時，其內容也會被排除。

只有成功擷取出內文的檔案才會參與搜尋。沒有對應文件擷取器的二進位檔案會被略過，不會作為亂碼文字寫入索引。

即使設定的檔案大小不限，內文擷取仍有安全上限：Office ZIP 中每個解壓縮後的項目最多 128 MiB，每個 Office/PDF 文件擷取的文字最多 32 Mi 個字元。超過上限的文件會擷取失敗，不會只索引部分內文；單一檔案的擷取或寫入失敗會記入日誌，後續檔案仍會繼續處理。

搜尋方式 ​

在快速搜尋視窗中輸入 cs、空格和關鍵字即可搜尋。結果會顯示符合檔案的內文片段及所在資料夾，按下 Enter 可開啟選取的檔案。查詢有結果時，在未選取類型篩選的情況下，完整搜尋視窗中也會顯示這些檔案結果。

首次建立索引時，cs 佔位結果會顯示已索引檔案數和剩餘工作數。主機監聽器報告新增或變更的目錄後，外掛模組會在背景處理其中的檔案，因此索引期間不會影響普通檔名搜尋；索引穩定後不會再循環掃描檔案系統。

支援單字、雙字關鍵字，也支援將短詞與長詞組合查詢。短詞按字面子字串比對；條件允許時使用較長的關鍵字可提高查詢速度。

僅在初次內容索引完成，以及每次主動重建後的首次完成時提示一次。複製或修改檔案、儲存設定和重新啟動程式都不會再次顯示完成提示。達到索引容量上限時會另行警告；停止或暫停索引不算完成。

清除與重建 ​

內容搜尋設定中提供兩個不同的操作：

  • 清除索引：刪除內容索引，但不會重新掃描監控資料夾。
  • 重建索引：刪除內容索引，然後重新掃描所有監控資料夾。

這兩個操作只影響內容搜尋索引，不會刪除 Lertaro 的普通檔名索引。

使用提示 ​

  • 如果檔案沒有出現在結果中，請檢查它所在的資料夾、副檔名、排除規則和大小上限。
  • 修改監控資料夾或索引規則後，請儲存設定並等待背景掃描完成。
  • 修改規則後如果希望重新擷取已有檔案，請使用重建索引。
