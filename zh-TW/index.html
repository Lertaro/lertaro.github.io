三程序隔離架構與運行模型

嚴格劃分特權邊界，確保系統級檢索效能與前景 UI 的極致穩定性

SYSTEM 服務Lertaro.Service

以 LocalSystem 權限常駐背景，直接讀取 NTFS / ReFS 底層 USN Journal 與 $MFT，監聽 FAT32 / exFAT 變動，並透過具名管道提供高效能唯讀資料檢索。

使用者態前景Lertaro.App

標準使用者 Session 桌面程式，承載快速搜尋置中浮動視窗、完整主視窗、設定中心、動作選單以及外掛管理，不持有任何多餘系統特權。

視窗與掛鉤Lertaro.Service --hook

獨立特權輔助程序，託管低階全域鍵盤與滑鼠監聽，突破 Windows UIPI 權限隔離以無縫嵌入管理員權限對話方塊，同時隔離異常當機風險。

常見問題與解答

針對架構設計、系統服務與使用模式的核心技術解答

Q

為什麼需要安裝背景 Windows 服務？

背景服務以 LocalSystem 權限直接讀取 NTFS/ReFS 磁碟底層的 USN Journal，無需使用者在前景頻繁彈窗賦予管理員權限，既保證了全盤變更監聽的高效能，又避免了讓前景 UI 程序持有不必要的系統高特權。

Q

Lertaro 與 Everything、Listary 的主要區別與定位是什麼？

Lertaro 專注於像 Listary 一樣深度掛載檔案對話方塊與即時模糊查找，同時具備 Everything 等級的底層 USN 秒級索引效能，並提供現代 .NET 10 開放外掛生態與即時磁碟空間分析。

Q

便攜版（Portable）與安裝版（Installer）有什麼區別？

安裝版會自動註冊並管理背景索引服務，適合長期作為系統主力檢索工具；便攜版完全免安裝解壓即用，若需要背景全盤索引服務也可在設定中心一鍵按需註冊與解除安裝。

Q

檢索資料會上傳到雲端或產生網路遙測嗎？

完全不會。Lertaro 為 100% 本機純離線運行工具，不包含任何背景遙測、資料統計回報或強制雲端連線，嚴格保障本機隱私安全。
