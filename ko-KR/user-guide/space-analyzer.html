공간 분석 ​

Lertaro에는 초고속 디스크 및 폴더 **공간 분석기 (Space Analyzer)**가 내장되어 있습니다. 시간이 오래 걸리는 전체 물리 디스크 스캔을 매번 수행하는 기존 도구와 달리, Lertaro가 백그라운드에 이미 구축해 둔 인메모리 인덱스 트리를 직접 활용하여 수백만 개의 파일이 있는 드라이브도 수 밀리초 만에 용량 통계를 시각화합니다.

1. 공간 분석 진입 방법 ​

  • 자동 표시: Lertaro 메인 검색 윈도우(Ctrl+F)를 열고 검색창을 빈 상태로 유지하면 공간 분석이 홈 화면으로 자동 표시됩니다.
  • 검색과 자연스러운 전환: 검색창에 문자를 입력하면 즉시 일반 검색 결과 목록으로 전환되며, Escape나 백스페이스로 검색어를 비우면 즉시 공간 분석 뷰로 돌아옵니다.

2. 화면 구성 및 시각화 ​

좌우 2분할 연동 레이아웃을 채택하여 각 디렉토리와 파일의 용량 비율을 직관적으로 확인할 수 있습니다.

좌측: 트리맵 (Treemap) 직사각형 차트 ​

  • 면적 기반 시각화: 용량이 큰 폴더나 파일일수록 더 넓은 직사각형 면적을 차지합니다.
  • 명암 및 경계선: 현재 폴더 내에서의 상대적 비중을 명암으로 표현하며, 전용 테두리 스타일로 폴더와 일반 파일을 명확히 구분합니다.

우측: 크기 내림차순 목록 ​

  • 크기순 정렬: 현재 계층의 하위 항목을 큰 순서대로 나열하여 용량을 많이 차지하는 항목을 즉시 찾아냅니다.
  • 비율 프로그레스 바: 각 행 하단에 얇은 바가 표시되어 현재 총 용량 대비 점유율을 직관적으로 보여줍니다.
  • 양방향 연동 하이라이트: 좌측 트리맵이나 우측 목록에서 항목을 선택하면 반대쪽 패널에서도 동일한 항목이 동시에 강조 표시됩니다.
  • 긴 파일명 자동 스크롤: 화면 폭을 초과하는 긴 파일명은 마우스 호버 또는 선택 시 매끄럽게 자동 스크롤됩니다.

3. 탐색 및 조작 방법 ​

  • 계층 이동:
    • 폴더 진입: 트리맵 카드나 우측 목록 항목을 좌클릭 더블클릭하여 내부 구조로 진입.
    • 상위 폴더 이동: 상단 바의 "위로" 화살표를 클릭하거나 이동 경로(Breadcrumb)의 부모 폴더를 클릭.
  • 컨텍스트 액션 메뉴: 카드나 목록 행에서 우클릭하면 일반 검색 결과와 동일한 액션 메뉴(열기, 전체 경로 복사, 탐색기에서 위치 확인, 휴지통 이동, 영구 삭제)가 열립니다.
  • 휠클릭으로 위치 열기: 휠클릭(중간 버튼)하면 설정된 파일 관리자에서 해당 파일의 위치가 즉시 열립니다.
  • QuickLook 미리보기 연동: 항목 선택 후 Alt+P를 누르면 미리보기 패널이 열리며, 선택을 변경할 때마다 내용이 실시간 갱신됩니다.

4. 통계 기준 및 실시간 동기화 ​

통계 범위 및 계산 방식 ​

  • 기존 인덱스 기반: Lertaro에 이미 활성화된 인덱스 데이터만 집계하므로 추가적인 디스크 I/O가 발생하지 않습니다. 제외 규칙에 해당하는 파일은 통계에 포함되지 않습니다.
  • 논리 파일 크기 기준: 파일의 실제 논리 크기를 집계하며 하드링크 데이터는 1회만 계산하여 중복을 방지합니다.
  • 숨김 및 시스템 파일: 숨김 파일은 정상적으로 집계 및 표시되며, 시스템 파일은 상위 폴더의 총 용량에 합산됩니다.

실시간 변경 반영 및 자가 복구 ​

  • 실시간 반영: 파일 추가/삭제/변경이 발생하면 인덱스 변경 알림을 수신하여 뷰를 매끄럽게 자동 갱신합니다.
  • 경로 자가 복구: 탐색 중인 폴더가 외부에서 삭제되거나 이름이 변경되더라도, 공간 분석기는 유효한 상위 부모 폴더로 안전하게 자동 복귀합니다.
