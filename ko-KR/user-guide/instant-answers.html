인스턴트 답변 및 키워드 확장 기능 ​

Lertaro는 로컬 파일 검색 외에도 즉시 계산, 시스템 도구 및 키워드 기반 확장 플러그인을 제공합니다. 파일 검색 결과를 기다릴 필요 없이 해당 명령어를 입력하여 즉각적인 결과를 얻을 수 있습니다.

1. 상시 활성화된 인스턴트 기능 ​

키워드 접두사 없이도 입력된 텍스트가 특정 패턴과 일치하면 즉시 실행됩니다.

계산기 및 진법 변환 ​

검색창에 수학 수식을 직접 입력하면 첫 번째 줄에 결과가 실시간으로 표시됩니다. Enter를 누르면 계산 결과가 클립보드에 복사됩니다.

text
12 * (4 + 3)
100 * (1 - 0.15)

진법 변환도 기본 지원합니다.

text
255 to hex
0xFF to dec
101010 to bin

환경 변수 확장 및 검색 ​

  • 변수 값 확인: %NAME%(예: %PATH%, %APPDATA%)을 입력하여 실제 경로 값을 확인합니다. PATH처럼 여러 경로가 포함된 변수는 줄바꿈 목록으로 깔끔하게 자동 전개됩니다.
  • 환경 변수 퍼지 검색: % 뒤에 키워드를 입력(예: %temp)하면 해당 단어가 포함된 시스템/사용자 환경 변수를 검색합니다.

명령어 즉시 실행 ​

터미널을 따로 열지 않고 검색창에서 직접 명령을 실행할 수 있습니다.

  • #<명령어>: 명령 프롬프트를 열고 관리자 권한으로 실행합니다(예: #sfc /scannow 또는 #net start LertaroService).
  • $<명령어>: 명령 프롬프트를 열고 일반 사용자 권한으로 실행합니다(예: $ping 1.1.1.1 또는 $ipconfig /all).

설정 → 플러그인 → 코어 확장 → 구성 → 명령 실행기에서 CMD(기본값), Windows PowerShell 또는 PowerShell(pwsh)을 선택할 수 있습니다. 현재 디렉터리에서 실행은 인라인 검색의 디렉터리 또는 빠른 검색에서 마지막으로 탐색한 디렉터리를 사용합니다. 사용할 수 없는 디렉터리에서는 실행을 중단합니다.

계단식 폴더 탐색기에 표시를 켜면 메뉴를 연 디렉터리에서 명령을 실행할 수 있습니다. 하위 폴더의 우클릭 메뉴는 해당 하위 폴더를 사용합니다. 대화 상자에서 셸과 관리자 권한을 선택하며, 빈 입력은 선택한 셸을 엽니다. #/$ 접두사는 권한 체크박스보다 우선합니다. 접두사 뒤의 입력이 정확히 cmd, powershell, pwsh이면 해당 프로그램을 직접 엽니다(대소문자와 앞뒤 공백 무시). 프로그램이 없는 경우에만 원래 입력을 CMD로 실행합니다. 일반 명령에 설정된 셸이 없으면 오류를 표시합니다.

CMD는 디렉터리를 바꾸기 전에 시작 명령의 %CD%를 확장합니다. 권한 상승이나 UNC 경로로 초기 디렉터리가 변경되면 이전 위치를 가리킬 수 있습니다. 시작 명령에서 디렉터리를 읽으려면 PowerShell의 $PWD를 사용할 수 있습니다.

웹 URL 바로 열기 ​

http:// 또는 https://로 시작하는 URL을 입력하거나 붙여넣고 Enter를 누르면 기본 브라우저에서 즉시 열립니다. example.com과 같은 유효한 프로토콜 없는 웹 주소를 입력하면 빠른 검색 창에 https://...와 http://... 두 개의 즉시 결과가 생성됩니다. 프로토콜 없는 인식은 하드코딩된 일반 최상위 도메인 화이트리스트(.com, .cn, .io 등 100여 개 접미사와 xn-- 국제화 도메인)에만 적용되며 설정할 수 없습니다. 일반 파일 확장자와 겹치는 접미사는 의도적으로 제외되어 그 외의 입력은 그대로 파일명 검색으로 처리되므로 abc.txt에서는 브라우저 결과가 생성되지 않습니다. 목록에 없는 주소의 경우 프로토콜을 함께 입력하세요. 각 결과는 브라우저로 열기 안내를 두 줄 형식으로 표시하며 검색 상자 내용은 변경되지 않습니다. 이미 프로토콜이 포함된 URL은 하나의 결과로 표시됩니다.

빠른 검색 창의 클립보드 텍스트 가져오기 ​

설정 → 일반 → 퀵 검색 윈도우 → 클립보드 텍스트 자동 입력(기본값 꺼짐)을 켜면, 미리 입력된 내용 없이 빠른 검색 창을 호출했을 때 클립보드가 비어 있지 않고 같은 창에서 직전에 가져온 값과 다를 경우 텍스트를 자동으로 입력하고 전체 선택합니다. 같은 값은 반복해서 가져오지 않으며 URI 또는 전체 검색 창에서 돌아올 때의 미리 입력된 내용도 덮어쓰지 않습니다.

2. 키워드 실행 기능 (내장 플러그인) ​

짧은 트리거 키워드 + 공백 뒤에 쿼리를 입력하여 전용 플러그인 기능을 호출할 수 있습니다. 모든 키워드는 설정 → 플러그인에서 변경할 수 있습니다.

구분자는 반각 공백·전각 공백·탭을 모두 쓸 수 있으며, 트리거 단어 자체는 파일 이름 일치나 강조에 사용되지 않습니다. 두 기능이 같은 단어를 쓰면 플러그인 설정 페이지의 해당 입력란 아래에 호박색 알림이 뜨지만 저장은 막지 않습니다.

기본 키워드플러그인 이름기능 설명 및 활용사용 예시
ps프로세스 관리실행 중인 프로세스를 이름, PID, 창 제목으로 검색하고 Enter로 즉시 종료.ps chrome 또는 ps 1234
win창 전환기열려 있는 앱 창을 검색하고 실시간 백그라운드 썸네일과 함께 즉시 전환.win code 또는 win 브라우저
bb브라우저 북마크Chrome, Edge, Firefox의 북마크를 검색합니다.bb github
bh브라우저 방문 기록Chrome, Edge, Firefox의 방문 기록을 검색합니다.bh github
set설정 검색Lertaro 내부의 모든 설정을 퍼지 검색. 선택 시 해당 설정 페이지로 즉시 이동 및 하이라이트.set 단축키 또는 set 퍼지
flowFlow 플러그인 브리지로드된 Flow.Launcher 플러그인 및 트리거 목록을 확인하고 Flow 생태계 활용.flow

3. 웹 검색 엔진 바로가기 ​

웹 검색 플러그인에는 주요 검색 엔진이 내장되어 있어 접두사 뒤에 검색어를 입력하면 브라우저에서 바로 검색할 수 있습니다.

단축어검색 엔진예시설명
bd바이두 (Baidu)bd 딥러닝Baidu에서 검색
g구글 (Google)g lertaro githubGoogle에서 검색
bing빙 (Bing)bing 마이크로소프트 문서Bing에서 검색
gh깃허브 (GitHub)gh LertaroGitHub 저장소에서 바로 검색
wiki위키백과 (Wikipedia)wiki 양자역학위키백과 항목 검색
yt유튜브 (YouTube)yt lofi hip hopYouTube 동영상 검색

설정 → 플러그인 → 웹 검색 → 설정에서 새 검색 엔진과 커스텀 URL 템플릿을 추가/편집/삭제할 수 있습니다.

4. 즉시 번역 ​

기본 트리거 tr 뒤에 번역할 텍스트를 입력하면 Lertaro UI 언어로 자동 번역됩니다.

text
tr Hello, how are you today?
  • 타이핑 중 비동기적으로 번역 결과가 나타나며, Enter를 눌러 결과를 복사할 수 있습니다.
  • 설정 → 플러그인 → 번역 → 설정에서 트리거 단어를 변경할 수 있습니다.

5. 파일 필터 ​

설정 → 플러그인 → 파일 필터 → 설정에서 트리거 키워드에 특정 폴더를 바인딩하여 일반 검색을 해당 폴더 안으로 제한할 수 있습니다.

  • 대상 폴더: 한 줄에 하나의 경로(예: D:\Engineering\Drawings). 환경 변수(예: %TEMP%)와 셸 가상 경로(예: shell:Downloads)도 지원하며, 실제 폴더로 확인되지 않는 항목은 건너뜁니다. 검색 결과는 파일 색인에서 나오므로 폴더는 색인이 적용되어야 합니다(색인이 활성화된 로컬 드라이브 또는 설정 → 색인 → 폴더에 추가, 네트워크 공유 경로 지원). 색인이 적용되지 않은 폴더는 건너뛰고 로그에 경고가 기록됩니다.
  • 확장자 규칙 지정: *.dwg;*.dxf 같은 파일 이름 패턴(폴더는 항상 포함).
  • 트리거 키워드 할당: 접두사(예: cad)를 할당하면 빠른 검색에서 cad 부품도 입력 시 일반 색인 검색(파일 이름 퍼지 매칭, 병음 별칭 포함)이 바인딩된 폴더 안으로 제한됩니다. 키워드만 입력하면 계속 입력하라는 안내가 표시됩니다.

6. 커스텀 명령어 ​

각 명령의 현재 디렉터리에서 실행은 고정 작업 디렉터리 대신 메뉴를 연 위치, 인라인 검색 위치 또는 빠른 검색에서 마지막으로 탐색한 위치를 사용합니다. 디렉터리를 사용할 수 없으면 실행을 중단합니다. 기본값은 꺼짐입니다.

설정 → 플러그인 → 커스텀 명령어 → 설정에서 복잡한 스크립트, CLI 도구, 외부 앱을 간단한 명령어로 래핑할 수 있습니다.

  • 매개변수 플레이스홀더: 위치 플레이스홀더 %s1, %s2... 및 전체 입력 캡처 %s 지원.
  • 퀵 내비게이션 연동: "퀵 내비게이션에 표시"를 체크하면 퀵 내비게이션 메뉴에 등록되며, /를 이용한 다단계 서브메뉴(예: 개발도구/서비스재시작) 분류도 지원합니다.
