빠른 시작 ​

Lertaro에 오신 것을 환영합니다! Lertaro는 Windows 환경에 최적화된 파일 검색기 및 생산성 런처입니다. 이 가이드에서는 설치 방법, 핵심 아키텍처, 3가지 윈도우 모드 및 기본적인 검색 워크플로를 안내합니다.

1. 다운로드 및 설치 ​

공식 홈페이지에서 최신 릴리스를 다운로드할 수 있습니다. 각 배포 버전은 네이티브 x64 및 ARM64 애플리케이션용 설치 프로그램과 포터블 패키지로 제공됩니다.

설치 프로그램 (Lertaro-Setup.exe, 권장) ​

  • 자동 구성: 설치 마법사가 필요한 .NET 데스크톱 런타임을 자동으로 설치합니다. 첫 실행 시 Lertaro 앱 자체가 백그라운드 인덱싱 서비스를 등록하고 시작 프로그램 항목을 구성합니다.
  • 원활한 업데이트: 백그라운드 자동 업데이트 확인 및 원클릭 덮어쓰기 업그레이드를 지원합니다.

포터블 버전 (Lertaro-Portable.zip) ​

  • 무설치 압축 해제 실행: 원하는 폴더에 압축을 풀고 즉시 실행할 수 있습니다.
  • 런타임 의존성: 시스템에 필요한 .NET 데스크톱 런타임이 없는 경우, 압축 해제 디렉토리에 포함된 install-dotnet-runtime.bat 스크립트를 실행하여 설치할 수 있습니다.
  • 독립적인 데이터 저장: 포터블 버전은 프로그램과 동일한 디렉토리의 Data\Machine에 머신 데이터를, Data\Users\<SID hash>에 사용자 설정을 저장합니다. Data 폴더가 아직 없는 경우 호환성을 위해 시스템의 %ProgramData%\Lertaro 및 %LocalAppData%\Lertaro를 읽어오며, 폴더가 생성되면 완전히 독립된 자급자족 포터블 환경으로 동작합니다.
  • 서비스 설치 시 폴더 보호: 백그라운드 서비스를 설치하면(UAC 확인을 한 번 승인) 포터블 폴더가 보호됩니다. 애플리케이션 파일은 관리자만 변경할 수 있고, Data\Machine은 서비스만 기록하며, 각 사용자의 Data\Users\<SID 해시> 폴더는 해당 사용자 전용이 됩니다. 따라서 포터블 버전을 업데이트하거나 제거하려면 관리자 권한이 필요하며, portable-cleanup.bat은 스스로 권한을 요청합니다.
  • 클린 제거: 포터블 폴더를 삭제하기 전에 포함된 portable-cleanup.bat 스크립트를 실행하세요. 백그라운드 서비스를 중지 및 제거하고, 사용자의 lertaro:// URI 프로토콜 및 시작 프로그램 레지스트리 항목을 깔끔하게 정리합니다.

TIP

Surface Pro X나 스냅드래곤 탑재 노트북과 같은 Windows on ARM 기기에서는 네이티브 Lertaro-Setup-arm64.exe 또는 Lertaro-Portable-arm64.zip을 다운로드하여 최고의 성능과 배터리 효율을 경험하세요.

2. 핵심 아키텍처 개요 ​

Lertaro를 처음 실행하면 전용 Windows 서비스(서비스 이름 LertaroService, 바이너리 Lertaro.Service.exe)가 설치되고 실행됩니다. 이 구조를 이해하면 Lertaro를 더욱 효율적으로 활용할 수 있습니다.

  • 포그라운드 App (UI 및 인터랙션): 검색창, 플로팅 패널, 액션 메뉴, 키보드 후킹 및 즉시 미리보기 렌더링을 담당합니다. 메모리 점유율을 낮추고 즉각적인 반응 속도를 유지합니다.
  • 백그라운드 Service (인덱싱 및 데이터): 서비스 권한으로 백그라운드에 상주하며, NTFS / ReFS USN 변경 저널 모니터링, 기타 파일 시스템의 실시간 변경 감지, 네트워크 공유 인덱스 관리 및 인메모리 검색 트리를 유지 관리합니다.
  • 아키텍처의 장점: UI를 재시작하거나 업데이트해도 백그라운드 인덱스가 손실되거나 전체 디스크를 다시 스캔하지 않습니다. 또한 대규모 인덱싱 작업이 UI의 매끄러운 타이핑을 방해하지 않습니다. 설정 → 서비스 상태에서 언제든지 상태를 확인할 수 있습니다.

3. 세 가지 윈도우 모드 ​

Lertaro는 다양한 워크플로에 맞춘 세 가지 윈도우 모드를 제공합니다.

윈도우 모드기본 호출 방법주요 특징 및 설계 콘셉트최적의 활용 시나리오
퀵 윈도우 (Quick Window)Ctrl 더블 클릭 (사용자 지정 가능)화면 중앙의 컴팩트 플로팅 창. 입력 즉시 검색, 검색창 아래 유형 필터 바, 숫자키 빠른 이동 및 전체 키보드 조작 지원자주 쓰는 앱 실행, 특정 파일 즉시 검색, 빠른 계산 및 번역
메인 윈도우 (Full Window)작업 표시줄/시작 메뉴, 또는 Ctrl+F대화면 풀 기능 창. 대량 결과 테이블 뷰, 사이드바 필터 그룹, 열 정렬, 내장 공간 분석기 지원파일 탐색, 광범위한 검색, 디스크 공간 정리 및 상세 필터링
인라인 윈도우 (Inline Window)파일 대화상자/파일 관리자에서 글자나 숫자 입력 (탐색기에서는 직접 도킹)Windows 표준 파일 대화상자 및 지원되는 파일 관리자에 직접 내장되어 작업 컨텍스트를 벗어나지 않고 검색. 카드는 절대 키보드를 가로채지 않습니다. 대화상자 자체의 입력창에 계속 타이핑하고, Ctrl 더블 클릭(설정해 둔 호출 단축키)을 눌러 캐럿을 카드로 이동하세요앱에서 "열기" 또는 "다른 이름으로 저장" 시 대상 폴더/파일을 빠르게 지정

세 가지 창 모드는 완전히 동일한 검색 엔진, 단축키 체계, 필터 규칙 및 액션 메뉴를 공유합니다.

4. 첫 검색 및 기본 조작 ​

입력하여 즉시 검색 ​

검색창을 열고 원하는 단어를 입력하기만 하면 결과가 실시간(밀리초 단위)으로 나타납니다. 검색 알고리즘은 기본적으로 퍼지(Fuzzy) 매칭을 사용하므로, 문자가 연속되지 않고 띄엄띄엄 있어도 정확히 찾아냅니다. 상세 문법은 검색 문법을 참고하세요.

결과 이동 및 실행 ​

  • 선택 항목 이동: 방향키 ↑ / ↓(또는 설정된 탐색 단축키 Ctrl+P / Ctrl+N)를 사용하여 목록을 이동합니다.
  • 직접 열기: Enter를 눌러 선택한 파일을 열거나 응용 프로그램을 실행합니다.
  • 탐색기에서 위치 확인: Ctrl+Enter를 누르면 파일 탐색기가 열리고 해당 파일이 선택된 상태로 표시됩니다.
  • 관리자 권한으로 실행: Ctrl+Shift+Enter를 눌러 관리자 권한으로 실행합니다.
  • 숫자키 빠른 실행: 퀵 윈도우에서는 Ctrl + 1–9를 눌러 상위 9개 결과를 즉시 열 수 있습니다.

액션 메뉴 및 확장 조작 ​

강조된 항목에서 Ctrl+O 또는 방향키 →를 누르면 액션 메뉴가 열리며, 경로 복사, 속성 확인, 파일 조작, 플러그인 확장 기능 등을 실행할 수 있습니다. 이 두 키는 퀵 윈도우와 파일 대화상자 밖의 인라인 카드용이며, 메인 윈도우에서는 대신 우클릭 또는 Apps 키를 사용하세요. 자세한 내용은 액션 및 미리보기와 단축키를 참조하세요.
