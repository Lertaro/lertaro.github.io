검색 기록 ​

기록 설정 페이지에서는 경로별 사용 빈도, 입력한 검색어, 확인된 검색어 연결을 검색 기록·키워드 기록·검색어 연결의 3개 독립 탭에서 관리합니다.

1. 검색 기록 (Search History) ​

실제로 실행한 파일, 폴더, 앱의 실행 빈도와 최근 시간을 기록하여 비슷한 관련성을 가진 직접 일치 결과 사이의 순서를 정교하게 조정합니다.

  • 감쇠 빈도 기반 미세 정렬: 자주 여는 항목은 90일 반감기 점수로 동일한 일치 등급 안에서 우선 정렬되며, 정확한 직접 이름 일치를 앞지르지 않습니다.
  • 인라인 윈도우 스마트 분류: 파일 대화상자의 인라인 검색 시 현재 열린 폴더 내부 항목은 "현재 폴더", 나머지는 "전체 검색"으로 분류됩니다.
  • 삭제된 경로 자동 필터링: 이동되거나 삭제된 경로는 결과에서 자동 제외됩니다.
  • 관리 기능:
    • 기록 기능 활성화, 검색 필터링, N회 이하 기록 지우기, 개별 삭제 및 모든 기록 삭제, 실시간 횟수 갱신을 지원합니다.

2. 키워드 기록 (Keyword History) ​

결과나 액션을 실행했거나 해당 검색어로 메인 윈도우를 열 때 실제로 사용한 원시 검색 문자열 자체를 기억합니다.

  • 단축키 빠른 탐색: 퀵 검색창에서 Alt+Up(이전) / Alt+Down(다음)으로 과거 검색어를 탐색하고 Ctrl+Delete로 즉시 삭제할 수 있습니다.
  • 독립 관리: 전용 활성화 스위치, 필터링, N회 이하 기록 지우기, 개별 삭제 및 모든 기록 삭제를 제공합니다.

3. 검색어 연결 (Query Associations) ​

경로별 일반 사용 빈도와 분리하여 확인된 검색어 → 대상 경로 연결을 저장합니다.

  • 3회 직접 실행 임계값: 정규화된 동일 검색어에서 3회 이상 직접 선택해 실행한 항목만 보조 후보로 재호출되어 일회성 오클릭 오염을 방지합니다.
  • 자가 강화 루프 차단: 학습된 보조 결과에서 다시 실행해도 미확인 횟수가 부풀려지지 않으며 항상 직접 일치 뒤에 배치됩니다.
  • 독립 정리: 경로별 사용 빈도를 유지한 채 개별 연결 삭제 또는 전체 초기화를 수행할 수 있습니다.
