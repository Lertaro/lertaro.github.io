모양 및 테마 ​

Lertaro는 세련되고 현대적인 비주얼 디자인 시스템을 갖추고 있으며, 정밀한 테마 모드 전환과 다채로운 색상 팔레트를 제공합니다. 모양 설정은 설정 센터 좌측 사이드바 하단("정보" 바로 위)에 위치합니다.

1. 테마 모드 (Theme Modes) ​

상단에 제공되는 세 가지 모드 카드 중 하나를 선택할 수 있습니다.

  • 라이트 모드 (Light): 밝은 인터페이스 스타일로 고정하며 하단 그리드에 라이트 테마만 표시됩니다.
  • 다크 모드 (Dark): 어두운 인터페이스 스타일로 고정하며 하단 그리드에 다크 테마만 표시됩니다.
  • 시스템 설정 따름 (Follow System): Windows 시스템의 밝은/어두운 모드 전환에 맞춰 자동으로 테마가 실시간 변경됩니다. 이 모드에서는 하단 그리드가 라이트 테마와 다크 테마 선택 영역으로 나뉘어 낮과 밤에 각각 사용할 색상 조합을 지정할 수 있으며 앱 재시작 없이 매끄럽게 전환됩니다.

NOTE

Lertaro는 라이트 모드와 다크 모드에서 각각 선택한 테마를 독립적으로 기억하므로 모드를 오가도 선택이 초기화되지 않습니다.

2. 테마 선택 카드 ​

테마 선택 영역은 시각적인 썸네일 카드 그리드로 제공됩니다. 각 카드는 검색창, 그림자 테두리, 폰트 위계 및 강조 선택 행의 실제 색상을 정확히 미리 보여주며 현재 적용 중인 테마에는 체크 배지가 표시됩니다.

기본 및 번들 테마 안내 ​

  • 코어 기본 테마 (CoreExtensions):
    • 라이트 (Light) / 다크 (Dark): Windows 네이티브 스타일에 자연스럽게 어우러지는 깔끔하고 미니멀한 흑백 기반 디자인.
    • 노르딕 블루 (Nordic Blue): 딥 네이비 배경에 부드러운 아이스 블루 액센트가 어우러진 쿨톤 긱 스타일.
    • 사쿠라 핑크 (Sakura Pink): 은은하고 산뜻한 파스텔톤 핑크 & 화이트 배색.
    • 사이버펑크 (Cyberpunk): 네온 옐로우와 미드나잇 퍼플이 대비를 이루는 미래지향적 감성.
  • 애니메이션 테마 (AnimeThemes, 번들 제공):
    • 에반게리온 (Evangelion), 벚꽃 만개 (Sakura Blossom), 날씨의 아이 (Weathering with You).
  • 큐레이션 테마 세트 (Curated Themes, 번들 제공):
    • 라이트/다크가 쌍을 이루는 10가지 세련된 테마: 글래시어 블루 (Glacier Blue), 테라코타 (Terracotta), 포레스트 그린 (Forest Green), 애메지스트 (Amethyst), 크림슨 (Crimson), 그래파이트 (Graphite), 인디고 나이트 (Indigo Night), 민트 시안 (Mint Cyan), 샴페인 골드 (Champagne Gold), 앰버 골드 (Amber Gold).

플러그인 테마 확장 ​

모든 테마는 Lertaro.PluginSdk의 UI 테마 표준 규격에 따라 개발되었습니다. 서드파티 개발자는 커스텀 테마 플러그인을 제작하여 이 그리드에 새로운 색상 조합을 등록할 수 있습니다.
