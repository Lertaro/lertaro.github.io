일반 ​

여섯 개의 탭: 시스템, 퀵 검색 창, 전체 검색 창, 미리보기, 빠른 탐색, 미리보기 및 썸네일입니다.

시스템 ​

  • Windows와 함께 Lertaro 시작 — 체크박스, 로그인 시 Lertaro를 실행합니다.
  • 시작 시 업데이트 자동 확인 — 체크박스입니다.
  • 새 버전이 감지되면 자동 무음 업데이트 — 체크박스이며, 위의 확인 옵션이 켜져 있을 때만 활성화됩니다. 묻지 않고 백그라운드에서 업데이트를 다운로드하고 설치합니다.
  • 하드웨어 가속 활성화 — 체크박스, 기본값 켜짐. 이를 끄면 퀵 검색 창이 Direct3D를 사용하는 대신 소프트웨어로 렌더링하도록 강제합니다 — NVIDIA Advanced Optimus가 Lertaro 실행 중에 GPU를 즉시 전환하는 것을 거부하는 문제를 우회합니다(영향을 받는 것은 퀵 창뿐이며, 앱 전체가 아닙니다). 적용하려면 Lertaro를 재시작해야 합니다.
  • 트레이 아이콘 숨기기 — 체크박스, 기본값 꺼짐. 즉시 적용되며 재시작이 필요 없습니다. 트레이 아이콘 우클릭 시 나타나는 것과 동일한 메뉴는 이 설정과 무관하게 퀵 창 자체의 로고에서 항상 사용할 수 있으므로, 트레이 아이콘을 숨겨도 설정이나 종료로 돌아갈 방법이 없어지는 일은 없습니다.
  • 새 파일 탐색기 탭에서 폴더 열기 — 체크박스, 기본값 꺼짐. Windows 11에서 기본 파일 탐색기 창이 이미 열려 있으면 열기와 포함된 폴더 열기가 새 탭을 사용합니다. 후자는 대상 항목도 선택합니다. 파일 탐색기 창이 없으면 Windows가 첫 항목을 일반 창으로 열고, 이후 항목부터 탭을 사용합니다. 이 실험적 통합은 타사 파일 관리자가 설정된 경우 적용되지 않습니다.
  • 퍼지 매칭 사용 — 체크박스, 기본값 켜짐. 켜져 있으면 일반 검색어는 그 문자들이 이름 어딘가에 순서대로 나타나기만 해도 매칭됩니다. 끄면 일반 검색어는 연속된 부분 문자열로 나타나야 합니다 (abc는 더 이상 a-b-c에 매칭되지 않습니다) — 무엇이 바뀌고 무엇이 그대로인지는 검색 문법을 참고하세요. 즉시 적용되며 재시작이 필요 없습니다.
  • 쿼리 토큰 전체 접두사 문자 — 텍스트 상자(최대 1자, 기본값 :). 검색창 끝의 토큰식을 분할하는 전체 접두사 문자를 설정합니다. 경로 제외 및 사용자 지정 필터의 접두사 문자는 설정 → 플러그인 → CoreExtensions에서 개별 설정할 수 있습니다.
  • 로그 레벨 — 드롭다운: Error / Warn / Info(기본값) / Debug. App, Service, Hook 로그 전반의 상세도를 제어합니다(서비스 상태 참고).
  • 인터페이스 언어 — 드롭다운으로, 설치된 모든 번역 제공자(내장 언어와 플러그인이 추가한 언어)로 채워집니다.

테마 선택은 자체 외관 섹션으로 이동했습니다 — 테마 선택기와 "시스템의 라이트/다크 설정 따르기" 옵션은 해당 페이지를 참고하세요.

퀵 검색 창 ​

퀵 검색 바의 외관과 검색 결과의 우선순위가 정해지는 방식을 모두 다룹니다.

검색 바 레이아웃 — 퀵 검색 바의 크기와 화면상 위치를 커스터마이즈합니다.

  • 검색 바 너비 (px) — 범위 300~1200px, 기본값 570px.
  • 검색 바 높이 (px) — 범위 45~120px, 기본값 60px. 이 값 하나가 결과 행의 아이콘 크기, 이름/경로 글꼴 크기, 행 높이(height / 60)까지 함께 결정하므로, 검색 바를 더 높게 만들면 아이콘과 텍스트 사이의 비율을 항상 그대로 유지하면서 결과 목록 전체가 함께 커집니다.
  • 검색 상자에 시계 표시 — 체크박스, 기본값 꺼짐. 검색 상자가 비어 있는 동안, 평소의 "입력하여 검색..." 자리표시자 텍스트 대신 현재 날짜, 요일, 시간을 표시합니다. 대체하는 자리표시자와 마찬가지로 입력을 시작하는 순간 사라집니다. 퀵 창 전용이며, 인라인 창은 이 설정이 켜져 있어도 항상 평소의 자리표시자를 유지합니다.
  • 반복 단축키 입력 시 전체 창으로 다시 열기 — 체크박스, 기본값 꺼짐. 평소에는 퀵 창이 이미 열려 있는 상태에서 토글 단축키를 다시 누르면 그냥 숨겨지지만, 이를 켜면 두 번째로 누를 때 아무것도 닫는 대신 전체 창으로 전환합니다(이미 입력했던 쿼리를 그대로 가져갑니다).
  • 위치 잠금 — 체크박스, 기본값은 꺼짐. 켜면 빠른 창을 끌 수 없게 하여, 실수로 눌러 놓아둔 자리에서 밀려나는 일을 막습니다. 로고를 우클릭해 위치를 초기화하는 것은 그대로 사용할 수 있으며, 아래의 레이아웃 설정 초기화는 이 잠금도 나머지와 함께 해제합니다.
  • 레이아웃 설정 초기화 버튼 — 위의 다섯 가지 설정을 모두 기본값으로 되돌립니다.

퀵 창의 로고를 우클릭하면 화면상 위치만(크기는 아님) 초기화되며, 처음 실행했을 때와 같은 방식으로 다시 가운데로 맞춰집니다.

결과 유형 우선순위 — 아래의 빠른 탐색에서 사용하는 것과 동일한 위/아래 화살표 (또는 드래그하여 재정렬) 목록입니다. 결과 유형(애플리케이션, 설정, File Filters, 서드파티 플러그인 자체의 검색 가능한 항목, 또는 내장 "파일" 항목)을 위나 아래로 옮기면, 실제로 어느 것이 쿼리 텍스트에 더 잘 매칭되었는지와 무관하게 퀵 창 결과에서 항상 아래에 있는 유형보다 우선하게 만들 수 있습니다. 즐겨찾기와 기록은 항상 가장 먼저 나오며 이 목록에 포함되지 않습니다.

각 유형은 자체적인 한 글자 트리거도 가질 수 있습니다(선택 사항, 행마다 텍스트 상자 하나). 퀵 창의 맨 처음에 그 문자를 입력하면 그 유형의 결과만 표시되고 나머지는 모두 숨겨집니다 — 예시는 검색 문법을 참고하세요. 트리거만 입력하고 뒤에 아무것도 없으면 "검색 결과 없음" 대신 "계속 입력하면 X만 검색합니다" 안내가 표시됩니다. 유형에 한번 할당되면 예약되므로, 평소에 실제 검색을 시작할 때 절대 쓰지 않을 문자를 고르세요 — 아무것도 입력하지 않은 상태의 공백 하나는 빈 검색 상자와 동일하게 취급되어 그 안내가 표시되지 않으므로, 구두점 문자(예: ;)가 단순한 공백보다 더 안정적으로 동작합니다.

전체 검색 창 ​

전체/메인 검색 창(작업 표시줄이나 시작 메뉴 바로가기로 얻는 더 큰 창으로, 퀵 팝업과 대비됩니다. 시작하기 참고)의 기본 크기를 설정합니다.

  • 창 너비 (px) — 범위 640~2000px, 기본값 854px.
  • 창 높이 (px) — 범위 400~1400px, 기본값 480px. 최솟값은 창 자체의 크기 조절 하한과 일치하므로, 구성된 값이 창 자체에 의해 조용히 무시되는 일은 없습니다.
  • 검색 창 설정 초기화 버튼.
  • 전체 검색 창을 하나만 허용 — 체크박스이며 기본값은 꺼짐입니다. 꺼져 있으면 서로 독립적인 전체 창을 여러 개 열 수 있습니다. 켜면 전체 창을 다시 열 때 새 창을 만들지 않고 기존 창을 활성화합니다. 퀵 창의 더 보기에서 쿼리를 넘겨받으면 해당 쿼리가 기존 창의 쿼리를 대체합니다.

창의 가장자리를 드래그하여 수동으로 크기를 조절하면 자동으로 기억됩니다 — 다음에 창을 열 때(또는 새 창을 열 때) 마지막으로 남긴 크기 그대로 다시 나타나며, 이 페이지의 필드도 그에 맞게 갱신됩니다. 최대화된 상태에서 크기를 조절해도 기억된 크기는 덮어써지지 않습니다 — 일반(최대화되지 않은) 상태에서 크기를 조절할 때만 저장됩니다.

전체 창의 결과 목록에는 즐겨찾기나 기록의 개인화된 불러오기 항목이 앞에 추가되지 않습니다. 이러한 결과는 퀵 창과 인라인 창에만 남으며, 전체 창은 활성 검색 공급자가 제공하는 일반적인 관련성 순서를 유지합니다.

결과 그리드 열 순서 — 설정의 다른 곳에서 사용하는 것과 동일한 재정렬 목록입니다(즐겨찾기 참고). 결과 그리드 열(이름, 경로, 수정된 날짜, 또는 플러그인이 제공하는 열)을 왼쪽이나 오른쪽으로 옮깁니다. 그리드/테이블 결과 레이아웃에만 영향을 주며, 간결한 목록 레이아웃에는 재정렬할 열이 없습니다.

사이드바 필터 순서 — 같은 방식으로, 사이드바 필터 그룹(유형, 수정된 날짜, 플러그인이 추가한 그룹)이 나타나는 순서를 정합니다.

동작 메뉴 섹션 순서 — 같은 방식으로, 동작 메뉴의 섹션들 — 내장 동작 그룹과, 그곳에 동작을 기여하는 플러그인마다 하나씩(예: Custom Actions, 또는 Windows 셸 마우스 우클릭 메뉴)의 섹션 — 이 나타나는 순서를 정합니다. 아직 이 목록에 없는 섹션은 원래의 위치로 돌아갑니다(내장 섹션이 먼저, 그다음 기여된 순서대로 플러그인 섹션).

결과 그리드 열 헤더를 클릭하면 오름차순, 내림차순, 그리고 세 번째 클릭에서는 기본 관련성 순위 순서로 되돌아가는(헤더의 정렬 화살표가 사라짐) 세 상태를 순환합니다. 이는 Lertaro가 실행 중인 동안에만 기억됩니다 — 앱을 종료하면(창을 닫는 것만으로는 안 됩니다) 다음에 열 때 정렬이 기본값으로 초기화되며, 이는 영구적으로 저장되는 위의 열/사이드바 순서와는 다릅니다.

미리보기 ​

  • 미리보기 너비 (px) — 범위 250~900px.
  • 미리보기 높이 (px) — 범위 250~1200px, 일반적인 디스플레이에서 패널이 지나치게 높지 않도록 기본값이 정해져 있습니다.
  • 미리보기 창 설정 초기화 버튼.

미리보기 창은 현재 결과 개수를 무시합니다 — 콘텐츠에 따라 커지는 크기가 아니라 고정된 크기입니다. 패널이 어떻게 위치하는지는 동작 메뉴 및 미리보기를 참고하세요.

빠른 탐색 ​

빠른 탐색 메뉴의 루트 레벨 섹션이 나타나는 순서를 설정합니다 — 기여하는 제공자마다 하나씩의 섹션(예: 즐겨찾기/기록/구성된 폴더, Total Commander의 Directory Hotlist, Directory Opus의 즐겨찾기, 플러그인 자체의 빠른 탐색 항목)이 있으며, 각각 자체 헤더로 레이블이 붙습니다.

제공자 순서 — 설정의 다른 곳에서 사용하는 것과 동일한 위/아래 화살표(또는 드래그하여 재정렬) 목록입니다 (즐겨찾기 참고). 제공자를 위나 아래로 옮기면 그 섹션이 다른 것들에 비해 어디에 자리 잡을지가 바뀝니다. 여기에는 현재 플러그인 컴포넌트가 활성화된 제공자만 나열됩니다 — 플러그인에서 비활성화된 제공자는 애초에 메뉴 후보가 되지 않으므로, 정렬할 것이 없습니다.

미리보기 및 썸네일 ​

각각 자체 작업에 대해 어느 제공자가 먼저 거부권을 가질지 결정하는, 독립적인 두 개의 우선순위 순서 목록입니다. 평소에는 이를 순전히 각 제공자 자체의 고정된 내장 우선순위로만 결정하며, 제공자를 완전히 비활성화하는 것 외에는 이를 바꿀 방법이 없습니다.

File Preview Provider 순서 — 파일 미리보기 제공자용입니다 (예를 들어 QuickLook Bridge 플러그인은 모든 내장 미리보기 도구보다 위에 자체 우선순위를 둡니다). 설정의 다른 곳에서 사용하는 것과 동일한 위/아래 화살표(또는 드래그하여 재정렬) 목록입니다(즐겨찾기 참고). 제공자를 위로 옮기면 자체 내장 우선순위와 무관하게 항상 아래에 있는 것들보다 우선하게 됩니다. 여기에는 현재 플러그인 컴포넌트가 활성화된 제공자만 나열됩니다 — 플러그인에서 비활성화된 제공자는 어차피 아무것도 미리보기하지 않습니다.

Thumbnail Provider 순서 — 같은 방식으로, 검색 목록 자체에서 결과 옆에 표시되는 아이콘/썸네일용입니다 (미리보기 패널과는 별개입니다). 오늘날에는 내장 제공자가 하나뿐이므로, 둘 이상의 플러그인이 커스텀 썸네일 제공자를 구현했을 때 가장 의미가 있습니다.
