일반 설정 ​

일반 설정에서는 Lertaro의 핵심 시스템 동작, 검색창의 픽셀 단위 크기 및 레이아웃, 결과 유형별 우선순위, 미리보기 제공자 순서 등을 관리합니다. 상단에는 시스템, 퀵 검색 윈도우, 메인 검색 윈도우, 미리보기 윈도우, 퀵 내비게이션, 미리보기 및 썸네일의 6개 탭이 제공됩니다.

1. 시스템 (System) ​

  • Windows 시작 시 자동 실행: Windows 로그인 시 Lertaro를 자동 실행합니다.
  • 시작 시 자동 업데이트 확인: 앱 실행 시 최신 버전이 있는지 온라인으로 자동 확인합니다.
  • 무음 자동 업데이트: "업데이트 확인"이 켜져 있을 때 활성화되며, 백그라운드에서 조용히 다운로드하고 팝업 없이 즉시 덮어쓰기 업데이트합니다.
  • 하드웨어 가속 사용: 기본 활성화. 듀얼 GPU 노트북(예: NVIDIA Advanced Optimus)에서 Lertaro로 인해 내장 그래픽 자동 전환이 차단되는 경우 소프트웨어 렌더링으로 전환할 수 있습니다. 변경 후 재시작이 필요합니다.
  • 트레이 아이콘 숨기기: 작업 표시줄 알림 영역의 아이콘을 숨깁니다. 퀵 검색바 내부의 로고를 클릭하면 동일한 트레이 메뉴가 열리므로 진입점이 사라지지 않습니다.
  • Everything 호환 서비스 (IPC) 활성화: 표준 Everything Win32 IPC 프로토콜을 에뮬레이트하여 Directory Opus, Total Commander 등에서 Lertaro 메모리 인덱스를 직접 호출할 수 있도록 합니다.
  • 퍼지 매칭 활성화: 기본 활성화. 연속되지 않은 문자 점프 매칭을 지원하며, 끄면 연속된 부분 문자열만 일치시킵니다(검색 문법 참고). 즉시 적용됩니다.
  • 쿼리 토큰 접두 문자: 1자리 텍스트 상자(기본값 :). 검색어 끝의 속성 토큰(예: :.pdf, :@doc, :[S])의 기준 문자를 지정합니다.
  • 로그 레벨: "오류 / 경고 / 정보 (기본값) / 디버그" 중 선택하여 프로세스별 로그 출력 상세도를 제어합니다.
  • UI 언어: 앱 전체의 표시 언어를 선택합니다.

2. 퀵 검색 윈도우 (Quick Search Window) ​

화면 중앙에 뜨는 퀵 검색바의 크기와 결과 우선순위를 세밀하게 조정합니다.

검색바 레이아웃 ​

  • 검색바 너비 (픽셀): 설정 범위 300–1200px, 기본값 570px.
  • 검색바 높이 (픽셀): 설정 범위 45–120px, 기본값 60px. 이 값에 비례하여 결과 행의 아이콘 크기, 행 높이, 폰트 크기가 자동으로 균형 있게 조절됩니다.
  • 검색창 내 시계 표시: 검색어가 비어 있을 때 안내 문구를 현재 날짜, 요일, 시간으로 대체합니다. 입력을 시작하면 자동으로 사라집니다.
  • 단축키 재입력 시 메인 윈도우 열기: 퀵 윈도우가 열린 상태에서 호출 단축키를 다시 누르면 현재 검색어를 유지한 채 메인 윈도우로 즉시 전환합니다.
  • 위치 고정: 마우스 드래그로 검색바 위치가 이동되는 것을 방지합니다.
  • 레이아웃 설정 초기화: 모든 크기 및 레이아웃을 기본값으로 복원합니다.

결과 유형 우선순위 및 트리거 문자 ​

  • 우선순위 정렬 목록: 핸들을 드래그하여 앱, 시스템 설정, 파일, 플러그인 항목의 표시 순서를 변경합니다. 상위에 배치된 유형이 검색 결과에서 더 높은 가중치를 가집니다.
  • 전용 단일 문자 트리거: 특정 유형에 단일 문자 접두사(예: 파일 필터에 ;)를 부여하여 검색어 맨 앞에 입력 시 해당 유형으로만 즉시 필터링합니다.

3. 메인 검색 윈도우 (Full Search Window) ​

대화면 메인 검색창(Ctrl+F)의 기본 크기와 테이블 뷰를 설정합니다.

  • 창 너비 / 높이 (픽셀): 너비 640–2000px(기본값 854px), 높이 400–1400px(기본값 480px).
  • 메인 윈도우 단일 인스턴스 유지: 켜면 메인 창을 다시 열 때 새 창을 띄우지 않고 기존 창에 포커스를 줍니다.
  • 검색 윈도우 설정 초기화: 기본 크기로 복원합니다.
  • 결과 테이블 열 순서: 테이블 뷰에서 각 열(이름, 경로, 수정일 등)의 표시 순서를 드래그로 변경합니다.
  • 사이드바 필터 순서: 좌측 사이드바 필터 그룹의 순서를 변경하며, 각 분류별 일치 항목 수가 실시간 표시됩니다.
  • 액션 메뉴 그룹 순서: Ctrl+O 액션 메뉴 내의 그룹 표시 순서를 조정합니다.

4. 미리보기 윈도우 (Preview Window) ​

  • 미리보기 너비 / 높이 (픽셀): 너비 250–900px, 높이 250–1200px.
  • 미리보기 설정 초기화: QuickLook 미리보기 창을 표준 비율로 복원합니다(화면 밖 벗어남 자동 방지).

5. 퀵 내비게이션 (Quick Navigation) ​

  • 제공자 순서: 마우스 퀵 내비게이션 계단식 메뉴의 루트 카테고리(즐겨찾기, 기록, 열린 폴더, 파이러 북마크 등) 정렬 순서를 변경합니다.

6. 미리보기 및 썸네일 (Previews & Thumbnails) ​

  • 파일 미리보기 제공자 순서: 내장 미디어 디코더와 타사 QuickLook 브리지 등의 호출 우선순위를 조정합니다.
  • 썸네일 제공자 순서: 파일 아이콘 및 썸네일 추출 컴포넌트의 우선순위를 조정합니다.
