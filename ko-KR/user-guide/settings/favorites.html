즐겨찾기 ​

즐겨찾기는 자주 사용하는 폴더, 파일, 스크립트 또는 웹 URL을 고정 등록하여 전용 사용자 지정 이름과 최우선 검색 순위를 부여하는 기능입니다. 설정 경로는 설정 → 즐겨찾기입니다.

1. 즐겨찾기 항목 추가 ​

상단 등록 폼에서:

  • 표시 이름: 선택 사항. 비워둘 경우 대상이 로컬 경로이면 해당 파일이나 폴더의 이름이 자동으로 채워집니다.
  • 대상 경로: 로컬 파일/폴더의 절대 경로, %USERPROFILE% 같은 환경 변수, shell:Downloads 같은 Windows 셸 가상 경로 또는 http:// / https://로 시작하는 웹 URL을 입력할 수 있습니다.
  • 찾아보기: 폴더 찾아보기 또는 파일 찾아보기를 클릭하여 네이티브 파일 선택기로 직접 지정.
  • 추가: 유효한 경로를 입력한 후 추가 버튼을 클릭하여 저장.

2. 목록 관리 및 드래그 앤 드롭 정렬 ​

등록된 항목은 하단 목록에 표시되며 다음과 같이 관리할 수 있습니다.

  • 6점 드래그 핸들 정렬: 각 행 좌측의 6점 핸들을 드래그하여 순서를 변경하거나 우측의 위로 이동 / 아래로 이동 버튼을 사용할 수 있습니다. 이 순서는 검색 결과와 퀵 내비게이션 메뉴의 노출 우선순위에 즉시 반영됩니다.
  • 인라인 편집: 편집을 클릭하면 해당 행이 즉시 편집기로 바뀌며, 같은 행에서 저장하거나 취소할 수 있습니다. 상단 추가 폼을 재사용하지 않습니다.
  • 삭제: 즐겨찾기에서 항목을 안전하게 제거합니다.
  • 목록 지우기: 목록에 항목이 있으면 목록 제목 오른쪽의 버튼으로 모든 즐겨찾기를 한 번에 삭제할 수 있으며, 목록이 비어 있으면 버튼이 숨겨집니다.

검색 결과의 액션 메뉴에서 존재하는 파일 또는 폴더 하나를 바로 즐겨찾기에 추가할 수도 있습니다. Lertaro는 표시 이름을 입력하는 대화상자를 열며, 같은 경로가 이미 즐겨찾기에 있으면 이 액션을 표시하지 않습니다.

3. 검색 재호출 및 시각적 표시 ​

  • 별표 배지 (★): 검색 결과에 즐겨찾기 항목이 일치하면 경로 옆에 눈에 띄는 ★ 배지가 표시됩니다.
  • 커스텀 별칭 검색: 깊숙한 경로에 기억하기 쉬운 별칭을 부여할 수 있습니다(예: D:\Workspace\2026\Q1\Financial\Summary.xlsx에 재무총괄 지정). 검색창에 해당 이름을 입력하면 호출됩니다.
  • 다중 인터페이스 연동: 등록된 즐겨찾기는 퀵 내비게이션 메뉴 및 퀵 패널의 "즐겨찾기" 탭에 자동 동기화됩니다.
