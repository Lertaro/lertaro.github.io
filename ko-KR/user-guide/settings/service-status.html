서비스 상태 ​

서비스 상태 페이지에서는 Lertaro의 백그라운드 인덱싱 서비스의 동작 상태를 모니터링하고 Service, App, Hook 세 프로세스의 실시간 통합 로그를 확인할 수 있습니다. 설정 경로는 설정 → 서비스 상태입니다.

1. 서비스 상태 및 제어 ​

상단 상태 카드에서는 관리자 권한 백그라운드 서비스의 상태를 실시간으로 확인합니다.

  • 상태 표시:
    • 준비 완료 (Ready): 서비스가 정상 작동 중이며 현재 인덱싱된 파일 및 폴더의 총 개수를 표시.
    • 인덱싱 중 (Indexing): 초기 인덱스 구축 또는 증분 스캔 진행 중(스피너 표시).
    • 설치 중 (Installing): Windows 서비스 등록 및 구동 처리 중.
    • 오류 (Error): 서비스가 중지되었거나 비정상 종료된 상태(경고 마크 및 오류 설명 표시).
  • 자가 치유 및 설치 버튼: 서비스가 미설치 상태이거나 오류가 발생했을 때만 서비스 설치 및 시작 버튼이 나타납니다. 정상 작동 중에는 실수로 인한 중단을 방지하기 위해 백그라운드에서 항상 상주합니다.

2. 3대 프로세스 실시간 로그 뷰어 ​

하단 로그 뷰어는 Lertaro를 구성하는 세 개의 프로세스에 대응하는 독립된 탭으로 구성됩니다.

  • App 탭: 전면 WPF UI, 검색 인터랙션, 단축키 처리, 창 렌더링 로그.
  • Hook 탭: 저수준 전역 키보드 후크 프로세스(Lertaro.Service.exe --hook)의 키 감지 및 격리 상태 로그.
  • Service 탭: 관리자 권한 백그라운드 서비스(Lertaro.Service.exe)의 USN 저널 파싱, 디스크 스캔, 메모리 트리 구축 및 IPC 통신 로그.

필터링 및 로그 초기화 ​

  • 로그 레벨 필터: "전체 / 오류 / 경고 / 정보 / 디버그"를 선택할 수 있으며 심각도에 따라 색상 강조 표시.
  • 실시간 검색 필터: 검색어를 입력하여 현재 로그 내용을 필터링.
  • 안전한 로그 초기화: 로그 지우기를 클릭하여 현재 탭의 로그를 초기화합니다. Service 탭 로그는 IPC를 통해 안전하게 비워집니다.
