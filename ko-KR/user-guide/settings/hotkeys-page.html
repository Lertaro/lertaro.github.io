단축키 설정 ​

단축키 설정 페이지에서는 Lertaro의 모든 전역 호출 키, 앱 내 탐색 단축키, 플러그인 액션 바로가기 및 프로세스 블랙리스트 규칙을 통합 관리합니다. 상단에는 전역, 플러그인 액션, 프로세스 블랙리스트의 3개 탭이 제공됩니다.

1. 전역 (Global) ​

전역 단축키 그룹 ​

  • 퀵 검색 표시/숨기기: 전용 키 녹화 컨트롤. 수식키 더블 클릭 모드(기본값 Ctrl 더블 클릭, Alt나 Shift로도 가능) 및 일반 조합키(예: Alt+Space 등)를 모두 지원합니다.
  • 전체 패널을 기본으로 열기: 체크박스(기본 비활성화). 켜면 전역 호출 단축키가 퀵 윈도우 대신 메인 윈도우를 엽니다. 처음 표시될 때는 한 번만 전경 및 포커스를 처리하고, 표시되어 있지만 비활성 상태이면 다시 활성화하며, 이미 활성 상태이면 기본적으로 다시 눌렀을 때 퀵 윈도우로 돌아가고 단축키 재입력 시 전체 창 닫기가 켜져 있을 때만 바로 닫습니다. 창을 자동으로 항상 위에 유지하지는 않습니다.
  • 전체화면 앱 포커스 시에도 응답: 체크박스(기본 비활성화). 켜면 전체화면 게임이나 동영상 재생기가 활성화되어 있어도 단축키에 응답하며, 끄면 게임 플레이를 보호하기 위해 단축키를 통과시킵니다.
  • 퀵 점프 (Quick Jump): 기본값 Ctrl+G. 파일 대화상자에서 최근 탐색했던 폴더로 즉시 이동합니다.
  • 퀵 내비게이션 메뉴: 기본 단축키 없음. 선택한 전역 단축키를 지정해 계층형 메뉴를 열 수 있습니다. 바탕화면이나 일반 앱에서는 바탕화면 컨텍스트를 사용하고, 파일 탐색기와 네이티브 파일 대화상자에서는 현재 창 컨텍스트를 사용합니다. 일반 전경 보호로 전역 단축키가 억제되는 경우에도 파일 관리자와 파일 대화상자는 허용됩니다.

기능 키 그룹 ​

임의의 단일 키 또는 조합키를 지정할 수 있는 독립 녹화 컨트롤을 제공합니다.

  • 다음 / 이전 항목 선택: 기본값 Ctrl+N / Ctrl+P(방향키 ↓ / ↑와 동일).
  • 결과 이동 수식키: 기본값 Ctrl, 숫자키 1–9와 조합하여 즉시 실행.
  • 액션 메뉴 열기: 기본값 Ctrl+O(방향키 →와 동일). 두 키 모두 퀵 윈도우와 파일 대화상자 밖의 인라인 카드에 적용되며, 메인 윈도우에서는 우클릭 또는 Apps 키로 같은 메뉴를 엽니다.
  • 선택 항목으로 검색어 자동완성: 기본값 Ctrl+Tab.
  • QuickLook 즉시 미리보기: 기본값 Alt+P.
  • 이전 / 다음 검색 기록어: 기본값 Alt+Up / Alt+Down.
  • 현재 검색 기록어 삭제: 기본값 Ctrl+Delete.
  • 메인 윈도우 열기: 기본값 Ctrl+F.
  • LocalSend 창 열기: 기본값 Ctrl+S.
  • 창 고정 (항상 유지): 기본값 Ctrl+T.
  • 퀵 패널 표시/숨기기: 기본값 Ctrl+F2.

퀵 내비게이션 마우스 트리거 그룹 ​

  • 빈 공간 좌클릭 더블클릭: 체크박스(기본 비활성화). 바탕화면이나 탐색기 빈 공간 더블클릭 시 메뉴 표시.
  • 빈 공간 휠클릭: 체크박스(기본 활성화). 바탕화면, 탐색기 또는 파일 대화상자에서 휠클릭 시 메뉴 표시.

더블클릭 방식은 바탕화면과 파일 탐색기에서만 작동하며, 서드파티 파일 관리자는 휠클릭만 인식합니다. 포인터가 Lertaro 자체 카드 위에 있는 동안에는 두 트리거 모두 건너뛰고, 블랙리스트나 전체화면 때문에 전역 트리거가 침묵할 때에도 파일 관리자와 대화상자에서는 두 트리거가 계속 동작합니다.

단축키 입력하기 ​

어떤 키를 누르든 뒤의 앱이 아니라 입력 상자에 기록되므로, 입력 상자 자체에도 제스처가 있습니다.

  • Escape: 입력을 취소하면서 값을 지웁니다. "취소하고 되돌리기"는 없습니다. 누르는 순간 상자가 비어 있습니다.
  • ✕: 상자를 지웁니다. ↺: 그 행의 제조사 기본값을 복원합니다. 두 버튼은 항상 그중 하나만 보입니다: 조합이 입력되어 있으면 지우기, 비어 있으면 복원이 표시됩니다.
  • 수식키 단독 입력(Ctrl, Alt, Shift): 그것만으로 의미가 있는 행에서만 허용됩니다. 더블 클릭 방식이 되는 호출 단축키와 결과 이동 수식키가 그렇습니다. 일반 조합키 행에서 수식키만 누르고 놓으면 절대 실행될 수 없는 값을 저장하는 대신 그 행이 지워집니다.
  • Windows 예약 조합(Win+E, Win+D 등)은 거부됩니다: 값이 강제로 비워지므로 상자가 그대로 빈 상태가 됩니다.
  • 충돌 감지는 없습니다. 두 행이 같은 조합을 가져도 경고하지 않으며, 즐겨찾기 항목 단축키에서만 중복 또는 OS가 거부한 조합을 알려 주고, 그것도 적용한 뒤에 알려 줍니다.

즐겨찾기 항목별 단축키 ​

각 즐겨찾기(설정 → 즐겨찾기)는 자체 OS 레벨 전역 단축키를 가질 수 있습니다. Lertaro 창이 하나도 열려 있지 않을 때도 작동하며, 전경 파일 관리자를 해당 폴더로 이동시킵니다. 위의 입력 상자와 달리 반드시 수식키가 필요하고, 수식키 단독은 허용되지 않으며, F12는 사용할 수 없습니다.

2. 플러그인 액션 (Plugin Actions) ​

각 플러그인이 등록한 전용 액션 단축키(예: 경로 복사 Ctrl+Shift+C, 이름 복사 Shift+C, 잘라내기 Ctrl+X, 복사 Ctrl+C, 붙여넣기 Ctrl+V, 삭제 Delete, 영구 삭제 Shift+Delete 등)가 여기에 모여 있습니다.

  • 플러그인별 그룹화: 제공 플러그인별로 깔끔하게 정리되어 있습니다.
  • 개별 재등록: 각 액션마다 전용 녹화 상자가 제공되어 새 키를 입력해 즉시 변경할 수 있습니다.

3. 프로세스 블랙리스트 (Process Blacklist) ​

특정 프로그램이 활성화되었을 때 Lertaro의 단축키와 마우스 제스처를 무시하도록 설정합니다.

  • 대소문자 무관: game.exe 또는 game 모두 지원합니다.
  • 개별 추가: 프로세스 이름을 입력하고 프로세스 추가를 클릭합니다.
  • 일괄 관리: 텍스트 생성을 눌러 현재 목록을 내보내거나, 붙여넣은 후 목록에 적용을 눌러 일괄 갱신할 수 있습니다.
  • 파일 대화상자 자동 예외: 블랙리스트 앱이라 하더라도 표준 파일 선택 대화상자가 열리면 인라인 검색 및 퀵 내비게이션이 정상 작동합니다.
