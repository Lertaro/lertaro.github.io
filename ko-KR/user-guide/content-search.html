콘텐츠 검색 ​

콘텐츠 검색 플러그인은 로컬 문서의 본문을 검색하고 백그라운드에서 인덱스를 만듭니다. Lertaro의 일반 파일 이름 검색과 함께 사용할 수 있습니다.

시작하기 ​

설정 → 플러그인 → 콘텐츠 검색 → 구성을 열고 하나 이상의 모니터링 폴더를 지정한 뒤 저장합니다. 기본 트리거 키워드는 cs입니다.

text
cs 프로젝트 계획

키워드 뒤에는 공백이 필요합니다. cs가 작업 방식과 충돌하면 플러그인 설정에서 다른 키워드로 변경할 수 있습니다.

인덱싱 대상 ​

  • 모니터링 폴더: 설정한 로컬 폴더를 호스트 인덱스 서비스에 등록합니다. 초기 및 증분 검색은 SDK의 인덱스 디렉터리 열거와 디바운스된 디렉터리 변경 알림으로 수행됩니다. 각 폴더는 호스트의 로컬 드라이브 인덱스 또는 폴더 인덱스에 포함되어야 하며, 포함되지 않으면 열거 결과가 비어 있습니다. %USERPROFILE% 같은 환경 변수와 실제 폴더로 확인되는 shell:Downloads 같은 셸 가상 경로도 지원합니다.
  • 파일 확장자: 기본 대상은 txt, md, pdf, docx, docm, pptx, pptm, xlsx, xlsm, csv입니다. 쉼표로 구분된 목록은 변경할 수 있습니다.
  • PDF 파일: 추출 가능한 페이지 본문과 저장된 입력 가능한 PDF 양식 필드 값을 함께 검색합니다.
  • 파일 크기: 파일별 제한을 초과한 파일은 건너뜁니다. 콘텐츠 인덱스에도 별도 크기 제한이 있으며 0으로 설정하면 무제한입니다.
  • 제외 경로: 세미콜론으로 구분한 정규식을 사용해 전체 경로를 제외할 수 있습니다. 폴더가 일치하면 그 안의 내용도 제외됩니다.

본문 추출에 성공한 파일만 검색 대상이 됩니다. 적절한 문서 추출기가 없는 바이너리 파일은 읽을 수 없는 문자열로 인덱싱하지 않고 건너뜁니다.

설정에서 파일 크기를 무제한으로 지정해도 텍스트 추출에는 안전 제한이 적용됩니다. Office ZIP의 압축 해제된 항목당 128 MiB, Office/PDF 문서 전체의 추출 텍스트는 32 Mi 문자까지입니다. 제한을 넘는 문서는 일부만 색인하지 않고 추출 실패로 처리합니다. 개별 파일의 추출 또는 쓰기 실패는 로그에 기록하고 다음 파일을 계속 처리합니다.

검색 방법 ​

빠른 검색 창에 cs, 공백, 키워드 순서로 입력합니다. 결과에는 일치한 파일의 본문 일부와 폴더가 표시되며 Enter를 누르면 선택한 파일을 엽니다. 결과가 있고 유형 필터를 선택하지 않았다면 전체 검색 창에도 같은 파일 결과가 표시됩니다.

처음 인덱스를 만드는 동안 cs 자리 표시자에 인덱싱된 파일 수와 남은 작업 수가 표시됩니다. 호스트 감시기가 새로 추가되거나 변경된 디렉터리를 알리면 플러그인이 그 안의 파일을 백그라운드에서 처리하므로 일반 파일 이름 검색은 계속 사용할 수 있습니다. 인덱스가 안정된 뒤에는 파일 시스템을 반복해서 스캔하지 않습니다.

한 글자나 두 글자 검색어와 짧은 검색어·긴 검색어를 함께 사용하는 검색을 지원합니다. 짧은 검색어는 리터럴 부분 문자열로 비교하며, 가능하면 더 긴 검색어를 사용하면 검색 속도가 빨라집니다.

완료 알림은 최초 콘텐츠 색인 완료 후와 명시적으로 다시 빌드한 뒤 처음 완료될 때 각각 한 번만 표시됩니다. 파일 복사·수정, 설정 저장, 앱 재시작으로는 다시 알리지 않습니다. 색인 크기 제한으로 인한 일시 중지는 별도로 경고하며, 중지나 일시 중지를 완료로 처리하지 않습니다.

지우기와 다시 만들기 ​

콘텐츠 검색 설정에는 다음 두 작업이 있습니다.

  • 인덱스 지우기: 콘텐츠 인덱스만 삭제하고 모니터링 폴더를 다시 스캔하지 않습니다.
  • 인덱스 재구축: 콘텐츠 인덱스를 삭제한 뒤 모든 모니터링 폴더를 다시 스캔합니다.

두 작업 모두 콘텐츠 검색 인덱스에만 영향을 주며 Lertaro의 일반 파일 이름 인덱스는 삭제하지 않습니다.

팁 ​

  • 파일이 결과에 나타나지 않으면 폴더, 확장자, 제외 패턴, 파일 크기 제한을 확인하세요.
  • 모니터링 폴더나 인덱싱 규칙을 변경한 후 설정을 저장하고 백그라운드 스캔이 끝날 때까지 기다리세요.
  • 규칙을 변경한 뒤 기존 파일을 다시 추출하려면 인덱스 재구축을 사용하세요.
