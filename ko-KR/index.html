3 프로세스 격리 아키텍처

권한 경계를 엄격히 구분하여 최고 수준의 검색 성능과 데스크톱 안정성 확보

SYSTEM 서비스Lertaro.Service

LocalSystem 권한으로 상주하며 NTFS / ReFS USN Journal 및 $MFT를 직접 파싱하고 네임드 파이프를 통해 초고속 인덱스 검색 서비스를 제공합니다.

사용자 UI 앱Lertaro.App

표준 사용자 세션의 WPF 데스크톱 프로그램으로 퀵 검색창, 메인 윈도우, 설정 센터, 액션 메뉴 및 플러그인을 안전하게 구동합니다.

창 도킹 및 HookLertaro.Service --hook

독립 특권 보조 프로세스로 전역 키보드/마우스 훅을 관리하며, UIPI 권한 격리를 우회하여 관리자 권한 대화상자에도 안전하게 도킹합니다.

자주 묻는 질문 (FAQ)

아키텍처 설계, 백그라운드 서비스 및 사용 방식에 대한 핵심 기술 안내

Q

왜 백그라운드 Windows 서비스가 필요한가요?

NTFS/ReFS의 USN 저널을 LocalSystem 권한으로 직접 읽기 위함입니다. UAC 팝업 없이 초고속으로 파일 변경을 감지하며, UI 프로세스에 불필요한 시스템 권한을 부여하지 않아 안전합니다.

Q

Everything, Listary와의 주요 차이점은 무엇인가요?

Lertaro는 Listary와 같은 네이티브 파일 대화상자 도킹 및 퍼지 검색을 지원하면서도, Everything 수준의 USN 저널 인덱싱 속도, 최신 .NET 10 플러그인 SDK, 실시간 디스크 공간 분석을 함께 제공합니다.

Q

포터블 버전과 인스톨러 버전의 차이는 무엇인가요?

인스톨러 버전은 백그라운드 서비스를 자동 등록합니다. 포터블 버전은 무설치로 즉시 실행할 수 있으며, 필요 시 설정 센터에서 서비스를 원클릭으로 등록할 수 있습니다.

Q

검색 데이터가 외부 서버로 전송되나요?

전혀 전송되지 않습니다. Lertaro는 100% 로컬 오프라인 전용 도구이며 원격 측정 및 외부 통신이 일체 없습니다.
