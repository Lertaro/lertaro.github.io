Settings Reference ​

Lertaro provides a granular suite of customization options. Whether you want to fine-tune search bar pixel dimensions, customize global hotkeys, adjust drive indexing schedules, or manage third-party plugins and workspaces, everything can be configured in the Settings Center.

1. Window Features & Navigation ​

  • Resizable & Maximize Support: The Settings window supports smooth border resizing and titlebar double-click maximizing.
  • Global Settings Search: A search bar sits centered in the Settings titlebar. Powered by Lertaro's fzf fuzzy matching engine, it searches across all sections (including plugin settings and actions). Selecting a result jumps straight to that setting item and highlights it with a temporary flashing border.
  • Scrollable Tab Bars: In sections containing multiple nested sub-tabs (such as General, Hotkeys, Indexing), overflow navigation arrows appear on either side to ensure all tabs remain accessible across all UI languages.

2. Settings Sections Overview ​

The sidebar contains the following core sections:

SectionCore Capabilities
Service StatusWindows background service state, health diagnostics, and live log viewers for Service / App / Hook processes.
Indexing ManagementLocal drives (NTFS / ReFS / FAT32), network shares (SMB / NAS), WSL distributions, custom folders, and exclusion and priority rules.
General SettingsAutostart, hardware acceleration, IPC compatibility, search bar dimensions, Full Window column ordering, and preview parameters.
HotkeysGlobal search hotkeys, navigation keys, plugin action shortcuts, process blacklist, and fullscreen bypass rules.
PluginsInstalled plugins list, component toggles, custom configuration forms, Flow Launcher community bridge, and live plugin runtime status.
LocalSendWireless local network transfer protocol configuration (device name, port, PIN code, and auto-save options).
FavoritesStarred folders, files, and URLs with drag-and-drop ordering and quick alias recall.
HistorySearch result recall history, keyword query history, and cleanup tools.
Quick LaunchManage manual quick-launch items and choose which dynamic data sources appear in the empty Quick Search Window.
Quick PanelFloating docked workspaces, folder source aggregations, drag-and-drop file ingestion, and plugin dynamic tabs.
Appearance & ThemesLight / Dark / Follow System mode toggle and real-time visual thumbnail cards for built-in and curated themes.
About & UpdatesComponent version breakdown, user/machine data directory paths, backup rotation mechanisms, and in-place silent updates.
